# 小麦老师：五层提示词

教师入口：课程工作区 → **小麦老师 · 提示词设置**；课堂数字人面板 → **提示词设置**（新窗口打开并带入当前页、活动和课堂编号）。

## 模块与作用范围

| 模块 | 作用范围 | 默认内容 |
| --- | --- | --- |
| 总AI Agent | 所有课程 | 小麦老师的身份、职能、表达方式、教师控制与事实边界 |
| 课程 | 当前课程 | 教学对象、课程主线、知识范围和情境边界 |
| 章／讲 | 当前课程的指定讲次 | 港口课程的逐讲知识包；经济数学的单元、核心问题与练习能力目标 |
| Slide／实验 | 稳定的slide key或课程实验类型 | 作者逐页回答约束、当前页材料；实验目标与解释边界 |
| 工具 | 当前课程 | 教师可编辑的调用策略，加上服务端生成的实时动作协议 |

已建设课程覆盖：港口管理153页、3讲；经济数学1460页、32讲。经济数学13类页内实验使用各自所在页面的提示词。港口仿真、地球仪、白板、视频和互动活动有独立的实验／活动提示。未建设课程保留五层配置入口，明确显示没有已发布页面，不虚构教学内容。

每页默认提示进一步包含：本页在本讲中的作用、问题从何而来、本页材料与概念联系、后续如何使用、综合回答方式及专属约束。内容来自本页已编写的材料、附近最多两页可安全引用的前置材料，以及按港口课程20个小节／经济数学8个单元编写的概念联系。课件顺序只作为知识衔接，不表示本班已学习，也不直接作为因果证据。

跨讲只提供上一讲主题，不拼接其他讲的页级材料。经济数学不导入前面的练习解答或未知揭示状态的实验结果；后页只说明环节作用，不注入后页题干、公式、数值或答案。已有教师自定义文本继续保留，关联背景通过实时上下文补入。简单问题仍简答；综合问题再联系前置条件、本页机制及有条件的影响。

## 编辑与生效

- 选择讲次、Slide或实验，再选择五个模块之一。修改后手动保存，下次提问生效；已开始的回答不会中途更换提示。
- 总Agent修改影响所有课程；其他模块按课程、讲次或稳定页面标识隔离。恢复默认删除对应覆盖文本，保留其他设置。
- 设置由平台状态存储持久化，兼容JSON开发适配器和校园SQLite状态存储。全局修订号防止多人旧页面覆盖新配置，发生冲突返回409。
- 提示词管理及现场预览接口仅供教师使用，学生snapshot不增加提示词字段。编辑页直接请求服务端，不缓存到离线课程响应中。

## 调用链

文字／语音转写 → `/api/class-sessions/:id/assistant/turns` → 服务端最新课堂snapshot与已保存设置 → 五层编译器 → LLM → 校验后的课堂动作与dialogue → TTS/LAM。

每次调用都重新读取设置，注入当前课程、讲次、页面、局部与全局页码、实验参数及揭示状态；仿真与地球仪使用当前摘要或播放状态。没有提供的视频／白板内容不会假装已经读取。提示词只进入LLM请求，数字人播报的是dialogue，不朗读提示词。课下学习也使用同一五层配置，并替换为个人学习工具协议。

页面事实与工具协议来自服务端，编辑工具提示不能扩大实际动作权限。经济数学未揭示练习或实验暂不注入可能包含参考答案的页级编辑文本，改为策略性提示；原始编辑文本仍可供教师查看。提示词、页面、活动或实验状态变化后，不沿用旧上下文中的模型回答，避免串页与已揭示答案倒灌。

备课页的完整预览使用实验初始值。由课堂打开时，点击“刷新当前课堂注入预览”可读取最新现场内容；该内容与下一次调用使用同一个编译器（前提是期间没有再次切页、修改参数或保存配置）。

## 验证

- `pnpm test`：包含1613页的五层覆盖、作用域、学生权限、重启恢复、修订冲突、恢复默认、文字／语音请求捕获与课下调用验证。
- `pnpm build`：类型检查与生产构建。
- `pnpm --filter @edu/platform-api exec tsx ../../scripts/verify-assistant-prompts-browser.mts`：需要5173开发前端；使用临时隔离API，浏览器修改五层后核对模型请求，检查桌面和390px布局，不改变日常课堂提示词。报告位于 `output/assistant-prompts-qa/`。

请求链路验收使用捕获型模型提供器验证完整请求及SSE行为，不代表已验证真实模型的回答质量、现场麦克风识别或数字人口型同步。
