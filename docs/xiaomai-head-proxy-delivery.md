# 小麦老师：立体辅助转头与 P1/P2 动作

## 验收后的实装调整

用户验收后决定不实装左右转头。当前教学系统、课下学习和动作预览均已停用水平转头；单项左右转头、连续转头和转头眨眼按钮移除，旧动作 ID 保留为无动作兼容项。思考、讲解、头发和身体组合也不再带动水平转头，动作输出统一将 `x` 锁定为 0。下文的 Blender 转头资料与旧截图保留为制作历史，不代表当前实装动作。无接缝原画分层、独立眼睛、口型、点头、俯仰和歪头继续使用。

形象选单保留“小麦老师 · Live2D”和“澜舟 · 视频”。Haru、名取仁、日和、LAM 从选单移除，旧选择在读取时归一为小麦老师及默认语音，避免打开页面先加载旧模型。相关旧资源仍保留，不影响历史文件。

待机安排：呼吸周期 5.6 秒，眨眼间隔 3.2–6.7 秒；每 12–22 秒轻微移动视线并回正。首次待机约 10 秒后出现一次 4.5 秒的小幅重心变化和微笑，后续起始间隔 14–24 秒，大部分时间保持安静。倾听时目光回到前方，仅作一次轻点头，避免反复点头像在不断赞同；思考和讲解优先于待机动作，讲解强调仍由实际音量触发。减少动态效果设置继续生效。

本次实装验收证据位于 `output/live2d-qa/xiaomai-release-*`，动作、偏好迁移与回归测试日志为 `output/xiaomai-release-unit.log`。

本次结果：91 项前端测试、工作区类型检查与生产构建通过；20 个基础动作、9 类口型、减少动态效果、窄屏取景及课堂/课下 6 种布局通过。浏览器从旧 LAM/名取仁偏好进入，确认选单仅两项且未请求退役模型。26 秒待机采样及 5 种状态切换留下 11 张截图，复查未发现新增明显接缝。音频时钟夹具及打断、视频切换回归通过（首次并发浏览器采样未满足口型数量断言，独立重跑通过；本轮未重新调用外部 TTS）。本地教学系统与生产构建已更新。

## 制作路线与交付边界

使用本机 Blender 5.1.2 建立与原画逐点对应的浅曲面头部代理，制作 -18、-9、0、9、18 度左右转头形态，然后烘焙为二维位移数据。鼻部、脸颊、耳侧与外轮廓有不同深度；眉眼、嘴部所在的局部平面与邻近皮肤平滑连接。正面纹理保持原画，不使用重新打光的三维材质。

这是小幅转头的 2.5D 制作，不是完整三维头模：没有重建后脑和大侧面隐藏区域。当前俯仰仍采用已有的小幅二维绑定。18 度是 Blender 代理的角度范围，不代表单张插画能支持任意真实视角。

运行时使用 **Blender 烘焙数据 + 无损原画分层网格 + 原有独立眼睛和口型**。这是教学系统的播放器扩展，**没有把新增关键形态写入 `.moc3`**；不能将原始 `.moc3` 单独移入其他 Cubism 播放器，期待得到全部动作。原始 `.cmo3`、PSD、`.moc3` 保留。

原试制模型纹理图集的重采样在分层边缘留下细线。新版直接使用原始分层 PNG，并从同坐标的原始合成图向各分区边缘补入 2 像素颜色重叠，避免相邻两个半透明边缘相乘后漏出背景。补入的是已有原画像素，不是新生成的脸。原版 P0 留在预览的版本选择中供对照。

眨眼时保留原始瞳孔与眼白纹理，并对移动眼睑的接触线做抗锯齿曲线处理，消除半闭/闭合时睫毛纹理重采样的碎边。完全睁眼的双眼仍直接输出原始图层像素。

## 动作覆盖

| 级别 | 已制作的动作 | 使用方式 |
|---|---|---|
| P0 | 自然眨眼、半闭/闭眼、四向视线、眉毛、连续口型、真实语音口型、左右转头/回正、抬低头/点头、歪头、呼吸、头发延迟 | 原有共享语音与状态驱动；预览逐项和组合检查 |
| P1 | 身体轻转左右、前倾、重心移动、微笑鼓励、思考疑问、专注倾听、轻微惊讶、认真强调 | 9 个可单选姿态/表情；倾听、思考、说话状态复用对应的克制动作 |
| P2 | 短促微笑、柔和眯眼、待机节奏变化 | 3 个细节动作；保留原有单侧挑眉 |
| P2 | 欢迎开课、解释概念、提出问题、等待回答、肯定答案、结束讲解 | 6 个组合动作；一次性组合自然回正，解释/等待可持续 |
| P2 | 状态自然衔接、打断后停下 | 按已有课堂状态渐进过渡；实际口型仍由音频时钟驱动，静音和打断闭嘴 |

组合动作通过播放器的 `animationAction` 可调用，并在预览中有明确按钮。没有新增从回答文本猜测“这句话是在提问/表扬”的自动语义触发器，也没有向教师课堂界面增加手势控制面板。

## 按用户允许跳过的项目

| 项目 | 原因 |
|---|---|
| 双臂身前合拢等独立手臂待机姿势 | 现有半身画没有可独立活动的完整手臂和手掌 |
| 挥手欢迎、挥手告别 | 需要新增手臂、手掌、袖口及遮挡补画；现有欢迎/结束组合采用面部与点头 |
| 指左、指右、指指定课件区域 | 同上；未以移动整张头像冒充指向手势 |
| 摊掌、双手展开、计数等讲解手势 | 同上 |
| 惊讶时额外扩大眼白、夸张表情 | 未补画额外眼白和大幅表情素材；本版惊讶限于抬眉、轻微圆唇 |
| 大角度侧脸、后脑转向 | 单张原画缺少隐藏区，当前代理只用于小幅转头 |
