# 港口模拟实验停滞与速度异常排查

日期：2026-10-17。范围为本地工作区和本机浏览器，不包含远程部署、真实学生账号或历史成绩改写。

## 已确认的问题

1. **常规综合实验被切换到了不同的时间模型。** 第11、12讲设施模型引入后，`usePortOperations` 的新场次默认值从3.1变成3.2。五个独立课程分段仍明确使用3.1，但原48小时综合入口也被默认切到逐箱设施模型。该模型计入空车到位、道路预约、场桥移动和堆垛操作，其时间尺度没有按原综合实验的船期、服务时间和评分目标重新校准。不能用同一套课堂节奏和履约目标直接替代原实验。
2. **堆场存在真实的倒箱活锁。** 调度把全部倒箱任务放在直接提箱任务之前。在底层位置均被占用的堆场中，一只未来船舶的箱子可以在两只当前待装箱上方来回移动。每次刚露出的箱子还没得到提取机会，又被下一次倒箱压住。默认综合场景中，S01最终停在46/78箱装船，S03停在0/62箱装船；第30至48小时卸船、装船、交付三个累计值均不再增加。
3. **道路等待被连续场桥作业饿死。** 旧调度先给下一次场桥作业封路，最后才重新检查已等待的车辆。连续倒箱可以反复封闭同一区域，邻区已有任务的车辆也无法出发。

教学模式的节点暂停另有明确原因：资料通过、卸船完成等目标会暂停一次，必须点击“继续运行”。这种暂停与上述时钟继续走、任务长期无新增的程序停滞不同。实际浏览器操作已逐项核对这些节点。

### 已修正的问题

1. **撤岗交接期间车辆被误标为未配岗。** 司机由2人减为1人后，场内车2仍载箱进行原有安全交接，但从7200秒到7304秒被标为 `unstaffed`。现在这104秒记为在岗等待交接，真正交接并退出后才记为未配岗；物理任务和人工成本不变。
2. **基准独有的状态缺少图例。** 状态条已画出基准中的故障或停用颜色，但图例只收集当前方案的状态。现在构成条图例取当前与基准的并集；不叠加基准的时间轴仍只展示当前状态。
3. **零产出也画出1像素柱。** 移除零值柱的最小正高度；产出为0时柱高为0。完成任务数的纵轴刻度同时改为整数。
4. **低库存曲线几乎贴在0线上。** 原堆场容量占用图固定显示0—100%，而实际峰值只有0.31%—0.51%。现在库存图按当前与基准共同峰值选取可读刻度，始终从0%开始，并明确标示缩放；设备任务占用率仍保留0—100%的刻度。
5. **重开后残留旧图表提示。** 旧提示可能仍显示第120—130分钟的数据，而新场次已回到第120分钟。现在模拟时间回退或图表配置变化时清除提示。浏览器已验证重开后清除，再推进5分钟也不会重新出现。
6. **进行中的试验与完整基准计算差值。** 原表把第150分钟的4箱与第360分钟的30箱直接相减，显示为减少26箱。现在进行中仍显示实际进度，但交付与成本差值标记为“待同终点”，完成到统一终点后才计算。
