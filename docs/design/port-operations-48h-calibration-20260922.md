## 发现并修复的问题

1. 成本基准异步计算期间，网页曾把未含效率分的 79.50 先显示为“本地成绩”。现在总分和效率分在参考计算完成前显示“计算中”，完成后才显示最终值。
2. 时长先拆小时再四舍五入分钟，可能显示“× 小时 60 分”。现在先对总分钟取整再拆分，正确进位。
3. 提交与工作区回归测试在 Windows 使用 `python3` 商店别名及 URL pathname，导致清理步骤失败。已使用平台适配的解释器及 `fileURLToPath`，支持 `EDU_TEST_PYTHON` 覆盖，相关回归通过。

本次覆盖的运营链路未发现阻断性业务错误。每步检查了箱量守恒、交接账本连续性、堆场容量、活动箱与设备唯一占用；核对异常处理、空交班被拒绝、有效交班得分、导入导出同状态、伪造成绩被忽略。上述结果不等同于所有参数组合及真实课堂设备的穷尽验收。
