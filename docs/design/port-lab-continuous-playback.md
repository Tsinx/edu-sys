# 第11、12讲：连续作业推进

2026-10-14，本地版本。

## 学生操作

两讲的普通推进均按小步运行同一个逐箱内核，三维现场、任务进度、车辆位置、库存和费用随仿真时钟更新。可选择1、5、10、30、60、120倍速；默认为30倍。可以连续推进5、15、30分钟，前往下一整10分钟节点，或选择观察终点。

暂停按钮具有独立且固定的停止行为，继续在另一个按钮上操作。暂停后保留目标；恢复运行不会补算离开页面的时间。到达选定目标、观察终点或处置检查点均停止。快算入口折叠在“快算 · 跳过过程画面”内，继续调用相同内核，但直接显示计算后的状态。

第12讲的独立记录核验与恢复对账现在分别启动10分钟耗时任务，经过真实的仿真时间才登记完成；任务可暂停、保存和刷新后续接。技术工作完成、24箱备用额度耗尽和3箱实际试运行完成仍由内核触发自动停止。旧版 `audit`、`reconcile` 指令继续按原语义重放，新过程使用 `start-audit`、`start-reconcile` 与 `tick`。

## 实现边界

- `usePortLabPlayback`只管理播放调度，不另存一份箱流、设备或成本模型。每次调度最多计入250毫秒墙钟间隔；后台挂起不通过一次大跳补时。
- 模型以整数仿真秒推进，画面在当前作业阶段内插值；镜头插值受目标和下一作业事件约束，暂停时使用已确认状态。改变倍速不会改变设备名义能力。
- 现有场景及控制器保持挂载；设备构造参数不变时不会随时钟或倍速重建WebGL场景。综合模拟沿用原有播放控制。
- 沿用 `port-class-lab/2.0`逐箱模型及原初始条件；新耗时任务可由指令重建。保留旧场次、历史分支、原笔记和报告要求。
- 低倍速用于观察动作；完整基准与多次试验可切换60或120倍，以适应约30分钟实操。
