# 港口仿真 V0.04 课堂可靠运行与边缘协同说明

## 1. 本版目标

V0.04 不增加新的港口类型、货类或设备规则，集中解决 70 名学生、15 个小组同时上课时的身份可信、断线恢复、服务端负载与运维可见性。用户可见版本为 `V0.04`，业务场景继续使用 `0.0.3`。

新建运行使用 `event_stream_v1`；从 V0.02/V0.03 数据文件加载的运行标记为 `snapshot_legacy`，继续走完整快照接口。运行中的旧数据不会被补写事件序号或迁移业务规则。

## 2. 权威状态与浏览器回放

服务端仍是唯一裁决者。浏览器不能直接提交身份 ID，也不能在服务端确认前将正式命令写入权威界面。每个小组拥有独立、单调递增的 `sequence`：

1. 服务端按顺序验证身份、席位令牌、业务版本、基础哈希和安全规则。
2. 服务端写入一条规范事件并返回轻量命令结果，不附带完整快照。
3. SSE 将同一事件对象复用给本组所有监听者。
4. 浏览器 Web Worker 使用相同版本的 `@edu/port-simulation-core` 回放事件，计算地图投影、派生状态与 SHA-256 哈希。
5. 本地哈希与权威哈希不一致、事件有缺口或运行 ID 改变时，客户端停止正式命令并重新读取检查点。

状态哈希排除连接状态、席位租约、界面选择和 `wallClockAnchor`。数组在规范化阶段按稳定标识排序，浮点数按固定精度表示。核心不读取未注入的 `Date.now()` 或 `Math.random()`。

服务端为已经发给客户端的事件、检查点和时间同步哈希保留 20 秒短窗口。命令仍须同时匹配运行 ID、事件序号和业务版本；该窗口只用于消除“服务端时钟刚推进、客户端下一条时间同步尚在传输中”的误判，不允许旧业务事件或旧版本命令越过冲突检查。

## 3. 事件流、检查点和恢复

- SSE 支持 `Last-Event-ID` 和 `afterSequence`，代理响应头包含 `X-Accel-Buffering: no`。
- 服务端每 5 秒发送轻量时间同步；学生界面区分在线、重连、补齐事件、状态一致、离线和重新同步。
- 每 30 秒或累计 50 条权威事件保存检查点，以先到者为准；SQLite 仅保留最近三个检查点，并在检查点覆盖后压缩旧事件。
- 事件已被压缩时返回 `resync_required`。教师可对单组发起强制重同步。
- 页面不可见或减少动态效果只影响 SVG 表现，不暂停权威时钟和岸桥移动事件。
- API 重启后从 SQLite 检查点恢复新运行，并统一转为安全暂停；进程内租约失效，需要学生重新认领席位。

## 4. 持久化与租约边界

平台已有课程等开发数据仍使用 JSON 适配器。新仿真运行的元数据、规范事件、幂等回执和检查点使用 Node 内置 SQLite，启用 WAL 和 `synchronous=NORMAL`。

岗位续租、在线状态和 `presenceRevision` 只驻留进程内存。续租接口只向调用终端返回新的到期时间，不写完整业务状态、不推进 `revision` 或 `collaborationRevision`，也不广播完整快照。未来多实例部署可在不改变业务事件协议的情况下替换为 Redis 租约适配器。

## 5. 身份与姓名可见范围

`ClassroomIdentityProvider` 是平台与教学信息系统之间的中立接口。业务处理接收解析后的 `ClassroomActor`，不相信请求体中的 `participantId`。开发环境通过同源、HttpOnly、SameSite=Lax Cookie 使用 `DevelopmentIdentityProvider`；生产模式默认禁用开发身份和旧式请求体身份回退。

未来教学信息系统适配器负责认证、教学班名单和固定分组。外部 subject、原始学号和令牌只应存在于服务端映射中，不得进入事件、检查点、课堂快照或 DOM 数据属性。

教师可读取任一小组的实名席位。学生只有加入本组后才能读取本组检查点、事件流和实名席位；课堂总览中的其他小组只包含人数、岗位、序号和运行摘要。

## 6. 15 组课堂启动检查

教师端启动前检查包含：身份适配器、名单/分组来源、1–15 组容量、四主操到岗、SSE、服务器时间和 SQLite WAL。开发身份和主操缺席显示警告；非法固定分组、超出容量等条件显示阻断。教师仍可明确确认缺主操开局，且该决定进入事件记录。

70 人可以使用默认的 14 个 5 人组，也可以显式配置十个 5 人组与五个 4 人组。任何配置都必须保持每组 4–6 人、总容量等于运行人数。

## 7. 部署配置

推荐由同一个 HTTPS 站点反向代理 Teacher Web 和 `/api`。生产反向代理必须关闭 SSE 缓冲并将读取超时设置为高于一堂课时长。主要环境变量：

```text
NODE_ENV=production
EDU_API_HOST=0.0.0.0
EDU_API_PORT=4300
EDU_DATA_FILE=/srv/edu/state.json
EDU_PORT_SIMULATION_DB=/srv/edu/port-simulation.sqlite
EDU_ALLOW_DEVELOPMENT_IDENTITY=false
```

生产环境不得把 `EDU_ALLOW_DEVELOPMENT_IDENTITY` 设为 `true`。教学信息系统适配器尚未交付前，生产身份路由会拒绝未认证请求；不要使用请求体身份回退临时绕过。

Nginx 类代理的 SSE 路由至少应设置：

```nginx
proxy_http_version 1.1;
proxy_buffering off;
proxy_cache off;
proxy_read_timeout 2h;
```

## 8. 本版边界

V0.04 仍是单 API 实例，不包含 WebRTC、学生主机选举、客户端权威状态、Redis、多实例实时网关、真实教学信息系统适配器、花名册编辑器、AI 调度或排行榜。
