# 港口教学引导与航行规则 1.0

四项交付：语义化时钟高亮、舞台循环拖拽手势、与业务时间一致的船舶航行、三秒呼吸光。参数为教学假设，不代表真实港口生产数据。

## 操作教学

`clock:start`、`clock:resume`、`clock:pause` 分别注册；等待时优先定位屏幕内的继续入口，顶部时钟滚出视野时使用教学卡内入口。运行后高亮转向回执或航行结果，不继续圈住暂停按钮。

入港步骤提供源船舶 ID 与有效目的位置集合。桌面手势使用实际三维投影，每四秒演示一次左键按住、移动、松开；学生操作期间让开，错误拖放后允许重试。窄屏使用同一业务命令的对象—目标操作。相机由首次定位或用户主动定位调整，手动观察不会反复被拉回。动态效果减少时保留静态指引。

## 航行模型

共享模块 `port-navigation.ts` 不依赖 Three.js。世界坐标每单位两米，船头局部正 X 方向；航迹以相切直线、圆弧和最终辅助横移组成。两类船型分别使用 300 / 400 米最小半径，港外 6 / 5 节、港内 3 / 2.5 节，转弯不超过 2 节，辅助靠离泊不超过 0.3 节。加速 0.02 / 0.015 米/秒²，减速 0.03 / 0.02 米/秒²。

路线筛选使用带余量的船体矩形，检查岸线、陆域、其他泊位、锚位及港外候泊位置。港外位置由挂靠 ID 固定，船舶从该位置起航，通过同一入口；候泊区与入口航道分开。路线和速度曲线只由输入参数决定，查看资料或播放手势不消耗随机数。

速度曲线以不超过四米的弧长采样，前向限制加速、后向限制减速；按匀加速段求时间和位置。完成事件取整到仿真秒，最后不足一秒保持停稳。渲染与状态读数共用同一采样函数，船体和船上箱位同步旋转。内核决定资源释放和系泊完成，动画不发送业务指令。

目的位置先预留。离开原泊位、锚位的船体清空其占用范围后，发出 `source-clear` 事件；航道在到达事件释放。原挂靠泊位信息保留为进口岸侧货物来源，实际泊位资源独立释放。系泊与解缆准备各十五分钟；教学增加 10× 选项，实战固定 60×。
