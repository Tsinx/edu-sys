# 港口逐箱设施版修复与验收

本次交付覆盖第11讲、第12讲专用实验及48小时综合模拟。发布课件版本为 `release-port-management-facilities-v20`，实验为 `port-class-lab/2.0`，综合规则为 `port-operations/3.2`。

## 同一份运行状态

- 两讲复用综合内核。每箱只有一个业务身份，船载、车载、吊装和箱位均由任务及库存记录推导。
- 岸桥必须有操作员、可接箱车辆和交接位置；取消无车卸入地面缓存的替代流程。
- 目的作业位可用时直接送达；仅在受阻时安排带箱待接。空驶、送入作业区、吊装、空吊具返回及交接完成均有持续时间。完成交接后，车辆实际离位才释放位置。
- 运输按连接道路、交接支路和待命区行驶，记录空载与重载距离。道路按车辆占用范围预约；暂停导致预约过期时重新申请。
- 场桥按实际服务区、位置、转场任务和人员派工。轨道场桥不能跨场块；同一场块只容纳一台场桥。吊装前先封闭作业区，等待已预约交通清空，防止无限让路。
- 箱位有唯一占用与底层支撑；只提顶层箱，必要的倒箱形成真实任务。船上出口箱不会压住尚待本港卸下的进口箱。
- 出口提箱前先取得可行装船箱位，防止所有场内车辆被无处装船的出口箱占满。综合外集卡区分进口提箱和出口送箱；两讲只安排进口货流，固定4辆外集卡提箱。
- 岸桥分配变更需待原任务与交接预约清空，协同移机计时，保持轨道顺序。船舶停工及风况变化会改变在制任务；有在制任务的设备不能直接撤走操作员或司机。
- 库存和结果以交接循环完成为结点；落箱到空吊具返回期间显示交接中。渲染不额外生成堆场装饰箱、永久车载箱或独立循环车辆。

## 功能修复

- 每个窗口、刷新和导入建立独立记录分支；不覆盖来源。闲置窗口不反复刷新最新记录指针，历史场次可恢复。
- 损坏原记录保留；损坏的旧入口原文先另存，新副本可以继续自动保存。存储失败时明确提示下载备份。
- 完成标记按重放结果与复盘要求重算；未完成运行不能靠导入时间戳伪装完成。
- R2、R3是相同有效副本，隔离其中任一条及R4均可通过核验。
- 第12讲未恢复的失败处置也可以在240分钟保存复盘；重开保留前次分支及文字、事件、失败尝试。
- 技术恢复、备用额度用尽、实际3箱试运行完成自动暂停。切离页面暂停自动推进；未应用的岗位修改阻止开始试验。
- 对照表列出全部岗位、交付差额、成本差额和未完成量。近10分钟实际出流与配置、暂停状态分别标明。
- 右键拖动由画布接管并抑制拖动后的菜单；默认支持左键平移、Shift加左键旋转及滚轮缩放。
- 网页全屏与屏幕全屏独立。浏览器拒绝屏幕全屏时报告失败，保留场景和当前操作状态。
- 普通局域网HTTP缺少SubtleCrypto时，记录使用同结果SHA-256兼容实现；填充边界、中文、大记录和原生实现已交叉核对。

这不是生产港区数字孪生。几何和速率为教学设定；交通预约偏保守。未校准真实车辆动力学、司机班制、能耗、危险货物间距或法定放行。浏览器与模型验收不等于已完成真实班级试讲或跨设备网络实测。

## 使用

本机统一入口：http://127.0.0.1:5174/port-classroom.html 。同网段使用教师电脑IPv4地址替换127.0.0.1。服务只读提供构建产物，不代理后台接口；实验在各学生浏览器独立运行。

重启：在仓库根目录运行 `pnpm serve:port-classroom`。修改代码后先运行 `pnpm --filter @edu/teacher-web exec vite build`。原5173开发入口继续保留。
