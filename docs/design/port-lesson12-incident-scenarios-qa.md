## 已实现

1. 初始只显示告警，范围、接口日志、备用台账或设备诊断经耗时检查取得；第95、110分钟回报引用当时实际车辆、库存和交付。中途回报、检查完成、维修完成、替代返回与试运行完成自动暂停。
2. 系统场景支持隔离范围、1/2人维修、备用交付、对账和实际3箱试放行；RTO 60分钟、RPO 10分钟为教学目标，初始数据暴露窗口不冒充已永久丢失量。
3. 设备场景支持保护停机、安全交接收尾、2分钟撤离检修位、隔离、90人分钟维修、场桥3实际转场支援、完成当前任务后实际返回、维修后检查、故障场桥空载返回及实际3次箱交接。设备复工目标90分钟。
4. 暂停业务只阻止新派工，已承诺的非闸口物理任务安全完成；失去可信记录的闸口不适用该放行规则。替代设备原区暂失能力，转场/空载返回不计箱交接。
5. 同开局重开保留历史方案、复盘及拒绝尝试，沿用图表并清空当前复盘；仅同场景、同规则的已完成方案进入图表对照，使用相同设备与当前已观察时间窗。完整JSON重放指令，重新生成线索、状态区间与交接记录。
