# 港口长期独立经营系统

## 已确认的范围

单人独立经营；浏览器本机工作线程执行全部仿真；本机数据库存档；平台仅用于身份、任务发布、主动提交与独立核验。保留旧分段、48小时、第11—12讲实验和历史存档，不改变它们的规则、入口和评分。

完整产品覆盖：空间与自然环境、治理权责、市场客户、规划建设、设备资产、维修备件、人力与排班、联合调度、船舶交通与服务、六类货种生产、堆存、腹地集疏运、口岸保税、财务融资、能源环境港城、数字协同、安全恢复、绩效实验、个人教学考核、版本与保存。

## 模型边界

- 时间使用UTC日期和小时事件，支持1/3/5经营年。季度与月份按日历计算。
- 长期生产使用货批级小时离散模型；单箱精细实验仍由原引擎承担。参数为带单位的教学情境，不冒充真实港口价格、生产数据或监管时限。
- 船、货、库存、资产、人员、应收、债务、建设和故障跨期连续。三维场景只读业务投影，不决定业务完成。
- 每台资产独立型号、泊位归属、交期、投运依赖、工时、维护、能耗和账面价值。不得按设备总数重复计算能力。
- 购买资本化，折旧计损益；购置款只流出一次。余额、利息、应收和终期义务可核对。
- 默认以已批准的计划和策略执行日常业务，学生可调整策略、安排具体挂靠、处理异常并保存决策说明。
- 原始指令重放是核验依据，本机快照仅用于恢复和展示。正式任务的初始条件由平台绑定。
