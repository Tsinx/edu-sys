# 港口长期经营5.0：总经理模式验收

日期：2026-11-01。范围为本机长期经营模拟的UI与运行方式。校园服务器、真实学生记录、旧课堂六类实验的规则及成绩均未改动；没有提交或推送Git。工作区其他课程的在制修改继续保留。

## 已实现

- 港口3D场景为主界面。顶部经营、资源、建设、市场、财务、报告菜单打开工作窗口，“全部”保留搜索与专业接管入口。日结折线只在报告窗口显示；关闭窗口回到场景，不保留常驻曲线。
- 日常约1秒1天；每月8日00:00暂停进入24小时现场观察日，约1秒10分钟，每6秒按原小时引擎结算一次。次日00:00暂停恢复简报。打开管理窗口、编辑输入或切到其他浏览器标签时暂停。没有逐船点击的日常要求。
- 重大异常在发生小时暂停，由经理核查和授权；获批修复可以交给部门继续执行。既有保险、备用方案、预算、资金停产及破产责任保留。
- 起重岗位先覆盖真正具备装卸条件的泊位，再按剩余标准作业小时分配追加岗位。设备适配、合格人员、供电、燃料与就绪货量共同限制数量；覆盖不足时累计等待进入排序。适配设备不足不能被虚拟岸桥补齐。
- 每台设备保留最近24个实际作业小时，图层可看负荷、岗位保障、健康。缺人、缺电、缺油、补能、检修、故障、受阻及无样本分别表达；点击实际3D设备可核对状态时长。日常代表性流量动画与现场实际船舶有明确标识。
- 每日保存真实经营结果；履约或等待无样本时保留缺口。报告支持30日、90日、一年、完整经营期和日期核对。十年绘图缩减点数时保留区间实际高低点。事件标线仅使用最近事件窗口，不声称覆盖十年全部事件或证明因果。
- 自由练习与正式任务支持1、3、5、10年；新界面默认10年。完整经营与单人本机计算保留。前半年带教使用10年港口，核心兼容既有3年教学配置，但不迁移旧引擎存档。
- 游戏带教升为7版、43项任务，新增巡港日程、首个现场日、设备图层、实际岸桥分配和日结趋势。当前按钮/字段闪烁并显示鼠标示范，其他经营操作和快捷键锁定。前半年资金方式仍由核心固定，退出或刷新不能解锁，第181日交接后继续同一港口。
- 两种全屏继续由同一个展示控制器负责；只有一个底部工具栏。窄屏使用紧凑按钮，教程会滚动顶部菜单把当前高亮项带入可见范围。

引擎/作业：`port-enterprise/5.0`、`port-operations/5.0`；新增`port-director/1`、`port-enterprise-telemetry/1`。设备、需求、财务和评分分别保持3.0、2.0、4.0、4.0。带教/学习报告为7。保存按引擎作用域隔离，未删除旧库；新版不重算4.0或更早成绩。
