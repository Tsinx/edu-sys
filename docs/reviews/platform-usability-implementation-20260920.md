## 数据清理与回滚

`deploy/linux/cleanup-classrooms.py` 先输出不可变的课堂 ID 清单，再在停止服务、完成全库备份后执行。删除课堂、运行时、课堂活动和旧多人仿真事件；保留课程、账号、阅读进度、个人存档、实验任务、全部提交及核验证据。每个删除课堂保留最少的课程映射与删除时间，用于旧链接提示和延迟提交校验。

脚本执行前后比较保留数据的逻辑散列，可重复执行。`update-release.py` 可接收清理清单作为第二参数；清理或启动失败时恢复全部数据库与旧版本。生产清单和含学生数据的截图仅存放于受保护的 `.runtime`，不提交到 Git。
