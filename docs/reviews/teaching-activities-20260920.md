# 教学活动流程与界面提升

## 已实现

- 教师工作台突出继续课堂、课前编排、实验反馈；课程页采用紧凑封面、讲次列表、真实课件页数与已保存活动数量。主导航保持工作台、课程、实验任务。
- 课程增加“教学活动”，提供本讲活动单、课程题库、课堂复盘。原习题库地址重定向到新入口。
- 从已有题库添加活动，调整顺序、建议发布分钟、建议作答时间、关联课件页及可选标记。支持题库现有新建、编辑、复制、归档功能；编辑和编排均可预览学生答题及公布后的画面。本次不新增课程习题正文。
- 活动单保存时锁定题目版本和内容。题库更新需明确选择采用；已载入课堂的活动单保留独立快照。冲突保留当前草稿并提供重新加载；保存中禁用编辑，未保存离开提示。
- 四门课程课堂均可打开活动面板，载入本讲活动单后手动发布、跳过或恢复。已发布状态跟随收题、公布结果；时间仅供参考，不自动发布。保留临时出题、点名及分组。
- 校园学生以实际登录姓名自动加入进行中课堂；教师预览和结束课堂不自动加入。
- 复盘按课程、讲次和课堂查看，课堂及活动各按 20 条分页。保存每项活动的参与名单和分组；多选完全匹配才计为正确，正确率分母为已提交人数，零提交、投票和点名不显示正确率。
- 学生从课程卡片进入自己的活动历史，只能看到本人已提交活动和本人答案。标准答案、讲解仅在教师公布后可见，不返回其他学生作答、名单或分组。
- 手机端活动编排与预览分步显示；成绩默认单实验，保留筛选后的完整导出。

## 数据与一致性

新增课程活动单、课堂执行快照、活动参与名单表，以及公布时间和请求内容指纹字段；旧库采用增量迁移。仅旧状态为“已公布”的活动补记公布标记，已结束活动不会因此公开答案。

活动创建、题目版本关联和执行状态在同一 SQLite 事务完成。重复点击不会重复发布；失败则一并回滚。不同课堂独立执行，同一活动单使用乐观版本检查。

本次不执行课堂清理、不修改账号密码、选课关系、课程归属和已有实验记录。生产校验清单、测试数据库、含个人信息截图仅保存在受保护的 `.runtime/portal-qa`。
