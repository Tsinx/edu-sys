# 港口长期独立经营：使用与教学说明

本系统以虚构的东湾港为教学情境。每名学生独立经营，全部生产计算在自己电脑的浏览器工作线程中执行，经营时间由学生主动推进。关闭页面不会继续消耗经营时间。

## 学生本机启动

含详细教学模式的分发包：`output/port-enterprise-teaching-student-windows-x64-2026-10-25.zip`。原分发包保留。

1. 将 ZIP 完整解压到固定文件夹，双击 `Start-PortEnterprise.cmd`。不要在压缩软件内直接运行。
2. 使用近期的 Windows 版 Edge 或 Chrome 打开启动器给出的本机地址。包内已包含 Windows x64 运行程序，无需安装 Node、数据库或下载素材。
3. 自动存档保存在当前浏览器的 IndexedDB。保持相同浏览器、解压目录和地址；跨电脑、更换浏览器或清理浏览器数据前，先导出 JSON 存档。
4. 通过“存档与回放”另建个人练习，可选择 1、3、5 个经营年，以及接管、增长、绿色或韧性情境。另建和导入均保留已有记录。
5. 双击 `Stop-PortEnterprise.cmd` 结束本包的文件服务。停止工具核对包实例、进程与可执行文件，只结束匹配的服务，浏览器存档继续保留。

本机文件服务仅监听 `127.0.0.1`，负责提供程序文件。三维不可用时提供业务平面图；生产、存档与业务面板仍可使用。正式平台的身份与成绩服务不随学生离线包启动。

## 详细教学模式

本机平台可直接打开 `http://127.0.0.1:5173/port-enterprise?tab=learning`。课程“长期经营”卡片提供教学入口；离线包在侧栏或页头点击“教学模式”。选择“另开三年教学练习，保留当前记录”，使用同一引擎创建种子20261025的3年接管情境。旧场次不被覆盖。

教学路线有八章、40步。每步分别说明现在的操作、参考参数与答案、原因、真实完成条件，并可定位和高亮实际控件。成功指令、业务结果与知识题共同形成学习进度；单纯按“下一步”不能通过业务任务。失败原因显示在原表单附近，错误操作保留在经营日志中。

| 章节 | 实际操作与证据 |
| --- | --- |
| 接管与单证 | 现金与债务口径；人工单证、兼容泊位、正确独立引用、等待回执、监管与交付、离港准备 |
| 生产与人员 | 日常策略授权、设施适配的运输路径、公路限额、招聘技术后备、夜班技能培训和本人安排检修 |
| 投资与设备配置 | 购置190万元AGV、租赁日租600元的人工闸口、1400万元自动化配套、岸电与保障条件 |
| 客户与资金 | 1.05后续报价、当前季度真实可用协议、50万元借款与偿付、3份备件采购及成本确认 |
| 投运与应急实证 | AGV60日交付时等待接口、150日自动化投产后验收；核查、隔离、可选备用、技术修复、实际完成和确认恢复；培训后技术人员入班 |
| 绩效与解释 | 月报口径、相同种子/时点/规则的对照、四类不少于20字且有真实数据的决策说明 |
| 年度滚动经营 | 每年运行观察和单独年度复盘；年度说明必须在该年末后保存，保持三年连续记录 |
| 结业与保存 | 如实核对期末义务、封存、完整JSON与CSV、学习报告、只读回放，以及本机保存和平台回执的区别 |

参考方案用于学习约束与取舍，不承诺最优解。每季度只提供三类轮换合同，教练读取当前实际合同，不虚构所有货种同时可选。设备和工程按小时结算验收：计划时点到达后，推进到下一小时节点再核对状态。新事件会停止里程碑推进；应急插入卡依据现场状态给出下一项真实处置，不代替学生执行。一次推进最多93日。

运行一周后，实时经营诊断会选出到期履约最低的已到期货种，展示到期量、按时量与累计交付的口径差异，并指出实际超过80%的库场。集装箱诊断提醒核对T2铁路窗口与路径，不把“有接口”当成足够运能；学生需要根据实际证据比较政策，教学路线完成并不保证高履约。

请区分供电容量、接口与使用条件。现有规则中，基础供电接口已允许普通电动车投运；本路线选用真正依赖自动化等级的AGV展示配套等待。自动化项目不会增加供电容量，仍需数字岗位、供电、充电和共享资源。

教学进度使用独立的`port-enterprise-teaching/1`元数据保存在当前个人场次中，可切换自由经营后恢复，刷新和只读回放不改写经营规则。初次验证的时点、指令位置和事实证据单独保留，之后能回查当时的待投运状态。正式场次与考核场次不展示参考答案；可以另外创建独立教学练习。

学习报告为`port-enterprise-learning-report/1`，用于复盘，不是可恢复经营的JSON或正式成绩。恢复经营仍使用“导出存档”；跨电脑导入只恢复经营指令，教学知识回答和学习勾选不作为成绩或导入的可信凭据。原四类说明的计分规则保持不变，新增年度说明不加改原评分。

期末可能留有未完成或未恢复责任，必须如实保留并在说明中解释。到达经营期末后无法继续技术工作，不能为了教学完成而倒改原记录。教学路线的完成标记不等同于正式任务成绩。

## 建议的最后一周个人任务

学生担任独立的港口经营负责人，沿同一条经营时间线完成以下任务。教师可以设置三年或五年经营期，并依据课程进度调整观察点。

1. **接管诊断**：检查七个作业区的既有资产、瓶颈、班组、现金、接口和待处理业务，保存接管判断。
2. **资源与投资**：比较设备型号和保有方式，安排建设、培训、供能和维修；解释交期、施工占用与资金约束。
3. **运行与重排**：按小时、班次、生产日或季度推进，观察船舶与货物链条，处理资料退补、路径接续和共享资源竞争。
4. **风险与恢复**：根据实际发生的事件核查证据、控制范围、修复并确认恢复，比较备用与停工的经营代价。
5. **经营复盘**：完成约定经营期，核对利润、现金、债务、应收、终期义务和未完成货物；提交四类个人说明及其观察依据。

日常业务依据学生批准的策略执行。连续推进会在重要事件出现时暂停；输入表单或页面进入后台也会暂停连续推进。学生可以逐小时检查，或按较长步长观察长期后果。

## 教师发布与提交

本机教学平台入口为 `http://127.0.0.1:5173/`。从《港口管理概论》课程卡片进入“长期独立经营”，或在课程工作区选择“长期经营”；实验任务中心也提供同一入口。教师课堂“更多工具 → 课程资源”、学生课堂及独立阅读的“更多工具 → 个人经营”可以另开经营空间，当前课堂继续保留。

直接入口为 `/port-enterprise`，也提供独立的 `port-enterprise.html` 页面。教师在“任务与提交”公布个人任务，指定情境、种子、经营年数、截止时间、允许场次数及是否必须完成全部经营期。发布后保持初始条件固定；调整条件时另发任务。

学生登录后建立自己的正式场次。正式记录与自由练习分别保存，每个任务的场次数独立计算。要求提交的四类说明为“经营决策、设备投资、生产调度、异常与边界”，每类至少20字。文字检查确认完整性，教师仍需评价理由与证据的质量。

若学生需要用离线包或另一台电脑继续正式任务：

1. 在平台领取正式场次并导出 JSON。
2. 在离线包“存档与回放”导入该文件，保留任务初始条件与规则，继续经营。
3. 完成后导出，在平台导入，并在对应任务点击“关联当前导入记录”。只可关联自己尚未提交、条件与版本相同的场次。
4. 封存后点击“主动提交教师”。接收后由持久队列独立重放；网络中断可重试同一封存包。

教师可以查看个人结果、导出 CSV、打开核验通过记录进行只读复盘。长期经营核验结果计入平台“新提交”提醒，可以统一标记已读；学生“我的提交”显示自己的长期经营记录，并可直接打开对应任务与复盘。展示最近核验通过的场次，后续失败提交保留为记录。服务器重算成绩并核对状态摘要，不直接信任浏览器分数；重放核验不能证明远程作答者身份或替代监考。

本次按要求只接入本机教学平台，未更新校园服务器。本机使用现有登录身份、原数据目录和一键启动器；升级前已备份并校验历史课堂与旧实验数据库。后续发布校园服务器时须同时更新前端、API及 `enterprise-submission-worker.mjs`，并保留原数据库。学生离线包仍可独立运行；已有离线 JSON 可以导入教学平台，原浏览器存档继续保留。

## 模型边界与验收

2026年10月25日已在本机教学平台逐步操作完40步教学路线：三年1096日、36期月报、145条经营指令（含两次被正确拒绝的错误操作），16个事件全部确认恢复。已实际完成封存、JSON/CSV与学习报告下载、刷新恢复、只读回放至起点并返回期末，以及独立重放核对。诊断分93.28；集装箱到期履约49.9%，仍有478353TEU未完成，其他货种约99.5%—99.9%。这些结果用于教学瓶颈分析，参考方案不承诺最优绩效。

17项相关前端测试、11项长期经营核心测试、类型检查与生产构建通过。8217入口在屏蔽外网与API后可运行，实际请求仅为本机页面、CSS、主程序和工作线程；390像素布局、实际控件定位、全屏及模式切换草稿、教学进度恢复均已验证。单选框的最终实际尺寸为18×18像素。完整记录见`docs/verification/port-enterprise-teaching-2026-10-25.json`；学生包经干净解压校验13个有效载荷文件。

长期生产使用货批级、小时粒度的离散模型；设备与货物按有限能力和库存流转。三维场景展示业务状态，部分移动效果为示意动画。既有精细短期实验继续承担更细粒度的练习。

港区、规格数值、成本、交期、需求、风险、税率和监管时长均为公开的教学情境设定。模型未接入真实生产系统、实时AIS、真实监管回执或实际电网数据。

已完成核心业务测试、跨年长周期重放、身份与提交测试、生产模式核验工作线程测试、桌面与390px浏览器检查、三维与无WebGL回退、全屏连续性，以及从最终ZIP解压后屏蔽外网/API的运行验证。详细结果及全库其他课程未通过项见 `docs/verification/port-enterprise-2026-10-25.json`。
