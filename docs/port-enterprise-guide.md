# 东湾港长期经营：管理规则与游戏带教

东湾港是虚构教学港口。每人独立经营1、3、5或10年，界面默认10年，业务计算在自己电脑的浏览器工作线程运行。六类业务、设备购租、人员、建设、财务、市场、风险、回放与正式核验均保留。关闭页面不会继续推进经营时间。

## 本机启动与记录

完整解压分发包后运行 `Start-PortEnterprise.cmd`，无需另装Node、数据库、求解器或AI服务。Windows x64运行文件已包含在包内；启动器只在127.0.0.1提供程序文件，优先使用8217端口。重复启动复用同目录服务，`Stop-PortEnterprise.cmd`只结束本包服务。

存档属于当前浏览器和地址。清理浏览器数据、更换电脑、浏览器、目录或端口前，先导出完整经营JSON。导入另建记录，原件保留。月报CSV和带教足迹用于分析与复盘，不能替代经营JSON。

当前引擎为 `port-enterprise/5.0`。经营机制发生改变，不重算或迁移4.0及更早的长期记录；不兼容记录明确提示并保留原件。旧课堂六类分段实验继续使用原入口与原规则。

## 六个经营入口

港口场景始终是主界面，经营菜单、事件和报告呼出工作窗口。常用菜单为：

| 入口 | 管理内容 |
| --- | --- |
| 经营 | 巡港日程、实际岸桥分配、经营方针、自动授权、堆场与运输仓储政策 |
| 资源 | 班次保障、分批培训、设备购租、补能与维护 |
| 建设 | 能力核对、技术方案、工程、实施位置与信息协同 |
| 市场 | 报价、价格敏感度、增量业务与履约承诺 |
| 财务 | 现金保障、月度收支、借款、风险保障与重大事件 |
| 报告 | 按日折线、周报、完整统计、同条件试验与个人决策证据 |

存档、带教和正式任务单独作为工具入口。船舶、单证、货批、逐项处置等专业明细保留在查询与接管窗口中。日常无需逐船或逐批点击。

顶部提供六个常用菜单和“全部”入口，事件铃铛打开待办。打开工作窗口、编辑输入或切换浏览器标签页，会暂停连续经营。折线图只从“报告 → 经营趋势”打开，不常驻主界面。网页全屏和屏幕全屏是同一底部工具栏上的两个独立按钮，切换不重建计算线程、场景或草稿。

## 日常简报、每月现场日与重大异常

日常以3D港口和设备图层呈现经营概况，约1秒推进1天。每月8日00:00自动停下，进入24小时现场观察日，约1秒推进10分钟，一天约2分24秒；次日00:00停下并恢复日常简报。现场显示真实在港船舶与设备最近一个作业小时；日常动画表达过去24小时的业务流量，代表性流量船不冒充某一条真实船舶。

重大异常在发生小时暂停，要求核查影响和授权，修复获批后由部门继续执行；修复超过一天也不强迫一直使用慢速现场时钟。普通异常、常规靠泊、单证、采购与排修沿已批准策略执行。窗口里的专业接管保留，但不要求日常逐条船点击。

业务引擎仍按小时计算。现场每6秒完成一个真实小时结算，场景保持平滑渲染；界面不捏造每10分钟的独立财务数据。手动推进按钮同样遵守现场日边界、异常中断与财务停止条件。纯时钟运行十年约5小时47分，其中120个计划现场日约4小时48分，暂停决策与重大异常另计，适合分次课续玩。

场景可选原貌、设备负荷、岗位保障与当前健康。前两类统计来自每台设备最近24个已完成作业小时，未形成样本时标为无样本。缺人、缺电、缺油、补能、受阻、检修和故障是独立状态；待命可能是合理备用，不能只凭颜色判定浪费。点击实际设备查看状态时长与折合作业时长。低配电脑无法使用WebGL时，平面图仍提供实际设备着色和查询。

日报保存现金、定存、借款、应付、收入费用、用电、排放、工作时长等实际结果。报告中的折线可选30日、90日、一年或完整经营期，核对历史日期不会回退当前经营。等待指标使用当日离港船舶，履约使用当日到期业务，无样本保留缺口。完整经营期绘图保留抽样区间的真实高低点；事件线仅显示仍在最近事件窗口中的记录，不据此推断因果。

## 经营方针与自动执行

初始现金3200万元、借款2000万元，接管资产和库存单独计量。固定采用综合经营协议，公共资源费用为服务收入的2.5%；取消没有责任差异、只增加费用的日常经营制度切换。

四种方针是可检查的起点：稳健经营采用期限优先；履约优先保障合同相关资源；流转优先采用先到先服务；节能经营在同等期限下优先使用电动设备。现金保障统一由资金规则管理，不再由经营方针改写。选择方针不会覆盖已发布的班表、补能、堆场或运输政策。

调度按当前作业需求与船型匹配分配岗位和供电，闲置设备与不适配当前船型的岸桥保持待命；待命设备仍可按规则充电和维护。起重作业先为每个已具备装卸条件的泊位保障一台，再按剩余标准作业小时分配追加岗位；设备数量、合格岗位、供电、燃料及就绪货量共同约束分配。岗位不足以覆盖全部泊位时，综合到期时间和累计等待分配，避免长期饥饿。不能给尚未靠好、无可装卸货物的泊位虚占岗位。常规靠泊、有效资料提交、异常资料复核、采购及设备修复默认自动执行。普通中断可按常设修复或连续性规则处理；严重事件、污染、保安事项及授权不足仍需本人决定。人工接管保留在专业窗口中，关闭自动执行会产生相应人工待办。

## 客户、价格和承诺

报价影响后续价格敏感货源，已公布的价格保持不变。分货种需求响应采用 `exp(-弹性×情境敏感度×(报价系数-1))`，截在0.35至1.8之间。集装箱、干散货、液散、件杂货、滚装、客运的弹性分别为1.45、2.1、1.05、1.3、1.6、2.3；绿色情境敏感度乘0.8，增长情境乘1.15。客户稳定性还根据近期到期履约调整，未完成业务不能从履约分母消失。

合同按每次挂靠增加工作量，只为增量确定合同价格和违约责任，不把原有货源改成折扣合同。挂靠混合业务采用加权单价，合同完成量按实际交付比例分摊；这是本情境的批次抽象。承接本身不确认收入，回款通常在确认收入后的30日发生。

增长情境从第121日起、其他情境从第三年起，部分集装箱与散货船增至360米。集装箱吃水15.7米、横向24列；散货吃水14.7米。条件不足时自动记录未承接机会，不能把机会量计为实际吞吐或收入。已经签下的合同增量承诺仍保留，不能靠拒绝业务免除责任。

建设期间，新挂靠按公开可用条件分流；没有适配泊位时记录未承接机会。已进场库存和已有业务不凭空转移。岸线、水深及相应设备投资由此具有真实用途，也需要承担施工损失与回收周期。

## 能力、设备和建设

能力核对板按作业区展示岸边、运输、堆场和闸口的设备上限估算，用于寻找优先核对的环节。实际执行还受合格岗位、健康、风况、距离、共享电力、堆垛及运输窗口约束，不能把上限估算当作实际吞吐预测。

设备保留购置、租赁、交期、接口、调拨、折旧与退出责任。租赁从原交付日起计费，首月预付抵扣实际租金。自动化工程只提供接口，AGV和智能闸口需要另行采购及合格人员；闲置设备不会自动带来收益。

日常维护只提供按健康与工时、优先夜间两种有效安排；原“提前维护”在本版故障机制中没有额外可靠性收益，已撤出常规选项，仅保留引擎负面对照参数。维修分为预防维护和故障后自动排修，均消耗技术人员、备件与真实停机时间。大修费用和停机更多，会恢复电池状态并延长剩余使用年限；不增加既有账面价值。

工程在下单前检查位置、货种、在建项目和有效等级：已具备的单次接口不能重复购买；自动化、防洪、保安等达到有效等级后不再收取无收益投资。协同平台最多5级，供电、光伏、流线和扩容也有对应有效上限。经营期内不能投产的工程不开放。

## 堆场与仓储

两个集装箱作业区各有10个区块，每区块用5组并行批次堆垛表示，物理上限4层。入场上限为2或3层时，剩余物理层可供真实临时翻箱使用；翻箱仍需空位、作业能力和费用，不能超过4层。进口、出口和共享比例按10%调整。已有库存不因改规则而瞬间搬走。

分类与货位分配分别决定：入场顺序、预计周转ABC或航次归组；固定分区、共享缓冲或动态货位。ABC按公开交付期限分类：24小时内为A、48小时内为B，其余为C。信息协同投产后，周转估计误差从约±12小时缩至±4小时，不读取隐藏未来。

提取下层货物需有真实空位、场桥及必要运输能力，实际翻箱按55元/TEU次计费。动态货位、ABC或更高堆高不保证所有业务下更优。

部分集装箱和件杂货进口批次具有公开预约提货时间。普通库场也需等待预约；具备监管仓储接口并启用相应政策后，可以承接仓储服务。仅在约定时段按真实在库量计费：集装箱2元/TEU小时、件杂货1元/吨小时；设施每日运维600元。预约到期自动结束留置，再核对独立放行与接续条件，不需要逐批点击出区。

## 水陆接续

公路有按需通行、预约保障和高峰增援三档。对应日固定费用为0、800、2600元，实际交接单价为32、24、21元/本货种单位。基本小时容量为集装箱20 TEU、干散货100吨、件杂货30吨、滚装30辆、客运80人；预约与增援分别为基本容量的2倍和4倍。液散使用专用管道。

更高道路保障不会创造闸口、人员或设备能力。低负荷下固定费用可能浪费，高负荷下增援可以减少等待。

液散只展示专用管道说明，未接铁路的区域不开放无效铁路选择。其余作业区可设置公路优先、按公开窗口及已公布货量平衡、铁路优先或驳船优先。平衡策略还检查当日已分配铁路货量，超过600单位的后续批次改走公路；铁路未接入时自动回到公路，避免新货批被分配到不存在的接口。已集结和已进场货物保持原路径，调整会产生真实移位及费用。

铁路、驳船各按每日窗口接续，作业区内进出口共享窗口容量，分别为600、500个本货种单位；进口集结区容量也分别为600、500。进口实际发运单价为铁路15元、驳船12元；出口仍需真实进闸和作业。窗口是否匹配船期和交付期限，会影响等待、交付及费用。

## 人员、能源与补给

三班均衡、日班加强和后备保障保持人员总量、技能、工资及培训历史。夜间00—06时、22—24时工资上浮25%；后备待命工资为基本工资的110%。缺勤及培训造成缺口时，后备池按规则补位，日可用工时按人数、技能和8小时计算；重新点班表不能凭空创造人员工时。

培训可以只选一个班组中的部分人员，每人2200元、7日。只有本批退出生产，其余人员保留班次。新招聘仍需完成入岗培训。

电价为22—06时0.46元/kWh、06—17时0.82元、17—22时1.18元。低电量、错峰轮充、谷时优先分别影响可用车辆和补能时点；低电量与危险设备不等待普通时窗。充电桩、供电、电池和可用车保障共同约束执行。光伏只提供天气相关的日间发电，本情境不模拟夜间储能放电。

常规补给提供标准保障（7日燃料、12份备件）和韧性保障（14日燃料、24份备件）。低于目标一半时自动下单，遵守现金底线；燃料通常1日、备件2日到货，供应受阻会延期。在途物资保留资产价值，不能提前用于生产。库存按价值每日0.03%计保管与占用费用，关闭自动采购也不能免除该费用。

3日燃料与6份备件保留用于受控教学反例，不作为当前港口规模下的日常可选推荐。对照结果中的极低库存不等于低成本经营。

## 风险与财务

风险保障92元/小时，事故直接损失赔付70%，30日回款；停工和货源流失不赔。应收赔付先确认收入，回款时不重复确认。普通情境可以比较自担风险和购买保障，高风险情境仍需检验是否适合自己的资金与恢复能力，不能以一次无事故推断最优。

严重事件增加直接损失、技术工期与备用费用。批准方案与累计上限后，系统核查、隔离、排修并在技术完成后恢复。连续性方案只适用于供电和系统中断，不能绕过污染、积水或保安限制。预算超限或现金不足会再次请求决定，已发生费用不退回。

现金、利润、资产、应收、库存、在途物资、债务与后续合同义务分别计算。财务诊断按经营时长及净资产增长逐步计分，避免很早封顶后价格和浪费行为不再影响判断。四类决策文字只核验完整性，不声称自动评价了文字质量。

## 前半年游戏带教7

带教另建10年个人练习，不覆盖原场次或正式考核。从2027年1月1日至7月1日，共181日、4344小时、43项任务。无需阅读章节或写复盘才能继续。

每次只开放当前按钮、字段或选择表单。鼠标动画示范真实位置，金色边框闪烁；选择步骤示范先选方案、再发布。其他经营点击、焦点和快捷键被锁定，退出、重播与全屏始终可用。

- 一月：批准接管规则与固定资金方案，核对贷款还款表及巡港日历；运行首周，亲历现场日，点击设备负荷、真实交付和能力板，核对实际岸桥分配；选择道路保障，设置堆场分区与分类，核对月报、按日趋势、真实利息到账及90日现金预测。
- 二月：订购电动车与信息协同，批准日常自动授权，选择班表，安排维护。
- 三月：等车辆真实交付，检查投运条件，亲自选择补能策略，再等待协同工程验收。
- 四月：检查信息改善，调整经营重点，选择报价，承接增量合同；在流线和库场改造之间作出选择。
- 五月：核对合同实际履约，为已有铁路的T2选择分流政策，等待所选工程按自己的工期完成。
- 六月：检查改造成果与第六份月报，确认资金权限交接，接管同一座港口的余下经营。

重大异常会插入当前任务；常规事件按已授权规则执行。不同允许方案都能推进带教，但会留下各自的费用、产能、交付和风险后果。失败指令不完成任务，默认字段也不能替代学生亲自发布决定。

退出和刷新保留经营进度与未提交字段。未额外推进时间时可以继续原带教；若自由经营已改变时间或记录已封存，应另开带教。结业不自动封存、不免除未完成业务，也不赠送虚构现金。完整记录、带教足迹和月报可分别导出。

正式任务保留个人身份、任务条件、幂等领取和封存提交。平台独立重放相同版本的完整指令，核对业务状态哈希及成绩；正式场次以核验回执为准。原有任务在规则不匹配时归档，不能用新版引擎重新计算旧成绩。

## 4.0资金管理与经营失败

资金窗口只需设置现金保障15／30／60日、闲置资金保留活期或30／90日定存、自动周转授信0／500／1000万元。现金保留阈值每日按现有基础费用估算更新，不能从生产参数另改一套金额。

- 活期年利率0.3%，30日定存1.5%，90日定存2.0%，均为教学参数。借款与非本金欠款先扣除，只有剩余自有流动资金参与计息；新增借款前必须取回定存。定存本金不是收入，到期收益才入账；提前取回放弃未入账利息。
- 初始2000万元项目贷款分36期还本。项目贷款12／24／36期、年利率6.5%，另一次性0.5%手续费；周转贷款3期、年利率7.5%，不收开办费、到期一次还本。每期30日；与财务日历月报分别显示。所有贷款按真实模拟小时占用计息，每30日付息。提前还本须结清已计提利息，不能靠月末还款抹掉整月资金成本。
- 到期款自动按工资、能源、事故责任、利息、本金等顺序偿付，必要时先提前取回定存。经批准的周转授信只覆盖实际到期缺口，按10万元档提用，既受学生设定上限也受资产融资额度约束；不能为任意新投资无限垫款。自动提款共用一条授信账户，以首次提款起算90日期限；追加提款不会延长到期日，也不自动替到期本金续借。
- 现金不足的部分形成逐项应付款，保留原始到期时间，不把现金扣成负数。欠款的后续偿付不再次确认为费用；应付本金已包含在未还借款中，净资产不重复扣除。
