# 学生端课堂活动：50–100 人试课版

本次在已有学生课堂 `/join/:sessionId` 上补齐活动能力。课件、地球仪及个人港口仿真继续使用原有课堂入口；活动面板独立于课件画布，两门课程均可使用。

## 课堂怎么用

教师现在可以在“课程工作区 → 管理习题与活动”提前备课。题库按课程保存，支持新建、编辑、复制、归档恢复，以及按讲次、题组、分类筛选；编辑排序号可调整发布顺序。课堂中的“习题库与发布”使用同一份题库，逐题发布。《港口管理概论》已预置覆盖整讲90分钟的12项活动，详见[第一讲课堂活动发布单](./course/港口管理概论-第一讲-课堂活动发布单.md)。

“学生分组”支持对在线学生按目标人数随机均衡分组，也可指定学生手动调组。晚加入者默认未分组。讨论后每位学生仍分别作答，教师查看各组参与人数；为保留统计口径，需先收起当前活动再调组。

1. 教师进入正在进行的课堂，点击“学生互动”。经济数学点击“课堂活动”。全屏时，角落快捷栏也有“课堂活动”按钮。
2. 点击“邀请”复制学生链接，也可从活动面板的“学生加入链接”输入框选中复制。学生打开链接，填写老师能够认出的姓名并点击“加入活动”。教师预览不能提交学生答案。
3. 教师查看在线名单，随机点名或点击指定学生旁的“点名”。默认随机点名避开已点过的同学。被点名者点击“我在，准备回答”，教师会收到回应确认。
4. 输入选择题，设置单选或多选、2–6 个选项。勾选参考答案；不勾选任何答案即为观点投票。讲解内容在公布结果后对学生显示。
5. 点击“发布题目”。学生确认提交后不可改答；重复请求不会增加人数。教师可查看提交人数、选项统计以及名单中的回应状态。
6. “结束收题”停止接收新答案，但仍隐藏参考答案和统计。“公布结果”同时停止收题，并向全体学生展示统计、参考答案和讲解。“收起活动”结束并移除当前活动卡片，记录仍保留。

一次只开放一项活动。结束当前项后，可以发起下一题或点名；活动历史保留在教师面板中。关闭面板可继续讲课，当前页面内未发布的题目草稿会保留。刷新教师页面会清空未发布草稿，已发布活动仍保留。

学生刷新或短暂断线后，使用相同身份会恢复已提交记录。若服务器已经收到答案但响应在网络中丢失，学生端会重新读取服务器记录。实时连接不可用时，每 5 秒读取一次最新状态。在线人数按最近的连接/心跳计算，断开后约 45 秒转为离线。

## 教室局域网访问

学生设备需要能够访问运行系统的电脑。现有默认开发命令只监听 `127.0.0.1`，其他设备不能访问这个地址。

如果 API 已在默认 4300 端口运行，可在一个新的 PowerShell 终端用不同前端端口启动局域网入口，避免与原有 5173 服务冲突：

```powershell
Set-Location D:\codes\edu-sys
$env:EDU_WEB_PORT = '5178'
$env:EDU_API_PROXY_URL = 'http://127.0.0.1:4300'
pnpm --filter @edu/teacher-web exec vite --host 0.0.0.0
```

用 `ipconfig` 查看授课电脑的局域网 IPv4 地址。教师也通过 `http://该IPv4地址:5178` 打开课堂，再复制学生链接；这样链接里的主机地址才是学生能够访问的地址。手机和电脑应在能够互访的网络中，系统防火墙需允许该前端端口。API 仍通过前端代理访问，无需另外公开 4300 端口。

普通 HTTP 局域网不保证提供剪贴板 API，面板保留了可手动复制的链接。活动请求编号不依赖仅在安全上下文可用的 `crypto.randomUUID()`。

## 数据与身份边界

- 活动使用独立 SQLite WAL 文件：`${EDU_DATA_FILE}.participation.sqlite`。默认位于 `.runtime/platform-api/state.json.participation.sqlite`。每个答案是小事务写入，不重写课程 JSON。
- 答案以“活动 ID + 服务端学生身份 ID”唯一约束，收题和提交在同一服务进程内按事务顺序执行。重试已成功提交的相同答案仍成功，不接受更改答案。
- 新活动接口要求已登录身份；教师才能发布、点名、收题和公布结果。学生不能提交别人的身份、替被点名者确认、发起活动或结束课堂。
- 学生的 HTTP 和 SSE 内容在服务端分别生成。公布前不发送正确答案、讲解、统计、其他学生答案或教师名单；学生始终只能看到自己的提交记录。
- 现有开发身份允许自行选择角色，姓名也不是学校实名认证。本功能适合当前受控试课；正式身份仍应由现有外部身份适配器提供，不能把开发角色入口作为正式权限边界。
- 开发身份令牌暂存在 API 进程内，API 重启后需要重新加入。原活动和答案仍保存在 SQLite 中，但新开发身份不会自动认领旧答案。使用提供稳定学生 ID 的外部身份时，可按原身份恢复。浏览器刷新和短暂断网不会重新生成身份。
- 本次并发范围是单 API 进程、单本地 SQLite 文件。尚未实现多 API 副本之间的活动广播和在线状态共享。

## 验证与复现

```powershell
pnpm test:classroom-load
pnpm --filter @edu/platform-api exec tsx --test test/classroom-participation.test.ts
pnpm test
pnpm build
git diff --check
```

并发脚本创建独立临时数据和 100 个独立身份，建立 100 条学生活动 SSE、100 条学生课件 SSE 加 1 条教师活动 SSE，共 201 条实时连接。它同时发送 100 份答案、100 个心跳和教师翻页事件，再重复提交 100 次答案，检查课件同步、准确计数、未公布内容保密、公布广播、重新连接和点名回执。结束后关闭连接并移除自身临时数据。

验收结果和截图位于 `output/classroom-participation-review/`。本机结果不代表校园无线网络质量，也未计入数字人音视频、GPU 推理或多服务器部署的容量。
