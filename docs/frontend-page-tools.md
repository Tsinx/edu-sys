# 教学前端：统一工具栏与页面工具接口

本文件是修改课堂、独立课件、全屏、数字人、地球仪或实验控件之前的必读约定。
目标是保留课程现有功能，让一个教学界面始终由课堂外壳提供一条底部工具栏。

## 职责

1. **课堂外壳**负责导航、工具栏、弹出面板、通用课堂操作、布局和权限。
2. **课程页面**负责1600×1000教学画布，并通过 `PageTools` 注册当前页的操作、面板与状态。
3. **现有控制器**继续负责语音、收音、动画、视频、参数计算、揭示与课堂同步。
   工具栏只调用控制器，不另建一份播放或实验状态。

普通和全屏模式使用同一工具栏实例及同一课程组件树。全屏不得卸载语音输入、丢失草稿、
重新创建地球仪或重启视频。参数与揭示仍走现有同步通道；历史课件版本不自动迁移。

已识别的经济数学历史版本应明确显示“已归档”，不能提示用户反复刷新来切换版本。
教师可另开使用当前课件的新课堂，从所选讲次首页开始；学生只获得新版阅读入口和
等待教师新课堂链接的说明。“开始／继续课堂”只续接课件版本兼容的经济数学课堂，
不得改写旧课堂的版本、页码、实验状态或结束状态。未知版本仍按同步问题处理。

### 两种全屏

- **网页全屏**只铺满浏览器窗口、收起外围布局，地址栏仍在；不调用浏览器全屏API。
- **屏幕全屏**由按钮的真实用户点击直接调用 `requestFullscreen()`，隐藏浏览器栏。
  以 `fullscreenchange` 和当前目标元素确认状态，拒绝请求时明确提示，不自动转为网页全屏。
- 两个按钮在同一底部工具栏中，使用独立图标、名称和按下状态；窄屏仍可操作。
  原有“纯画面投影”收入“更多”，用于只显示公开画面的投影工作流。
- 从网页全屏进入屏幕全屏后，退出屏幕全屏回到网页全屏；再按Esc或退出网页全屏恢复普通布局。
  屏幕全屏期间网页全屏按钮禁用，避免混淆两层退出。网页全屏中弹出面板优先处理Esc；
  屏幕全屏的Esc退出遵循浏览器原生行为。
- 使用共享 `usePresentationFullscreen` 与 `FullscreenButtons`；课堂翻页仍由
  `useClassroomFullscreen` 承接。独立经济数学课件、序章和课程预览同样使用两个按钮。
  两种模式均保持同一工具栏、控制器与草稿，不改变教学权限。

## PageTools 接口

入口：`apps/teacher-web/src/features/classroom/PageTools.tsx`。

- `PageToolsProvider`：外壳提供当前 `pageKey`、角色和是否由课堂数字人承接语音。
- `usePageTools`：控制器注册 `PageToolsDefinition`，并取得关闭面板等稳定的外壳操作。
- `PageToolsContribution`：已有复杂控件可作为面板内容接入；仍可提供直接操作。
- `PresentationToolbar`：统一呈现导航、主要页面操作、课堂操作、“更多”和全屏按钮。

定义包含 `pageKey`、带稳定 `id` 的 `actions`、`panels` 和可选 `status`。
操作可以执行回调或打开指定面板；面板包含标题和本地 React 内容。
`area` 区分页面操作和通用操作；`priority` 决定直接显示或收入更多面板。
`audience` 限定教师或本机可用操作。默认只有教师可以使用课程控制。
接口不接受远程脚本、任意HTML，也不承载讲稿、作者元数据或隐藏答案。

注册由组件生命周期管理。外壳只显示当前 `pageKey` 对应的定义，页面切换立即隔离旧工具，
卸载时撤销注册。使用两组上下文分别处理注册和显示，避免控件更新反复重渲染课程控制器。
注册模块不导入CSS，由工具栏或外壳入口导入 `page-tools.css`，保证SSR与控制器测试仍可直接引用。
滑块松开、按键结束、失焦时的同步提交监听放在同时包含画布和工具栏的外壳上，避免面板移出
画布容器后丢失原有提交时机。

## 布局与交互

工具栏分为课程导航、当前页操作、通用课堂操作三个区域。
直接显示主要操作；时间轴、多变量滑块、声音选项等放在工具栏上方的面板中。
同一时刻只有一个面板展开；翻页关闭旧面板，输入草稿保存在控制器中。
少量按钮使用统一图标、字号、44px触控区域、禁用态和焦点样式。
窄屏收纳次要操作，操作区可横向滚动，全屏按钮保持可达，不另起第二行。
翻页位置优先稳定；讲次、学时和长页面列表收入“更多”。不同课程的既有样式不得覆盖统一
工具栏中的导航、按钮或面板。独立阅读外壳也把工具栏放在可视区域底部。

数字人逐页讲解、教师原文播报和问助教是不同操作。课堂的“教师发言”打开现有输入组件的
文字播报模式；讲解页使用原有页面讲稿。音量沿用共享设置，最高500%。
收起数字人仍保留当前播放的停止操作和必要的收音控制。

学生跟随课堂时不注册教师操作；本机音量等操作须显式标记为本机可用。
学生独立浏览只获得原先允许的操作。纯投影隐藏工具栏，保持公开画布内容。
前端可见性不能代替服务端对课堂事件的权限检查。

## 接入范例

- 经济数学讲解：展开下一步、讲解/暂停/继续、停止；设置为面板。
- 参数实验：实验参数面板中的中文变量、单位、范围与重置；继续使用原有模型与同步。
- 港口地球仪：播放、恢复视角等主要操作；镜头、进度、路线和图层放入面板。
- 短片：播放/暂停为直接操作，进度、声音和重播收入面板。
- 普通静态页面：无需注册空工具，不显示无功能的“本页工具”。

其他入口没有外壳时，已有控件允许独立呈现；建立外壳后应使用同一个接口。
旧版 `ClassroomPlaybackSlot` 和 `ClassroomFullscreenControls` 已退役。
港口资源入口也由课程适配器注册，课堂外壳不按讲次拼接专属控制栏。
港口仿真的运行控制接入面板；仿真中的业务表单、三维设施操作和学生任务继续留在仿真应用内。
统计分析、管理学、各港口讲次和地球仪预览均使用同一外壳接口。

## 迁移和验收

先验证经济数学讲解页、参数实验页和港口地球仪页，再迁移港口动画、历史短片、管理学
演示与其他页面。保护其他课程的既有修改；本次不改课程版本、数学内容或服务端同步协议。

检查一条工具栏、工具随页切换、揭示与参数同步、返回页面恢复、教师/学生权限；
播放或输入时切换全屏，确认控制器与草稿连续；检查桌面、窄屏、真实全屏、输入快捷键。
完成相关测试、类型检查、生产构建和 `git diff --check`，再核对 localhost 当前服务。

本地浏览器验证不能代替实际投影、音响、网络和课堂节奏的试讲验收。
