# 第三、第四讲：从数列理解极限

更新日期：2026-10-11。第三讲72页（36+36），第四讲58页（30+28）；每讲两个45分钟，全部页面进入课堂主线。页内累积揭示单独计数。

## 教学主线

第二讲的商家在80元达到最大利润，但左右调价的损失不对称。第三讲先追问高中导数公式：分母不能取零，极限怎样给出确定结果？将同一疑问缩到平方函数差商，保留h≠0，嵌入原三分钟“微积分基础之争”影片，再沿h=1/n进入数列。数列以整数编号为输入，用离散点观察；误差1/n比“越来越接近”的口号更易核验。

先谈“没有最后一项”，区分潜无穷的过程与实无穷的整体观念。正整数趋向无穷并不是走到一个名叫无穷的实数，极限也不要求各项永远不等于目标。历史讨论不替代现代定义。

从误差0.02求第51项，再把误差要求推广为任意ε。中文解释整数门槛N和所有尾项，解释∀、∃以及向上取整，最后给出ε–N定义。先讲清规则，再安排基础辨认、门槛证明及反馈。第二课时用固定ε挑战错误候选2.001，明确“否定候选值”与“数列发散”的区别，然后解释有界、正负无穷及无界振荡。

扩容模型将抽象尾部保证变成履约期限。最后回到同一个Q(h)=2+h：数列只取一条输入路径，函数定义必须覆盖全部足够近的合法非中心输入。正弦反例的两条精确路径引出δ，先作中文对应，再给出ε–δ和完整证明。回到80元处的两个方向，为第四讲留下可计算的问题。

第四讲兑现这一问题：利润与差商是不同对象；两侧差商极限分别360与−160，因此80元虽最优却无导数。再用采购合同门槛理解单侧极限和实际定义域。极限运算法则先明确条件，精确约分与有理化之后才练习。后半讲区分有限采购范围与理想延伸，区分输入规模和输出高度，再以本批总成本而非极限单价作决策。

## 概念和习题的顺序

概念建立采用“同一个情境 → 看见变化 → 量化误差 → 中文保证 → 数学定义”，保持题设和已完成结果。每个正式概念、符号首次出现先解释，再标注英文。对数、向上取整、单调和有界均在使用前解释；不使用未介绍的聚点、去心邻域、上确界等术语。

基础层能区分收敛、达到极限、有界及正负方向；巩固层能写出N或δ并证明统一保证；深入层能写出固定挑战下的任意晚反例，或在模型条件内作采购判断。深入题不抢在定义之前；基础反馈也完整给出理由，而不只报字母答案。

## 模型、图形与边界

商家：需求D(p)=1200−10p，日能力400件，佣金10%，单位成本20元，固定成本2000元；连续近似范围30≤p≤100，实际价格为0.5元网格。利润为360p−10000（p≤80）及−9p²+1280p−26000（p>80）。差商保留（元/日）/（元/件）的解释，不能读成销量。

扩容：K₀=400，Kₙ₊₁=Kₙ+0.2(500−Kₙ)，故Kₙ=500−100(0.8)ⁿ。模型是给定实施规则，有限周不会精确达到500；第8周约483.22，第10周约489.26，第11周约491.41。至少490与误差严格小于10分别按不等号核验。

合同A：固定费5000元，q<500时单价20元，达到500后整批18元；实际q为正整数且最多10000。合同B：固定费7000元，单价17元，共同范围500≤q≤10000。相等批量2000件；1500件时A为32000元、B为32500元。无上限平均成本的极限18与17是理想延伸下的结果，不能替代有限批量预算。额外采购需库存、资金、损耗、未来用途条件；加入h(q−1500)后，在本批固定需求且无未来收益的简单扩展中，多买不会减少总费用。

数列只画离散点。放大实验将误差除以ε，支持15级十进制精度及对应尾部编号，避免把小误差四舍五入成零；错误候选可在更窄误差带下暴露。全尾保证来自解析式，不从18个可见点推断。软件精度有限，任意精度由定义和证明表达。

函数实验用h/ε与(Q−2)/ε坐标，误差直接由h计算；实际ε在公开读数中保留。静态图、动画和实验共用核验后的模型，越出图窗的点用箭头明确标识，非比例标注明确说明。
