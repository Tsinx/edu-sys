## 第16讲：案例讨论与投资选择

从五组案例任选一个，先解释它面对的具体问题，再说明措施怎样发挥作用：

- 天津港：电动设备为什么需要风光、储能与生产调度共同配套？夜班与白班的能源安排有什么不同？
- 鹿特丹：230米电缆沟与移动连接车解决了什么空间问题？更多设施推广后，电网为何可能成为约束？
- 黄骅港：为什么抑尘以后，还需要含煤水处理、调蓄与循环？只买洒水设备会漏掉哪一段？
- 重庆果园港：船随水位改变位置，怎样影响岸电与污染物接收？一批汽摩零部件改走铁海联运，为什么仍要考虑短驳、换装和船期？
- 洛杉矶港：为什么颗粒物与GHG的改善幅度不同？业务量增长19%、GHG增长8%时，单位效率与总量应分别怎样解释？
