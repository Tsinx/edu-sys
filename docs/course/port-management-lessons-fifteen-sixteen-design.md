# 第15—16讲建设安排

2026-10-21。两讲各32页、90分钟、1600×1000画布。接在第14讲之后，课程内页码622—653、654—685。前14讲页码与标识不变。

第15讲《智慧港口与数字协同》围绕一票新货A2展开：系统“完成”的对象不同，源事件与接收时刻不同，信息进入岗位行动还存在接口。承接第13讲的交付条件和第14讲的库存、分拨需求，不再重复申报与保税制度。前半讲以双时间轴和三情境演示解释信息延迟及约束迁移，最后写一条可执行交接规则。后半讲比较青岛沿海自动化、果园港监管数据协同与无人集卡混行，讨论人员、预测、数字孪生、成本、试点和评价。变化卡要求学生修订原来的原因判断。第12讲的应急中断与恢复步骤不在本讲重复。

第16讲《绿色港口与可持续转型》以天津港、鹿特丹、黄骅港、重庆果园港、洛杉矶港五组案例贯穿。学生先进入夜间靠泊的具体场景，再通过能源、连接工程、煤水循环、内河水位和运输接续理解不同改造的原因与运行机制。保留企业边界、总量与强度、岸电能源比较和预算组合计算，将其放进案例中的实际取舍。最后27分钟比较投资、讨论使用不足、回顾五港差异，并把数字协同和岸电放回一个靠泊日，为第17讲等待过程自然铺垫。

2026-10-23重构：12页采用逐段解释与独立过程图，加入白夜班能源关系、高低水位切换、六台集卡补能、船岸连接、煤水闭环、收益分配等。来源说明保留在紧凑页脚及教师材料，学生任务从反复填写核查字段改为解释案例、比较代价和回应另一种方案。32页、90分钟、原页码和片头保持不变。

## 教学计算

数据协同模型明确“业务条件发生”与“调度收到”。统一共享延迟从90降为5分钟后，车辆仍在10:00到位，交付只提前30分钟。提前派车是另一项独立改变。变化卡独立替代原接收假设，不与基准同时成立。

岸电模型为相同120kW服务负荷，分别比较5小时与2小时。柴油0.27L/kWh、3.1kg CO₂/L，电力0.55或0.85kg CO₂/kWh；均为自编教学系数。柴油只含燃烧、电力计入发电，暂不列转换损失，不称完整生命周期核算。费用不含设施投资与其他成本。环境总量与强度采用同边界实体箱口径，CO₂不混称CO₂e。

综合项目预算420万元、年度减CO₂目标200吨。D/S/E的初始投入120/220/300万元，年节约45/30/70、持续支出15/10/25万元，年减60/180/240吨。假设效果独立，不重复计量。DS与DE均满足给定数字条件，仍需比较服务适配和实施风险。变化卡S的使用、节约和减排减半，持续支出10万元不变，DS年净节约变35万元、减排150吨。现金回收仅为静态筛选，不取代完整投资分析。
