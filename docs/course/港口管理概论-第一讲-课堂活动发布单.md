# 港口管理概论 · 第一讲课堂活动发布单

配合“英国如何把贸易变成影响力？”第一讲第1—47页，净教学90分钟。前后两节各45分钟，课间另计。本单为初始备课建议，可在教师题库中继续编辑；不要求冻结课件或习题。

## 课前与课堂入口

课前：课程工作区 → **管理习题与活动**。已预置12项，分为“第一节 · 从下注到计算”和“第二节 · 从网络到港口”，其中10项主线活动、2项可选加问。可编辑题目、答案、讲解、分类、题组、顺序、页码、建议时间和教师提示；也可复制、归档和恢复。

课中：学生互动 → **习题库与发布** → 预览 → **发布这道题**。全屏时通过角落的课堂活动按钮进入。系统逐题发布，不会按计时自动跳页、自动发布下一题或自动收题；建议秒数供教师根据现场掌握。

学生通过链接填写姓名加入。课前或一项活动收起后，在“学生分组”中按每组4人随机均衡分组，必要时手动调到4—6人。50—100人的课堂不要求每组都上台：每个重点环节听两种不同解释即可。组内讨论后每人独立提交，教师能看到各组参与人数；该人数不是小组得分。

## 三个重点环节的组织方式

**P09：先判断证据，再听数字人。** 同桌一人做验货人，一人做出资人，各说一项清单还不能确认的事。先让全体提交，教师点一组说明选择，再请数字人只指出缺失记录。若把“10,200件”推成全年消费或最终销量，请学生指出缺少的统计总体或后续业务节点。

**P22：让答案带着计算过程。** 每组安排劳动日核验、丝产量核验、粮产量核验和反例检查。前60秒独立计算，后30秒核对，每人提交。正确方案是江南70日产丝、30日产粮，湖广100日产粮；各地100日约束不变。若选了其他方案，不只报对错，先检查是否满足70匹，再比较粮食总量。数字人在这90秒内不报答案。

**P45：判断必须带条件。** A为30±1天，B为18±8天，均为教学设定，未给概率分布和完整成本。组内需留下“选择—依据—缺少的信息”三项，再各自投票。较稳定不自动等于总成本更低；如果把±暂按边界理解，B的26天仍早于A的29天，因此不能仅凭窗口较窄宣布A对所有任务更好。数字人只补一项决策条件，不替教师宣布唯一最优方案。

## 数字人怎么配合

题目卡片的“预览选项、答案与授课提示”内，已保存教师接话和数字人提示。P09、P18、P31、P45对应原逐字稿的四次短互动。教师可选中提示文本复制到助教输入栏；提示不会自动发送，系统也不会假定数字人看见了纸张或听见了全班。

先收题，再请数字人提示，再由学生解释和教师公布结果。数字人未连接或等待过长时，直接使用原逐字稿的示范回应，活动照常进行。

## 留下什么、怎样调整

选择题保存个人选项，教师查看答题统计和参与情况。开场与回看分别保留为两次投票；系统没有自动把两轮配成个人变化报告，课堂上仍通过原先保留的纸面理由对照。

离堂反馈只采集选项，纸面三句话和具体疑问仍按原稿收取，系统不声称已经采集或自动评分这些文字。题库可以在试课后继续修改：例如机会成本误解集中，就延长P18；网络解释已经充分，就略过两项加问；决策条件不清，就把P45的讨论留足。

已发布题目保持与本次答案相对应；题库修改用于下一次发布。同一题需要再问一次时，先结束当前活动，再点“再次发布”，会产生一项新的课堂活动。
