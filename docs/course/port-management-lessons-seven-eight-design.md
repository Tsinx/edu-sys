# 港口管理概论 · 第7—8讲建设说明

版本：`release-port-management-cargo-planning-v13`。本轮在前6讲293页之后追加96页，原有页序与页键保持不变。第7讲全局294—341页，第8讲342—389页；各48页、90分钟，第24页后课间。第9—16讲仍待建设。

## 课程主线与学习成果

第7讲“货种改变，港口为什么必须跟着改变？”承接第3讲货种识别、第4讲完成条件、第5讲瓶颈和第6讲交付链。由三艘不同货物的来船进入，沿“货物属性—移动方式—设施配置—约束与交付”逐步解释干散货、粮食、液体散货、液化气、滚装、重大件、冷藏箱和客运。重点在工艺适配与条件推理，不重复一轮设备图片识别。

- 知识：辨认典型货物形态、船岸接口、暂存与陆侧接续；区分运输单元、温控要求、危险属性等交叉维度。
- 分析：解释专用配套、下游接收、品质保护与瓶颈迁移。
- 应用：针对给定货物提出初步工艺链，列出适用条件和关键资料缺口。

第8讲“港口如何演进，又该建在哪里、建多大？”从旧港与新港的并存出发，以能力扩展解释港口历史，再进入港城空间关系、候选区位、需求情境、能力规模与分期决策。

- 知识：理解一至五代港口的分析视角、港城紧邻／分离／再连接，以及需求、能力和产出的区别。
- 分析：联合观察海向、陆向、土地、生态、城市和实施条件，区分硬约束、未知条件和可补救事项。
- 应用：比较多需求条件下的能力缺口与余量，写出带证据、前提和触发条件的分期建议。

## 第4／5代港口与港城关系的明确位置

| 内容 | 第8讲页码 | 处理方式 |
|---|---|---|
| 能力演化框架与时期边界 | 4—6 | 由驱动力到框架，不机械按年份分类 |
| 第一代：海陆转换 | 7—8 | 港口与早期仓储、交易的邻近关系 |
| 第二代：工业增值 | 9—10 | 原料、码头与工业链联系 |
| 第三代：物流组织 | 11—12 | 区分仓库资产与供应链组织能力 |
| 第四代：网络整合 | 13—15 | 横向与纵向联系；自动化不构成单独判据 |
| 第五代：客户与社区导向 | 16—18 | 注明采用的研究框架，不称为统一认证或最高等级 |
| 港城演变与空间更新 | 19—24 | 三阶段示意、大士港与南部滨水规划、影响转移问题 |
| 港城条件进入规划 | 25—30、43—46 | 社区、交通、公共空间和过渡期纳入方案 |

第五代依据PEMP对UNCTAD及Flynn、Lee、Notteboom等研究的整理，采用客户与所在社区导向解释。不同研究的术语和分期存在差异，各代能力可并存。港城空间演变与港口代际是两条相关的分析线，不能把外迁直接当成代际升级。

## 视觉与课堂组织

保持1600×1000逻辑画布。以深蓝绿色、纸色和赭色形成工艺图册风格，沿用已有港口教学复原素材，配以新的代码原生SVG工艺图、停车区俯视图、冷藏箱配套图、港城空间图、候选址图、数量图和分期对照图。示意图不按工程比例，照片式插图注明教学复原。

课件正文逐页编写。教师讲稿与助手边界分别保存在 `teachingCue`、`assistantCue`；投影和学生画布不输出这些字段，也不输出作者页键与编排属性。来源用短页脚标注；本地概念来源在学生画布中没有通往教师授课台的链接。

课堂采用教师讲解、受控逐步展开和个人口头／纸面短判断，不增加分组、代码运行、成绩提交或个人生产仿真。教师可播放、暂停、重播、下一幕、拖动进度、全景显示、切换情境和揭示／收起解析。进入页面2秒后自动播放本页动画；手动操作取消本次自动启动，不自动翻页或揭示解析。每页状态独立保存；课堂状态经服务端同步，拒绝过期页和非法选项。学生可跨页、跨讲自由浏览并一键跟上教师，不更改教师状态。个人阅读页不展示教师控制台。
