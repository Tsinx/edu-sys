# 第二讲精修设计：映射、函数与定价决策

版本 `release-economic-mathematics-lesson02-mapping-2026-10-09`，Deck `deck-economic-mathematics-2026-lesson02-mapping`。本讲59页，两个45分钟课时。第一课时1–29页，第二课时30–59页；五次独立练习共20分钟，反馈另计。删去60页版第13页，腾出的1.5分钟用于像、原像和映射类型。60页版的源文件、讲稿、代码、资源清单与三个PDF已归档。

## 贯穿问题

商家准备调整售价，怎样得到一份有依据的定价建议？从两种价格下相同销量的记录出发，补上履约能力、明确假设需求，再形成价格到需求与价格到销量的两种对应。抽象定义承接具体问题，后续以同一商家检验函数链、销售目标、定价与扩容。

学生已有高中函数、方程、不等式与二次函数基础。映射采用严格定义；单射、满射、双射及反函数作为新概念讲授。定义域主要通过经济含义、经营承诺和平台规则展开。后续结论是在已给需求假设下推理，不在中间改作统计估计或外推预测。

## 映射与首次英文术语

第6页定义映射（mapping）：每个允许输入有唯一像。若f(x)=y，y为x的像（image），x为y的一个原像（preimage）。正向像唯一不意味着原像唯一；指定输出集合中也可有未被达到的元素。

第7页用同一组价格A={50,60,80}作三幅箭头图。需求对应的像是700、600、400；销量对应的像均是400。图形数值从原生商家模型计算。

| 映射与指定输出集合 | 判断 | 数学依据 |
| --- | --- | --- |
| 需求，B={700,600,400,1000} | 单射、非满射 | 不同输入有不同像；1000没有原像 |
| 销量，B={400} | 满射、非单射 | 指定输出集合已被覆盖；400有多个原像 |
| 需求，B={700,600,400} | 双射 | 指定输出集合每个元素恰有一个原像 |

单射（injection）要求对任意x₁、x₂，f(x₁)=f(x₂)推出x₁=x₂。第7页将满射（surjection）解释为指定输出集合B中的每个元素至少有一个原像；双射（bijection）同时满足两项。本页不提前使用“陪域”“值域”和f(A)，这些名称与记号在第10页定义后再使用。改变B可能改变满射判断，不能只看表达式。

第9页引入一元实函数、自变量、函数值与连续近似；第10页区分定义域（domain）、陪域（codomain）、值域（range）。复合函数、反函数与经济模型关键术语在本讲首次系统出现时标注英文，后续中文讲述。英文帮助连接国际用语，中文保持完整定义。

## 定义域与模型假设

第12页明确：实际问题中，函数的定义域不但要考虑数学背景，还要考虑实际背景。线性表达式在任何实数处可计算，但本情境要求价格和需求非负，得到[0,120]这一必要范围。

第13页直接给定共同假设：D(p)=1200−10p在P=[30,100]内成立，后续按此推理。仅简要说明实际建模时模型适用范围有时也会限制定义域。原先“资料只覆盖40至60元，能否预测80元”的独立统计外推页删除。第14页给平台0.5元报价网格，第15–18页讨论允许缺货、全部履约及售价上限造成的不同可行集。

## 主案例与经济条件

参数为单日、自拟教学假设。其他需求条件固定，商品统一报价，数量作连续近似；超额需求允许不成交；成本按实际履约发生，暂不计退货、跨日库存与竞争反应。

| 量 | 含义与单位 | 假设 |
| --- | --- | --- |
| p，P，G | 售价元/件；分析区间；可报价集合 | P=[30,100]，G={30+0.5k:k=0,…,140} |
| D，K，S | 需求、能力、实销量，件/日 | D=1200−10p，K=400，S=min{D,K} |
| C₀(s) | 不含佣金经营成本，元/日 | 2000+20s，定义域[0,400] |
| τ，R，Π | 收入抽成比例、日收入、日利润 | τ=10%，R=pS，Π=(0.9p−20)S−2000 |

全部履约才要求D≤K，得到G∩[80,100]；允许部分需求不成交时，容量进入销量法则。第19–22页从经营机制推出分段销量和值域。第23–25页先明确计费对象，再形成价格→销量→成本及一般复合定义。

C₀∘S在整个P上成立；C₀∘D只在[80,100]上成立。D(50)=700不在成本定义域，因此C₀(D(50))无定义。将700代入同形表达式得16000，擅自扩大了原函数的输入范围，又错把未成交需求当作已履约量。第26–29页以独立练习和累积反馈收束第一课时。

## 销售目标、反函数与双射

第30页从希望销量300或400件提出逆向任务。第31页先重申单射，再严格定义反函数：若f:A→B为单射，对每个y∈f(A)，将唯一满足f(x)=y的x∈A对应给y，得到f⁻¹:f(A)→A。分步公开反向对应的等价式，保留两个集合。

第32页用实际案例验证存在条件。需求严格递减，所有实际需求均有唯一价格；销量300唯一对应90元，但400对应[30,80]，故销量在整个P上不单射。一个目标能解出唯一价格不代表整个函数存在反函数。

第33–35页求需求反函数D⁻¹(q)=120−q/10，定义域[200,900]、值域[30,100]，辨析倒数并检验双侧复合。若陪域仍为非负实数，D仅为单射；将陪域指定为[200,900]后，D才是双射，反函数覆盖整个指定陪域。两侧恒等式必须分别写p与q的范围。

第36–38页限制销量函数到[80,100]或[85,100]，使其到对应值域为双射并求逆。两种逆函数表达式相同而集合不同；[75,100]仍保留同像价格，不可逆。课后映射题再次检验不同陪域，替换原先需求函数识别题。

## 定价、扩容与迁移

第39–42页依次引入收入、佣金、单位贡献及分段利润。基准利润为360p−10000（30≤p≤80）和−9p²+1280p−26000（80<p≤100）。第43–47页从三点比较进入全域证明：二次式顶点640/9不在其合法分支，唯一全局最优是80元，利润18800元，且属于网格。

第48–54页比较能力400变500的项目：销量边界从80变70，成本重新定义在[0,500]。同一二次式的顶点进入合法分支，连续最优约71.11元；网格最优71元，销量490件，利润19511元。增加收益711元，却新增每日固定成本1000元时，利润18511元，比原方案低289元。成本平移不改变方案内价格排序，但改变项目选择。

第55–57页以新商品D₂=1000−8p、P₂=[40,100]、K=320、c=30、F=1500、τ=15%独立迁移。第58页区分给定假设内已证明的结论和真实经营前须核实的假设；第59页收束。抽成分界、全域证明及停业的可避免成本在课后展开。
