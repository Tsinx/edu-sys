# 第二讲：概念引入顺序核查

日期：2026-10-09。核查范围为当前59页课件、原生图形与无障碍说明、页脚、逐步公开状态、数字人口播、课堂练习及课后参考解答。页面键和揭示数量不变，两课时仍各45分钟，独立练习20分钟。

## 使用边界

高中先修知识包括集合、区间、集合运算、实数、一次与二次函数、方程与不等式、单调性、二次函数顶点和配方。第1页明确列出这组已学工具；不将反函数、单射、满射或陪域视作高中先修。先修知识可直接用于推理，本讲新概念则必须先说明含义。名称第一次出现可与定义同页；不能先要求运用，再在后续页面补定义。

核查分别追踪投影文字和口播。名称只出现在讲稿不算完成画面介绍；名称出现在图形说明或页脚也算使用。概念定义应在起始状态可见，避免未公开定义却先朗读其用法。数值解答仍按原揭示步骤公开。
