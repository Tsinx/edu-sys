# 第11讲实验教程重构与验收

日期：2026-10-19。范围：第11讲独立实验教程、分析台、学习入口与使用说明。

## 教学主线

1. 入口明确选择“从基准开始新练习”或“继续本机场次”，续接显示基准／试验编号、分钟和保存数量；选择前不自动写入场次。
2. 基准固定原岗位，先连续运行5模拟分钟。有实际记录后才指导添加第一张图，读取状态或数值证据，再到第360分钟、写发现并保存基准。
3. 首次试验先回顾基准发现，选择岗位、修改人数、完成输入、应用配置，再运行观察。随后建立同段基准对照、阅读证据，到统一终点评审改善与代价、记录本次发现。
4. 第二次试验起自主设计。现场与倍速、图表、时间窗、图例、布局、导出共六项专题帮助按需打开，帮助不会代替实验指令或形成运行门槛。
5. “重置本次实验”随时可用；“从基准新开练习”另存整场。正常保存／进入下一试验仍须简写发现。

## 关键修复

- 教程依据实际分钟、已应用的岗位差异、真实图表和证据阅读状态推进，旧的功能点击计数不会提前完成新教程。
- 人数输入期间保留输入框目标和焦点；Enter、Tab或“完成输入”后才定位应用按钮。
- 未改岗位就运行时，定位可用的重置按钮，或由学生明确选择原配置重复验证；不会再要求修改已锁定的岗位。
- 仅有的图例系列被隐藏后，显示“显示全部系列”恢复路径；无可点击图形时转向数值表。
- 刷新后证据说明已关闭时，要求重新打开证据。切换试验只重建分析台临时编辑、图例与检查状态，保留图表配置和实验控制器。
- 示范指针真实移动、停留、示意点击，可重放；不移动系统鼠标，不自动操作实验。减少动态效果设置下改为静态定位。
- 窄屏指导卡片控制高度，滚动为当前控件保留空间；正在输入发现时不抢焦点、不跳到保存按钮。

## 实际浏览器验收

使用隔离的本地Vite服务5194、内置浏览器，桌面1280×720及窄屏390×844。均通过真实界面操作；未通过浏览器脚本修改实验状态。

| 路径 | 实测结果 |
|---|---|
| 全新基准 | 第120分钟，人员编辑框0个，首个目标为“连续推进5分钟”；第125分钟后转为添加图表 |
| 首张图表 | 默认状态时间轴可直接保存，完整配置在更多设置中；点真实状态段后停在阅读证据节点 |
| 首次试验 | 保存基准后才出现岗位选择；先回顾基准发现，再改人数、应用、运行 |

| 窄屏应用 | 完成输入后应用按钮底部约485px，指导卡片顶部约568px，留出约83px；应用目标高亮可见 |
| 对照图 | 运行后选择占用率和基准叠加，当前与基准使用同区间；只隐藏对照图的唯一系列后，教程转向恢复系列 |
| 刷新续接 | 第125分钟和图表保留，编辑器关闭，教程转向重新打开证据说明 |

| 发现输入 | 窄屏连续输入保持焦点在发现框，高亮不跳去提交；保存后按次保留发现 |
| 自主试验 | 试验2没有强制指导，发现为空，原两张图表保留；时间窗专题可展开设置、保存并返回自主主线 |
| 整场新开与恢复 | 新练习回到空白基准、无人员编辑；从历史实际恢复了此前的基准、试验1发现及两张图表 |

| 控制台与布局 | 本次验收捕获的警告／错误日志为空；窄屏已展开的图表设置无页面横向溢出 |
