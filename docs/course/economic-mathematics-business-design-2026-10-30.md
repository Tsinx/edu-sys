# 第14、15讲设计与数学边界

本次在合并后的31讲编号上制作第14、15讲，不再次调整编号。每讲48页、两个45分钟；24页分界。课堂以个人作答为主，每讲六组两题单选与两组4/5分钟书面题，选择题另留反馈时间。所有48页进入主线，揭示状态单独计数。

## 衔接与叙事

第13讲已从数学上解释驻点、严格凹性、区间和全局保证。第14讲以三条订单计划的利润数据引入，不先背边际口诀。逐步建立同一种商品一周统一定价的模型，说明收入为什么受到新增销量与原有销量重新定价的共同影响。连续最优以后，依次改变容量、费用能否避免、整数订单、每件税费。每次只改变一个已说明的条件。

第14讲末端用绝对变化的比较提出下一问。第15讲从“少卖10件与少卖6件哪个更敏感”进入相对基数，以极限给点弹性正式定义，再证明单位不变。先解决收入方向与精确变化，后返回利润条件。整个过程用相同线性需求与二次成本，只有进入等弹性专题时明确切换模型。结尾从已知边际成本反求总成本，接新版第16讲不定积分。

## 第14讲：逐段设计

| 页 | 教学内容 | 关键判断 |
|---|---|---|
| 1—7 | 订单数据、利润目标、统一定价、反需求、可行域与成本 | 价格与销量由同一需求关系绑定；生产等于销售 |
| 8—15 | 边际定义、单位、乘积法则、重新定价、离散差额；两组个人选择 | MR≠价格；导数≠精确一件增量 |
| 16—22 | Π′=MR−MC、候选、严格凹性、收入与利润不同目标、固定费用 | 必要、充分、全局、唯一分别说明依据 |
| 23—24 | 个人建模与反馈 | 新模型求边际量、最优方案及完整检验 |
| 25—31 | 容量端点、最优值V与局部容量价值；两组选择 | 正边际利润可与边界最优共存；有限扩产要算完整差额 |
| 32—36 | 平均成本、商法则、费用已发生与可以避免；一组选择 | MC=AC与MR=MC回答不同问题；负利润不等于立即停产 |
| 37—42 | 非最优驻点反例、整数核验、税费、换自变量、参数实验 | 明确每项简化所依赖的函数结构 |
| 43—48 | 扩产个人题与反馈、非光滑边界、综合追问、下一讲入口 | 新旧最优利润与费用比较，不能外推局部读数 |

基本模型：p=120−0.1q，C=F+24q+0.02q²；q件/周，p元/件，R、C、Π元/周。初始F=2000，K=1200。Π=19200−F−0.12(q−400)²，MR=120−0.2q，MC=24+0.04q。容量300、350的经营利润为16000、16900，扩产费用1000使后方案净利润15900。整数差额Π(q+1)−Π(q)=95.88−0.24q。所有读数与图形共用business-model.ts，禁止按关键词挑曲线。

## 第15讲：逐段设计

| 页 | 教学内容 | 关键判断 |
|---|---|---|
| 1—8 | 规模与单位反例、相对变化、极限定义、对数语言、分类、单位不变证明 | 带符号e与本讲下降需求的E=−e区分；p、q须正 |
| 9—15 | 线性需求的变弹性、零基数边界、点估算、有限乘积差额 | 线性斜率恒定不等于弹性恒定；交叉项不可假定为零 |
| 16—24 | 收入导数、E=1反例、区间条件、个人精算、弧弹性与观察数据边界 | 单点驻点不保证最大；模型内推理不等于因果估计 |
| 25—33 | 反需求导数、MR表达、内部加成率、容量反例、两组个人选择 | q′非零；MR=MC为额外条件；价格加成率不是总利润率 |
| 34—40 | 等弹性需求、收入与利润、η≤1边界、个人选择与参数实验 | 幂指数恒定不等于斜率恒定；无穷不是已取得的最优价格 |
| 41—48 | 非线性容量个人题与反馈、有限范围、相同局部信息、成本转嫁、积分入口 | 同一个E可对应不同边界加成；单点信息不足以决定整条曲线 |

深度反例：q=100(p−2+2/p)，0.8<p<1.2，需求正且下降，R=100[1+(p−1)²]在p=1取得严格局部最小而E=1。相同局部信息：q₁=1200−10p与q₂=2560000/p²在p=80具有相同q、q′、E，但p=100的销量不同。等弹性个人题q=360000/p²、C=1000+30q，30≤p≤120，无容量时p=60、q=100；容量64时p≥75，新最优p=75、q=64，加成率0.6而1/E=0.5。
