# 港口管理应急手册

第12讲 · 学生操作与决策指南。2026-10-19 / 教学版 1.1。

## 01 / 任务与边界 先保护人，再保护可信业务

你承担课堂情境中的港口值班管理角色。任务是用证据界定影响，组织有边界的连续性方案，验证恢复，并交代仍未解决的问题。

### 本实验的两个场景


| 场景 | 开局问题 | 需要验证的结果 |
|---|---|---|
| 系统中断 | 电子交付校验异常，放行已保护性暂停 | 记录可信、实际试放行和服务恢复 |
| 场桥故障 | 场桥1保护停机，当前交接安全收尾 | 检修区隔离、实际试吊和设备复工 |

### 先选学习方式

1. 教学模式：逐步给出操作答案、原因和完成标志。金色高亮指向真实控件，固定提示中的“答案与原因”可随时返回完整讲解；无需先听课也可跟做。
2. 实战模式：独立选择隔离、维修与连续性安排；通用手册仍可查阅，页面不提供逐步操作答案。
3. 两种模式分别保存最近进度。切换前自动保存；“从同一现场新开实战”保留旧记录并从第90分钟重新起步。

### 贯穿全程的六件事

固定告警 → 取得独立证据 → 界定并隔离影响 → 组织必要业务 → 受控验证与审查 → 观察影响、复盘和交接。检查顺序取决于条件；不要把所有工作机械串行。

本手册主要指导软件内的独立教学情境。现场事故由现场预案、指挥体系和有资质人员处置，模型按钮不构成实港授权。

## 02 / 运行与证据 分清课堂分钟与模拟分钟

每个场景约30课堂分钟；模型从第90模拟分钟开始，统一观察到第240分钟。倍速改变等待时间，不改变逐箱规则。

### 按这几个位置操作


| 位置 | 查看或操作 |
|---|---|
| 事件证据台 | 只显示已经取得的告警、检查、调度和恢复回报 |
| 实验运行控制 | 运行倍速、连续推进、暂停、继续耗时操作及快算 |
| 事件处置台 | 固定告警、检查、隔离、维修、备用或替代、试运行与审查 |
| 现场与分析台 | 设备当前任务、位置、库存、状态时间轴、交接量和成本 |

### 自动暂停后怎么继续

1. 先读最新反馈：暂停可能是新回报、检查完成、维修完成或3次交接完成。
2. 如“检查进行中”仍显示完成时间，点击“继续耗时操作”；中途回报不会把检查自动算作完成。
3. 如已取得新证据，先判断是否需要下达新指令，再点击“运行至下一节点”或连续推进。
4. “连续运行至终点”和“快算至观察终点”也会停在业务节点；以仿真时钟是否到第240分钟判断观察完成。

### 暂停与并行

暂停时技术工作和检查都不累计。一次只能进行一项耗时检查；已启动的技术工作可以与检查和被允许的业务并行。切离页面会自动暂停。

快算与连续播放使用同一逐箱内核。先用低倍速看清动作，再用高倍速或快算取得长时段结果；快算不是跳过证据要求。

## 03 / 系统中断 · 取证与连续性 先查可信性，再开有限备用

初始告警只证明电子交付校验异常。它没有证明所有设备故障，也没有直接给出可恢复的数据范围。

### 建立可核查的范围判断

1. 点击“固定当前告警证据”，保留告警时点和当前现场。
2. 启动“独立范围检查 · 3分钟”，推进至回执出现；说明哪些内部作业仍可独立运行。
3. 启动“追查接口日志 · 4分钟”，核对故障时点与最后可信快照。记录未知项，不凭截图推定最终数据丢失。
4. 在“隔离范围”选择受影响接口或全部内部箱流，再“执行所选隔离”。若范围扩大，解释停工收益与积压代价。

### 把技术工作与资料核验衔接起来

1. 本轮建议选择2人并“启动技术工作”。60人分钟＝2人×30分钟；核验、运输和试放行仍另外耗时。也可用1人方案比较代价。
2. 调取备用台账，展开独立值班副本。R2、R3是同一票号的重复行，留任意一条；R4版本17、10箱，与独立凭据版本18、12箱冲突。
3. 勾选＝隔离排除。示范只勾R3、R4，保留38箱、备用上限24箱；保守勾R2、R3、R4也认可，剩余20箱、上限20箱。启动10分钟核验，回执到达才解锁。

### 备用交付是一项选择

核验通过后，可启用本轮额度内的双人复核备用交付。额度取24箱与保留可信数量的较小值；单道核验、另计2人复核成本，仍须实际提箱、运输和闸口交接。额度不是产量保证，被隔离票据仍待恢复对账。

不用备用方案也可完成实战。说明选择等待或有限交付的理由，用实际结果解释代价。恢复对账开始后，不再重新启用备用交付。

## 04 / 系统中断 · 恢复验证 技术完成，不等于可以恢复放行

技术工作完成、记录对账、实际试放行和恢复审查分别产生证据。任何一个“完成”都不能替代下一项。

### 按证据通过恢复关口

1. 技术工作完成且备用记录核验通过后，启动“恢复记录对账 · 10分钟”。对账期间交付保持暂停。
2. 收到对账回执后，点击“启动3箱实际试放行”。
3. 连续推进，直到3箱实际完成提箱、运输和闸口核验。额度完成时自动暂停；只点击启动按钮不算通过。
4. 点击“审查证据并恢复电子交付”。系统在这一实际时点登记服务恢复。
5. 继续运行至第240分钟，核对新增交付、未交付、等待与成本。服务恢复后，积压不会瞬间消失。

### 看懂恢复目标


| 指标 | 正确读法 |
|---|---|
| RTO目标60分钟 | 从第90分钟事件起点到服务恢复审查通过的耗时 |
| RPO目标10分钟 | 核对独立日志揭示的可信恢复点暴露窗口 |
| 最终数据丢失 | 需以重建、对账证据另行确认，不能直接等同于快照间隔 |
| 经营影响 | 到统一第240分钟再比较交付、等待、成本和全部未交付量 |

### 没有达到目标怎么办

如实记录超时原因与代价，仍可在完成全部实战程序和复盘后提交。若到观察终点仍未恢复，只能保留草稿或失败复盘，并重开改进方案。

不要为了压低RTO，省略对账、实际3箱验证或明确的恢复审查。

## 05 / 场桥故障 · 安全与替代 先让当前交接安全结束

保护停机是不再接收新任务，不是把正在交接的箱子取消。保持箱、车与设备任务连续，是本场景的基本约束。

### 固定、诊断、隔离

1. 固定当前告警，启动独立范围检查，观察闸口及其余设备是否受到影响。
2. 点击“诊断场桥1 · 5分钟”，取得诊断回执。
3. 查看场桥1当前任务。如果还在安全收尾，继续推进到交接结束，不通过移动设备或重置现场跳过它。
4. 选择隔离范围，启动“安全隔离检修区 · 2分钟”，收到隔离回执后再安排维修。

### 维修班组怎么选

本场景为90人分钟。启动前可在1人和2人之间调整；理论技术用时分别为90或45分钟，实际设备复工还包括检查、返回、试吊和审查。维修启动后本轮班组锁定。

### 是否改派场桥3


| 选择 | 可获得什么 | 需要付出的代价 |
|---|---|---|
| 等待维修 | 保留场桥3原区服务 | 故障区更久地依赖剩余能力 |
| 改派场桥3 | 为故障区提供替代能力 | 先完成原任务、沿道路实际转场，Y3暂失该设备 |

### 根据证据保留独立业务

如果此前暂停全部内部箱流，取得范围证据且隔离完成后，可使用“恢复非受影响内部作业”。故障场桥仍受隔离限制。

模型假设检修区与替代作业区可以独立隔离。这是课堂条件，不是港区设备检修的现场操作规程。

## 06 / 场桥故障 · 受控复工 返回与空驶不能冒充3次试吊

替代设备须退出故障区，原场桥须实际完成受控箱交接。设备位置和实际任务记录共同构成复工证据。

### 完成设备复工的证据链

1. 维修达到90人分钟后，启动“维修后安全检查 · 5分钟”。
2. 若使用替代场桥，点击“撤回替代场桥至原区”。它先完成当前交接，再沿道路返回；继续推进到返回回执。
3. 确认内部场桥业务可执行，然后“启动场桥1的3次实际试吊”。
4. 持续观察场桥1的具体箱任务；移机、空载返回、车辆等待都不算试吊交接。3次完成时自动暂停。
5. 点击“审查证据并恢复场桥1作业”，登记设备复工时点，再观察至第240分钟。

### 试吊没有增加，先查哪里


| 现象 | 应查证据或条件 |
|---|---|
| 替代设备仍在故障区 | 撤回请求、当前任务、道路返回与回执 |
| 全部内部业务仍暂停 | 独立范围证据、隔离状态及业务恢复安排 |
| 场桥1没有可执行箱任务 | 该区库存、车辆任务、交接位和上下游接续 |
| 设备正在移动 | 位置与任务阶段；移动完成后才进入实际箱交接 |

### 复工目标90分钟

从第90分钟事件起点计至设备复工审查通过。不要把90人分钟维修工作量和90分钟复工目标混为一谈；两人维修也不能绕过安全检查或实际试吊。

若本轮没有完成实际验证，先保留草稿并说明卡点，再从同一开局试验另一方案。不能把手写“完成”作为证据。

## 07 / 经营判断 把恢复与积压放在同一张证据表里

“恢复成功”只说明服务或设备通过审查。完整的管理判断，还要解释期间损失、代价和仍需处置的积压。

### 用四类图相互核对


| 观察材料 | 可以回答 | 不能直接推定 |
|---|---|---|
| 单设备状态时间轴 | 故障、等待、转场和实际交接各占多久 | 全部占用都在创造产出 |
| 车辆分时占用 | 任务是否被接续等待阻滞 | 司机或运输一定负全部责任 |
| 实际交接量 | 哪个环节确实完成了箱任务 | 多环节箱次相加就是最终交付 |
| 库存与最终交付 | 积压在哪里、客户交付多少 | 只看已完成货物就代表全部需求 |

### 比较另一方案

1. 先运行到第240分钟，再“从同一开局重开方案”。旧场次、复盘和被拒绝尝试均保留。
2. 建议一次只改变一项：隔离范围、维修人数、是否备用交付或是否使用替代场桥。多项改变应全部说明。
3. 在“图表对照方案”选择已完成的同场景记录；使用同一设备、统计区间和观察终点。
4. 分别列出收益、代价与没有解决的问题。不同场景或不同规则的结果，不解释为单项措施效果。

### 成本与未交付

成本以教学单位累计，包含实际岗位与相应过程代价，不是实港报价。全部未交付包括仍在船、岸侧、运输与堆场的货物；不能只计算场内库存。

## 08 / 报告与交接 四项复盘，要能被下一班继续核查

每项至少15字仅用于完整性检查。教师仍需根据实际操作和证据评阅，不会因为字数足够就自动认定分析正确。

### 四项文字分别写什么


| 复盘项 | 可采用的结构 |
|---|---|
| 影响范围与隔离依据 | 哪条回执证明了什么；暂停或保留了哪些业务；有哪些代价 |
| 失效屏障与共同依赖 | 哪份记录、设备或接口失效；独立核验与替代能解决什么、不能解决什么 |
| 恢复证据与目标核对 | 技术、检查、实际交接、恢复审查时点；RTO或复工目标；交付、等待与成本 |
| 责任交接与下一班任务 | 尚未完成的事项、责任岗位、下一项证据及触发复核的条件 |

### 一条可执行的交接记录

事项：仍在等待的货物或任务。依据：当前时刻、对象标识与最新回执。责任：谁继续核查。动作：查什么、向谁确认。复核：什么时候或什么条件变化后重新决定。

### 避免空话

1. 将“加强沟通”改为明确联系岗位、记录与时间端点。
2. 将“已恢复正常”拆成已完成的审查和仍未清空的积压。
3. 将“应该全停”或“应该不停”接到具体影响范围和独立证据。
4. 对未证实原因写“待核查”，保留初判与修订理由，不补造因果链。

## 09 / 完成与提交 备份始终可用，正式提交需要完成实战

实验没有把下载操作冒充平台接收。你需要按教师指定入口提交实战文件；本页会明确区分草稿、教学复盘和实战提交包。

### 正式提交需要同时满足

1. 使用实战模式，并完成告警、范围、诊断、隔离等当前场景必要证据。
2. 完成技术工作、恢复检查、3次实际受控交接、服务恢复或设备复工审查；如使用替代设备，须实际返回。
3. 运行至第240分钟，填写四项复盘，各至少15字。
4. 点击“完成实战并封存复盘”，然后“下载实战提交包 JSON”。生成文件前会重放实际指令并重新计算结果。

### 哪些情况不会单独取消资格

恢复超过目标、成本较高、仍有积压或方案不如对照，都应如实报告；只要完成必要处置、验证、观察和复盘，仍可提交。

### 草稿、失败尝试与重开

“下载完整实验记录 JSON（草稿备份）”始终可用。教学模式可保存成功或失败复盘，实战未完成也可保留草稿；它们不会被标作正式实战提交。模式切换、刷新、导入和新开方案保留原场次。

修改复盘文字或继续操作会清除原封存状态，需重新完成并封存。载入文件会重放指令；修改文件中的统计数字、恢复标记或终点文字不能补齐实际证据。

## 10 / 真实港口的管理边界 课堂训练要迁移为有权限的现场协同

真实港口包含人员生命、危险货物、设备能源、船岸界面和公共环境风险。遇到真实险情，应执行本单位现场预案及授权指挥，不照搬本模型的时间、额度和隔离范围。

### 通用管理响应

1. 发现异常先报告并保护人员，避免进入危险区域；按照现场指令避险、集合与清点。
2. 向值班或授权指挥提供已知时间、地点、对象、人员影响、已采取措施与尚未知事项。
3. 由授权人员界定隔离、停工、专业救援和外部协同；保留证据和记录，持续更新，不自行扩大操作权限。
4. 恢复须核对人员、设备、环境、数据和业务条件，明确授权、验证记录、监测与再次停工条件。

### 不同风险，接到不同专业职责


| 风险线索 | 管理上应组织的协同 |
|---|---|
| 火情、泄漏或不明危险货物 | 现场指挥、专业救援和相应监管协同，人员避险与信息报告 |
| 强风、雷电、能见度或水位异常 | 气象与通航信息、作业限制、人员与船岸计划的授权调整 |
| 设备与能源异常 | 安全隔离、许可和专业检修，按批准条件验证复工 |
| 数据与信息系统异常 | 业务保全、独立证据、专业信息处置和可信恢复审查 |

### 制度与来源

交通运输部《港口危险货物安全管理规定》（2023年修正）强调相应应急预案、现场处置方案及培训演练；学生实习应接受相应安全教育培训。2026年部门应急预案修订进一步明确响应、指挥协调和信息报告。软件具体按钮、票据、箱量、时长、人员和费用均为本课程设定。

资料核对：2026-10-19。法规背景用于说明职责与预案要求，不代替具体港口、具体作业的适用规定和现场文件。
