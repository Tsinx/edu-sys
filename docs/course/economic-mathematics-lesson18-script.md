## 2. 分部积分来自乘积求导

第1课时，预计120秒。
预计120秒。按页中条件解释每一步，提问后保留独立判断时间；反馈只在相应步骤公开后讲解。
$$d(uv)=u\,dv+v\,du$$
u=u(x)、v=v(x)在同一开区间可导。
移开其中一项，再用原函数关系恢复。

公开步骤1：移项后的微分关系

$$u\,dv=d(uv)-v\,du$$
公开步骤2：分部积分公式

$$\int u\,dv=uv-\int v\,du$$

逐字讲稿：
初始状态：乘积的微分由两部分相加而成。把u乘dv留在一边，另一项移过去，再寻找原函数。由此得到分部积分，而不是把两个积分各自相乘。
第1步公开后：目标项等于整个乘积的微分，减去另一项。
第2步公开后：整个乘积的微分恢复为uv，剩余积分带减号，最终统一保留积分常数。

计算中I、J记所选的原函数，固定差在最终结果中合并为C。

$$\int\ln x\,dx=\int\ln x\cdot1\,dx,\qquad x>0$$

公开步骤1：选择与分部

$$u=\ln x,\quad dv=dx,\quad I=x\ln x-\int x\frac{dx}{x}$$

第1步公开后：对数作为微分部分，一乘dx作为积分部分。
第2步公开后：剩余积分为一，结果适用于正半轴。
