# 第12讲教学模式全流程检查与修订

检查日期：2026-10-19（America/New_York）。对象是独立课堂实验的系统中断和场桥故障两个场景。教学模式现在以无先修听课为起点，逐步解释操作、参考答案、原因和完成标志；实战继续独立处置。未改动1600×1000课件画布、课堂工具栏或逐箱物理引擎。

## 问题与修订

1. 旧高亮只接在处置按钮上，步骤转到运行控制、终点、复盘或备份时没有高亮。现在所有目标共用同一接口；运行中高亮暂停，检查中途回报暂停后高亮继续。学生提前运行时也先引导暂停，避免指向被锁定的业务按钮，暂停后回到缺少的步骤。可选操作导致按钮离开屏幕后，会重新定位当前目标；填写文本和选择参数时不抢走输入焦点。
2. 指导不再要求学生反复猜答案。七阶段路线包含固定告警、独立取证、范围与隔离、维修与连续性、实际恢复验证、终点观察、复盘与交接。每步说明做什么、为什么、何时完成。固定提示可定位真实操作，也可返回完整解释。
3. 补充课堂分钟、模拟分钟、人分钟、RTO、RPO、箱分钟、平均在制、交付、积压和成本的基础说明。维修人数、局部隔离、备用交付和替代调度给出示范选择及代价；示范不是最优方案承诺。
4. 备用资料调取完成后，同时展示待核验台账与独立值班副本，明确两者均为教学设定。勾选明确表示隔离排除，教学模式逐行解释有效、重复、旧版本和数量冲突，并提供可采用的选择。
5. 去重选择隔离R3、R4或R2、R4，保留38箱、备用上限24箱。保守选择隔离R2、R3、R4，剩余20箱、备用上限20箱。允许可信的部分记录通过核验；全部隔离、仍有重复或版本数量冲突则拒绝。额度由已接受指令推导，实际闸口达到额度后停止，导入与回放不能把20箱改成24箱。恢复对账后不能再重新启用备用交付。
6. 核验失败在按钮旁显示原因，调整选择后清除旧错误，拒绝尝试仍保留。通过核验后收起长台账，突出后续工作。全范围暂停后明确指导恢复独立内部业务，避免后续试吊没有可执行任务。
7. 四项复盘按未完成项依次高亮，给出本轮实际证据与指标的参考文字及原因；可采用后修改。未恢复场次的示例明确写未完成，不能补造恢复。保存后继续引导备份或同开局比较，教学记录不标作正式实战提交。
