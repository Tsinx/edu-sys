## 第12讲

### 当前入口：两个独立场景（场景规则1）

- 系统中断：`/port-class-lab.html?lesson=12&scenario=system`。
- 关键设备故障：`/port-class-lab.html?lesson=12&scenario=equipment`。
- 学生任务书：`/port-lab-taskbook.html`，可按场景定位、打印；使用说明：`/port-lab-guide.html#lesson12`。

每个场景约30课堂分钟，按5、8、10、7分钟安排证据获取、处置、恢复与另一方案、比较复盘。每次选做一个场景；两场景均从第90模拟分钟开始，统一观察至第240分钟。首轮建议连续播放，第二方案允许使用另设快算入口。30分钟为课堂设计，尚需本班试讲校准节奏。

系统中断开局只给电子交付校验失败与保护性暂停；范围检查3模拟分钟、日志追查4分钟、备用资料调取3分钟。第95、110分钟另有当时真实车辆与库存的回报。回报和任务完成均自动暂停；中途回报可能早于正在执行的检查完成，须继续耗时操作。日志才公开75分钟可信快照与15分钟暴露窗口，备用资料调取后才显示逐行台账。技术工作60人分钟，可配置1或2人，并与资料核验、有限备用交付并行。后续对账10分钟、实际3箱试放行及恢复审查分别计时。RTO目标60分钟，RPO目标10分钟；不把初始记录暴露窗口当成已经永久丢失的数据量。

当前系统场景允许两种台账处理：去重时隔离R3、R4（或R2、R4），保留38箱可信数量，备用上限24箱；保守地隔离R2、R3、R4，剩余R1、R5共20箱，备用上限20箱。隔离票据不计入额度，仍须后续恢复对账。备用额度由已接受的核验指令推导，实际闸口箱流和回放都按这一额度限制；恢复对账开始后不再重新启用备用交付。

教学模式按七个阶段给出明确操作、参考答案、原因与完成标志，持续高亮运行、暂停、处置、复盘和备份入口；台账提供独立值班副本与逐行解释，四项复盘示例使用本轮实际证据。实战模式隐藏这些逐步答案与示例，保留通用手册和业务反馈。两种模式分别保存进度。

设备场景开局为场桥1保护停机：停止接新任务，已承诺的交接安全收尾，避免把悬吊中的箱直接取消或瞬移。范围检查3分钟、设备诊断5分钟、安全撤离与隔离2分钟；维修90人分钟，人员成本按实际岗位计。可选择等待维修或改派RTG场桥3；替代须完成原任务、沿预约道路实际转场，Y3暂失该设备。故障区仅允许指定替代设备进入，原区保留返回位置。撤回时先完成当前交接，再实际沿道路返回；返回不计完成箱任务。维修后检查5分钟，故障场桥先实际空载返回作业区，再完成3次箱交接后才能审查复工；设备复工目标90分钟。教学假定检修区可与替代作业区独立隔离，不是实港设备检修规范。

两场景有不同任务和默认分析模板：故障/业务暂停状态构成、车辆分时占用、实际交接量、库存。可自配单设备时间轴。到终点后“从同一开局重开方案”保留旧方案、复盘和拒绝尝试，沿用图表配置，清空当前复盘。图表对照只接受同场景规则的已完成历史方案，使用相同设备和当前已观察时窗；最终经营表只在同终点比较。可比较维修人数、初始隔离、备用交付或替代调度，建议一次只改变一项。

记录只存场景标识、场景版本及指令序列，载入重新执行逐箱模拟；外部JSON中直接填写的原始统计、线索和完成状态不作为证据。原版2.0不带场景字段的记录沿原规则重放，不与场景规则1混作同条件对照。各新场景入口保存独立的最近场次，原场次仍能从历史入口恢复。

### 原版固定接口事件（供已保存旧记录核对）

R2与R3均为有效的T02副本，保留任一条、隔离另一条与R4，均可通过核验。R4版本过期且数量与独立记录不一致。

参考：第90分钟记录并隔离，核验至100；启用有限备用、启动技术恢复，130.00分钟完成技术工作，140.00分钟完成对账，实际3箱试运行后在152.05分钟恢复。RTO为62.05分钟，超出60分钟目标。
观察至240分钟：新增交付22箱，未交付267箱，成本142.10教学单位。

24箱是可信备用额度上限，不保证观察期内用尽；单道额定22箱/时仍受提箱、运输、道路和交接条件约束。技术完成、额度用尽和3箱试运完成会暂停推进。未恢复的失败处置也可在终点保存复盘，重开保留历史分支。

## 解释与核对

- 箱、车辆、作业任务和库存同源；吊装循环完成前显示交接中，空吊具返回并确认后释放车辆。
- 目的作业位可用时直接送达；受阻时才驶入带箱待接区。空车卸箱后离开交接位，返回待命区再领任务。
- 每个窗口独立保存；刷新、导入和载入历史场次会建立副本。损坏原文保留，完成状态重新核验。
- 切离页面自动暂停；岗位修改先应用再运行。左键平移、Shift加左键旋转、滚轮缩放，右键拖动也可平移。
- 数量为整数箱；平均在制与短窗速率可以有小数。兼容字段capacities沿用旧配置估计，不作为逐箱实际产能；现场分析采用observedRates、任务与资源状态。

几何、设备速率、费用、车队与恢复目标均为教学设定。交通预约偏保守，没有校准真实车辆动力学、司机班制、危险货物间距、怠速能耗或法定放行程序。成本不是实港报价。
