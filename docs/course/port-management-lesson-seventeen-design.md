# 第17讲：港口拥堵的非线性

建设日期：2026-10-23。42页，90分钟，1600×1000画布，接续全课程第686—727页。第18讲已于2026-10-26续建，见[建设说明](./port-management-lesson-eighteen-design.md)。原16讲的课程基线保留，本讲为新增扩展单元。

## 核心问题与知识增量

以虚构东湾港南闸口贯穿全讲。现有平均到达90票/小时，单核验台平均能力100票/小时，拟增加到99票/小时。票与车辆一一对应，先把其他港口环节隔离。学生从初始预测进入逐车记录，最终能以假设、计算和证据说明是否承接扩量及怎样改善。

第5讲已有瓶颈和有限到达对照，本讲进一步推导随机单台系统的稳态分布与非线性等待。第11讲的指标口径在这里落实为W与Wq、时间平均与逐车平均、模型均值与样本分位数的区分。第15讲的业务接续在预约场景中转为全程边界核算。第16讲的静态预算不在本讲扩展为实物期权。

## 无先修基础的推导路径

1. 用2分35秒原创动画跟踪一辆车，区分等待与核验，比较车等台/台等车，演示延误传播与空闲间隙。再把两个开工条件压缩为b=max(a,d前车)，以记录代替孤立减法练习。
2. 8车手算及时间条，理解等待来自到达节奏而不只来自服务工作量。
3. 在场数量曲线下面积等于所有完成车辆停留时间之和。在本例空到空窗口内，用A/T=(n/T)(A/n)得到有限记录恒等式，再介绍长期Little关系。
4. 定义每小时到达率λ、服务率μ和利用率ρ。用中文和单位解释记号。
5. 说明独立泊松到达、独立指数服务、单台、无限等候及λ<μ，不要求先学概率密度。
6. 用长期状态比例pₙ和相邻边界跨越次数说明λpₙ=μpₙ₊₁，得到pₙ=ρⁿp₀。
7. 几何和用错位相减求出p₀=1−ρ，加权和再用错位相减求出L=ρ/(1−ρ)，不使用微积分。
8. 从Little关系得到W=1/(μ−λ)小时，再计算Wq、Lq，反算能力并比较列明成本。

## 三轮简化模拟

入口：/port-queue-lab.html。独立于既有三维仿真引擎，无需排队论先修或编程。

- 模拟一：8车均匀/成对到达，支持自定义1—40辆车、固定服务时长、逐车推进、全量核对。默认观察窗0—24分钟。到达同刻按输入顺序。
- 模拟二：单台FCFS离散事件模拟。到达与服务随机流独立，速率变化复用相应底稿。默认500票热身、4000票正式记录，生成后服务至所有车辆完成。允许改种子、票数、速率和固定服务分布；固定服务或λ≥μ时不显示不适用的M/M/1稳态预测。热身与有限规模不构成稳态精度保证。
- 模拟三：12辆车在0/8/16分钟各4辆就绪。比较成批入队、分时预约、双台共队列。保留ready、arrival、start、departure，分别核算港外、闸口与全程。双台用逐车排程计算，不把两个μ相加后套单台公式。

学生先预测、再运行、简要写发现后保留对照记录。三场景分别保存预测与发现草稿；开始新一轮清空本次发现，避免把上一轮结论直接作为新记录。没有运行次数限制，随时重置当前场景，对照记录保留；清空记录另设明确操作。JSON含参数、预测、发现、历史摘要及当前逐车数据，CSV含本次逐车数据。本机缓存与下载不是平台提交，页面不发送成绩。

## 定量核对

- 手算4车0/1/1/4、服务2：开始0/2/4/6、完成2/4/6/8、等待0/1/3/2。
- 8车A等待均值0、停留2；B等待1、停留3；两者16分钟服务、24分钟观察。B面积24辆分钟，L=1，λ=8/24辆每分钟。
- μ100、λ80/90/95/99：W分别3/6/12/60分钟。λ90时Wq5.4、L9、Lq8.1。λ≥μ不求有限稳态均值。
- λ99、W≤10要求μ≥105；W≤5要求μ≥111。
- λ90、排队价值120元/车小时：A/B/C总成本972/867.142857/1091.818182元每小时，W6/4/3分钟，B为满足5分钟目标的最低列明成本方案。
- λ95：A/B/C总成本2166/1281.428571/1306.363636，W12/6/4，只有C满足目标。λ99时现有三个方案都不满足5分钟目标。
- 预约场景：原流程港外/闸口/全程均值0/3/5，预约3/0/5，双台0/1/3分钟。基地等待价值30、闸口120时，本批原等待成本72元、预约18元，差54元，仍需扣除组织支出。
- 迁移λ48、μ60：W5、Wq4分钟；W≤3要求μ≥68。

## 三轮模拟的过程示意

三轮实验共用“尚未就绪 → 港外等待 → 闸口排队 → 核验 → 完成”的回放视图。车身、准备区、单列队伍、核验台和离开区均为代码绘制的示意，位置与距离不代表实体物流。没有给排程额外加入行驶时间。

过程直接读取同一份逐车排程，不另建一套速度或服务算法。车辆在ready、arrival、start、departure四个原始时刻切换状态；同一时刻的事件合并处理。支持播放、暂停、逐事件前进、拖动时钟、回到起点、按编号定位以及从逐车表返回过程。点击车身暂停并显示已发生的时刻，未发生时刻暂缓揭示。

- 手算：播放到完成或点击“下一辆”，都加入同一份核对记录。重看与回退不会删掉已核对车辆；重新开始则清空本轮核对进度。
- 随机：过程保留热身和正式记录，热身车用灰色标记；“跳至正式观察”定位第一辆正式车入队时刻。正式均值和导出始终排除热身车辆，也不随回放时刻变化。队列较长时显示队首4辆，省略数量明确标出；跟踪省略部分的车辆时，额外显示其真实队列次序。
- 预约：准备区保留已就绪但未到入队时刻的车辆，防止把等待转移误画为等待消失。双台方案画出两个实际占用位置，均从同一队列取车，完成时间取自原排程。

每个场景按本轮运行标识独立保存回放检查点。切换场景或刷新后暂停恢复；即使输入相同，重新运行仍从起点开始。回放不按帧写入完整学习草稿，且不改变已保留对照历史。窄屏只在示意图内部横向滚动，并将图中跟踪车辆居中；减少动态效果偏好关闭车身过渡，播放仍需主动点击。
