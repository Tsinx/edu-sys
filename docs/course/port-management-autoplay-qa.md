# 港口管理概论 · 2秒自动播放

2026-09-21，按最新要求统一现有各讲的播放规则。

## 当前行为

- 每次进入动画页，等待2000毫秒后自动播放。第2—3讲106页、第4讲16页、第5讲24页、第6讲48页、第7—8讲96页，共290个有进度动画的页面适用。第1讲及第4／5讲的静态页不添加动画。
- 翻页会清除上一页计时，新页面重新等待2秒。自动播放不会自动翻页或揭示解析。
- 播放、暂停、重播、下一幕、拖动、全景、选项或解析操作接管当前页，取消尚未触发的自动启动。
- 第4—8讲恢复已保存进度后等待2秒续播；已到末尾则从头播放。第2—3讲保持进入页面从首帧开始的方式。第6讲保存中的播片状态在教师重新进入时先暂停，再按新延时启动。
- 跟随教师的学生／投影画面不另启计时；通过原有课堂或投影同步接收教师进度。独立静态阅读页保持只读。
- 系统启用“减少动态效果”时显示完整图解，不自动播放运动。
- 第6讲地图播片自动启动画面，不主动请求浏览器解锁声音。用户可点击“开启旁白”；浏览器声音权限不会阻止画面自动播放。现有旁白文件和音量控制保留。

## 实现与证据

统一延时位于`apps/teacher-web/src/features/classroom/usePortAutoplay.ts`。各讲保留原有动画时长、模型、布局和课堂同步方式；第5讲原先需要手动展开的第6／28页也遵循新规则。

`scripts/port-autoplay-audit.mjs`逐页检查前1999毫秒保持原进度、到2000毫秒开始播放、暂停保持、翻页计时清理、手动接管、刷新恢复后续播。另检查只读投影、390像素窄屏和减少动态效果，包括第6讲地图播片。采用Playwright受控时钟；启动计时与React播放状态更新后分别推进动画帧，避免将同一批时钟推进中的渲染调度误判为未播放。

`scripts/port-autoplay-classroom-audit.mjs`在独立QA课堂核验第7／8讲实际自动启动、服务端进度、学生画面同步及暂停保持，并确认第1讲没有新增动画控制。运行环境为本机Chromium、5188前端与4318隔离API；没有使用实际教学数据库。
