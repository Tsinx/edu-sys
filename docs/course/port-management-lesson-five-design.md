# 第5讲教学设计与分镜

题目：岸桥更多，船为什么未必更快？——港口作业中的能力、等待与瓶颈。

48页，90分钟（不含课间），第24页后为45分钟分界。教师演示与个人对照实验结合。学生不需要编程、组队或参与排行榜。制作基线：2026-09-17；实施状态与验证结果见 [验收报告](port-management-lesson-five-qa.md)，数据口径见 [实验证据](port-management-lesson-five-experiment.md)。

## 学习目标

1. 用统一对象、单位和时窗区分设备数量、可用能力与实际产出。
2. 用箱流、等待、资源状态提出可证伪的瓶颈假设。
3. 从相同起点只改变一项资源，以原始记录比较方案。
4. 解释局部提速、整体结果、瓶颈迁移及边际改善之间的关系。

本讲接续第4讲的“只改变一项资源，等待会在哪里减少”，结束于第6讲的“卸船更快，为什么堆场仍会积压”。不讲设备采购最优解、工程容量设计、完整排队论或正式投资评价。

## 课堂节奏

| 页码 | 分钟 | 学习任务 |
|---|---|---|
| 1—4 | 0—8 | 观察岸侧积压，对增加岸桥提出初始判断 |
| 5—10 | 8—18 | 从作业循环推导能力，确定比较口径 |
| 11—16 | 18—30 | 完成60/40/50串联能力演算 |
| 17—24 | 30—45 | 预测并观察A/B，比较局部与整船结果 |
| 25—30 | 45—57 | 六车到达对照，演算平均等待 |
| 31—36 | 57—70 | 个人从冻结起点执行C并留下解释 |
| 37—43 | 70—82 | 比较C/D/E，解释改善趋缓 |
| 44—48 | 82—90 | 新情境判断、公开解析与调度建议 |

## 逐页分镜

各页正文逐页编写；下表是制作说明，不进入学生投屏。场景页采用深海蓝、演算页米白，青蓝与砂金突出箱流、接续和对照方案；颜色含义由本页图例确定，不统一绑定进出口。1600×1000固定画布，无窄屏重排。所有数量和流程使用代码绘图，港口背景仅作教学情境。

| 页 | 学生可见主题 | 构图与操作 |
|---|---|---|
| 1 | 岸桥更多，船为什么未必更快？ | 全幅港口场景，大标题，双向箱流线索 |
| 2 | 只改变一项资源，等待会在哪里减少？ | 连接第4讲；一条可检验假设与一个反例 |
| 3 | 岸桥还在卸，岸侧已经排起队 | 横向接续图，箱子逐步在岸侧排队，观察慢接环节 |
| 4 | 再调来一台岸桥，会怎样？ | 问题场景，保留三个可能方向，不展示答案 |
| 5 | 一次循环，需要多久？ | 环形作业循环与四个步骤，60秒示例 |
| 6 | 从秒/箱，换算为箱/小时 | 米白演算页，3600÷60，由教师点击展开 |
| 7 | 设备在场，岗位是否到位？ | 设备与岗位配对，取可用数量 |
| 8 | 下一环节，能接住多少？ | 有限缓冲箱流，接续条件 |
| 9 | 能做多少，与已经做了多少 | 能力线与累计完成量并置 |
| 10 | 先约定，比较什么 | 对象、起点、终点、时窗四项标注 |
| 11 | 把一条箱流铺开 | 岸桥—运输—堆场链 |
| 12 | 60、40、50，谁决定持续产出？ | 三段能力条，暂不揭示最小值 |
| 13 | 运输每小时只能接走40箱 | 流量推导及积压动画 |
| 14 | 岸桥到90，出口仍只有40 | 单项变化对照 |
| 15 | 运输到60，约束移到堆场 | 40→50的产出变化 |
| 16 | 这个结论，需要哪些条件？ | 单箱流、同口径、稳定状态与现实边界 |
| 17 | 同一艘船，同一个起点 | S01与116/78箱；条件已核验 |
| 18 | 先预测A：两台岸桥、两个运输岗位 | 资源图，独立预测 |
| 19 | 运行A，追踪一条交接 | 教师演示入口，暂停观察点 |
| 20 | 一小时后，箱子停在哪里？ | 实际A快照，完成量与岸侧数 |
| 21 | 只多分配一台岸桥 | A/B配置差异，预测保持隐藏 |
| 22 | 运行B，先看局部，再看整船 | 教师演示入口 |
| 23 | 卸得更快，为什么结束更晚？ | A/B完成时间与一小时进度对照 |
| 24 | 修订判断，保留证据 | 假设—观察—解释，结束上半讲 |
| 25 | 六辆车，每辆处理两分钟 | 服务点示意；定义到达、开始、结束 |
| 26 | 每两分钟来一辆 | 均匀到达时间带 |
| 27 | 六辆车同时到达 | 集中到达队列动画 |
| 28 | 平均等待，怎样算？ | (0+2+4+6+8+10)/6=5分钟 |
| 29 | 同样忙碌，等待可以不同 | 两张时间带并排，忙碌12分钟 |
| 30 | 没在作业，不只有一种原因 | 作业、无任务、受阻、待核查 |
| 31 | 检验你的运输瓶颈假设 | 个人任务，参考A与待执行C |
| 32 | 什么结果能够推翻你？ | 中性假设提示，不代写结论 |
| 33 | 起点相同，只把2改为4 | 配置差异确认 |
| 34 | 开始自己的C方案 | 学生入口，操作与记录要求 |
| 35 | 先对账，再解释 | 完成时间、完成量、等待口径 |
| 36 | 用一条记录支持一句解释 | 提交简短解释；不代替实机记录 |
| 37 | 把个人结果放回同一张图 | 参考记录与个人运行区分 |
| 38 | 运输岗位2→4，发生了什么？ | 正式A/C运行曲线与终点 |
| 39 | 继续增加到8 | D配置及结果 |
| 40 | 从8到12，终点为什么没变？ | D/E对照，局部箱数仍不同 |
| 41 | 看曲线，不能只看最后一个数 | 生成记录的累计装卸曲线；D/E重合处用不同线宽显示 |
| 42 | 原来的约束减弱后，谁接过限制？ | 岸桥工作与箱流证据；不预设因果 |
| 43 | 改善，要同时回答三件事 | 改了什么、改善什么、付出什么 |
| 44 | 新情境：岸侧变少，堆场入口变多 | 教学迁移情境，非实测记录 |

| 46 | 支持什么，还不能推出什么 | 公开条件化解析 |
| 47 | 给调度主管一份建议 | 判断、证据、边界、下一轮比较 |
| 48 | 卸船更快，堆场为什么仍会积压？ | 黄昏港区全景，衔接第6讲 |

## 已实现的课堂控制

独立授课台路径为 `/port-lesson-five-preview.html`，正式课堂选择第5讲可进入全局198—245页。授课台含48页教师稿、页码跳转、纯投影及A—E演示入口。个人C实验可从第34页、学生课堂与课下学习进入。

24页有时间进度。第6/28页演算停在首步，教师点击播放或下一幕；其他场景动画首次进入1秒后播放一轮。第45页解析单独手动揭示。所有实验均只加载冻结现场，点击推进才开工。减少动态效果设置会展示完整图解。

播放控制与正式课堂控制栏共用位置；课堂与同步投影只接收公开进度。实验返回恢复来源页和页内进度，学生个人记录不进入教师演示记录。演示结束不标记学生完成。

## 实施与评价

个人任务只执行C；A为已标注的教师参考记录。教师预先准备A—E的复现记录，课堂可按观察点推进，不让计算等待占用讲授时间。操作故障时使用A/C记录分析，须标注完成方式。

离堂解释按三项核验：比较条件明确；结论对应具体记录；提出可推翻原判断的后续观察。无需用排名、点击数或仿真总分评价。

## 验收门

逐页学生文案审计；48页身份与90分钟检查；实验复现；教师/学生提示词与答案边界；桌面及390px全页浏览；动画与导航；类型检查、相关测试、生产构建和diff检查。最终报告不得把静态检查称为课堂运行验收。
