# 经济数学课堂版本入口修复

日期：2026-10-16。

## 原因与处理

第五、六讲重构后，课程发布版本为 `release-economic-mathematics-foundations-depth-2026-10-16`，共656页。
10月14日创建的旧课堂仍使用560页的 `release-economic-mathematics-limits-reinforcement-2026-10-13`。
原界面将归档状态显示成“重新同步”，而课程工作区的继续操作又会返回旧课堂，形成刷新循环。

- 识别已知的历史版本，明确提示已归档；未知版本或当前版本页码冲突仍提供重新加载。
- 教师可点击“使用新版新建课堂”，新课堂从同一讲次首页开始，使用独立请求编号避免重试重复创建。
- 学生不显示开课按钮，可阅读新版课件或使用教师提供的新课堂链接。
- 开始／继续课堂只恢复兼容版本的经济数学课堂；其他课程的续课规则保持原有实现。
- 原课堂的版本、页面、实验状态和课堂状态保留，不把旧版页码换成新版位置。
- 归档提示采用紧凑居中布局，避免继承课堂主舞台的两行网格后将文字和按钮拉散。

- 前端231项测试通过，含版本保护、学生入口及隐藏控制检查。
- 经济数学、课堂恢复和工作区接口9项测试通过，含重试、续课、服务器重启和旧记录保持。
- 全工作区类型检查、Vite生产前端构建、`git diff --check`通过；没有重新生成全部课程PDF。

- 从课程工作区点击“开始／继续课堂”返回同一新版会话，刷新后正常恢复。
- 原课堂保存的会话与运行时值在开课前后逐项一致；备份与结果位于忽略目录 `output/classroom-version-recovery-2026-10-16/`。
