## 2. 课程定位

### 2.1 课程要回答的核心问题

港口不是单一的装卸场所，而是船舶、货物、陆侧网络、资本、制度、城市和生态约束相遇的复杂系统。课程以“一票集装箱随一艘班轮完成进港、靠泊、装卸、堆存、集疏运与离港”为贯穿主线，再用散货、液体散货、滚装、冷链、客运和危险货物港口作对照，引导学生回答四类问题：

1. 港口如何创造并分配价值；
2. 作业链的瓶颈、风险和绩效如何识别；
3. 治理、竞争、数字化与绿色转型如何改变决策；
4. 面对不确定性，下一笔投资应投向哪里、依据是什么。

### 2.2 课程知识骨架

课程内容综合采用以下互补骨架，而不把任何一本教材当作唯一答案：

- [Port Economics, Management and Policy（第二版）](https://porteconomicsmanagement.org/pemp/contents/)用于航运网络、码头、腹地、治理、竞争、绩效、规划、数字化和港城关系的系统框架；
- [World Bank Port Reform Toolkit（第三版）](https://www.worldbank.org/en/topic/transport/publication/port-reform-toolkit)用于港口治理、私营参与、监管、融资、劳工、环境、数字化和港城关系；
- [UNCTAD Port Management Programme](https://tft.unctad.org/en/programmes/port-management/)用于“真实港口问题诊断—证据分析—可执行建议”的项目制组织；
- Burns 的 *Port Management and Operations*、Alderton 的 *Port Management and Operations*，以及中国港口经济、管理与装卸工艺教材用于补足运营、设施、价格、风险和中国情境；
- 现实主张优先来自交通运输部、IMO、UNCTAD、世界银行、港口管理机构和港口企业的一手资料，具体边界见[资料与证据台账](./port-management-evidence-ledger-v1.md)。

### 2.3 课程性质

- 定位为“概论 + 决策入门”，不替代港口工程设计、航海操纵、危险货物专业资质训练、生产调度系统培训或法律意见。
- 数量分析以能解释决策为限，要求学生理解单位、口径、约束和不确定性，不要求先修运筹学或强化学习。
- 仿真是概念模型和可复现实验环境，不是数字孪生、实时 AIS、工程设计或生产控制系统。

## 3. 先修要求与学习支持

### 3.1 建议先修

- 具备运输系统、物流或管理学的基础概念；
- 能使用电子表格完成比例、平均数、利用率和情境比较；
- 能阅读中文官方资料，并借助术语表阅读英文图表与摘要；
- 能在小组中记录分工、版本、来源和决策理由。

不要求学生会编程。涉及队列、瓶颈、折现、排放和多目标权衡时，课程提供公式卡、示例数据、无代码界面或纸面模板。编码训练仅作为 Agent Lab 的选修拓展。

### 3.2 学习支持

- 开课前发布中英双语术语表、证据卡模板、单位与口径检查表；
- 第 3 讲后完成仿真入门和一次无分数演练；
- 对无法稳定运行软件的学生提供等价的事件卡、状态表和预生成运行包；
- 对项目组提供案例池、最低一手资料清单和来源复核日期；
- 数字人或课程助手只在已批准知识边界内提供概念解释、资料定位和可解释建议，不能替学生作安全授权、工程判断或最终投资结论。

## 4. 课程学习成果

完成课程后，学生应能够：

| 编号 | 可观察的学习成果 |
|---|---|
| CLO1 | 用港口—航运—腹地网络解释港口的功能、价值来源及其对区域经济的作用边界。 |
| CLO2 | 绘制集装箱航次的完整港口作业链，识别前置条件、资源耦合、瓶颈和故障传播。 |
| CLO3 | 比较集装箱、干散货、液体散货、滚装、冷链、客运和危险货物作业对设施、流程、风险与服务的不同要求。 |
| CLO4 | 在需求、能力、区位、竞争、治理、融资、环境和港城约束下提出分期规划或经营方案。 |
| CLO5 | 解释周转时间、吞吐量、利用率、可靠性、成本、安全、排放和韧性等指标的口径，避免用单一排名替代完整绩效判断。 |
| CLO6 | 识别港口安全、保安、网络安全、能源与环境的硬约束，并说明哪些目标不能用效率收益交换。 |
| CLO7 | 用固定情境和种子比较人工、规则与 AI 策略，报告原始指标、波动、约束违例和跨情境表现，而不是追逐单次最高分。 |
| CLO8 | 围绕真实港口问题建立可追溯证据链，形成可复现的分析、投资建议和个人答辩。 |

## 6. 贯穿式项目

### 6.1 项目任务

4—5 人自愿组队，从一个真实港口的可证问题出发，最终回答：“在既定安全、环境、治理和资金约束下，下一笔投资或管理改进应优先解决什么问题，为什么？”

项目必须依次交付：

1. 真实问题与证据档案；
2. 流程、资源和瓶颈模型；
3. 可复现的仿真或纸面情境；
4. 人工、规则和 AI 策略对照；若 Agent Lab 尚未可用，则比较两种人工规则并用预生成 AI 运行包作审计；
5. 安全、绿色与治理分析；
6. 分期投资建议、风险、触发条件和反证。

### 6.2 审核案例池

- 重庆果园港：内河枢纽、多式联运与港城发展；
- 上海洋山港：自动化集装箱码头与海港区位；
- 新加坡港／大士港：枢纽港、分期建设与数字化；
- 鹿特丹港：港口协同、能源转型和港城关系；
- 比雷埃夫斯港：综合港业务、治理与区域门户；
- 洛杉矶／长滩港：港群竞争、空气质量、卡车与社区约束。

其他选题须在第 3 讲前通过审核，最低条件是：存在可公开核验的一手资料；问题规模适合本科课程；不依赖保密生产数据；能够说明数据期间、口径和局限。案例池仅规定材料充分性，不预设褒贬结论。

### 6.3 角色与贡献证据

每组至少设置并轮换以下职责：项目协调、资料与来源、流程与实验、风险与治理、展示与复现。每名学生维护个人贡献日志，记录日期、版本、产出链接、关键判断和被组内采用或否决的理由。团队共同署名不自动等于相同个人得分。

### 6.4 里程碑

| 截止点 | 必交物 | 验收要点 |
|---|---|---|
| 第 3 讲后 | 案例登记卡与 3 条一手来源 | 问题可证、来源可访问、无实时数据假冒。 |
| 第 4 讲后 | 证据档案 V0.1 与作业链 | 事实、推断、教学设定分栏；标出证据缺口。 |
| 第 6 讲后 | 流程与瓶颈模型 V0.2 | 资源、队列、前置条件、单位和反例明确。 |
| 第 8 讲后 | 情境与分期方案 V0.3 | 基准、乐观、压力情境可复现；参数有来源类型。 |
| 第 11 讲后 | 指标板与实验计划 V0.4 | 指标口径、比较基准、种子和停止规则预注册。 |
| 第 14 讲后 | 安全—绿色—治理审查 V0.5 | 硬约束不进入可交易奖励；责任主体清楚。 |
| 第 15 讲后 | 冻结实验包 V0.9 | 输入、版本、种子、事件、原始指标和局限齐全。 |
| 第 16 讲 | 最终报告、展示包、个人答辩材料 | 建议与证据对应，能复现、能反驳、能区分贡献。 |

## 7. 评价方案

### 7.1 成绩构成

| 构成 | 权重 | 评分内容 |
|---|---:|---|
| 团队项目成果 | 45% | 问题与证据档案 8%；流程与瓶颈模型 10%；实验设计与可复现性 10%；安全—绿色—治理与投资建议 12%；展示和交付质量 5%。 |
| 个人答辩与贡献核验 | 25% | 方法与关键决策解释 10%；来源、口径和局限回答 6%；个人贡献日志及版本证据 5%；对质询或反证的回应 4%。 |
| 个人基础任务 | 30% | 6 次证据／计算短任务，每次 3%，共 18%；3 次概念与边界检查，每次 4%，共 12%。 |
| **合计** | **100%** |  |

### 7.2 评分原则

- 评价推理、证据质量、约束意识和可复现性，不奖励单纯高仿真分数。
- 仿真本地分数只用于诊断；不得直接写入正式成绩，也不得以操作次数、单次最高分或“完成动画”替代业务结果。
- 若建议使用现实数字，必须同时给出单位、地区或对象、统计期间、口径、来源编号和访问日期。
- 法规、统计和政策未在当期开课前复核时，只能作为历史版本材料，不得表述为“当前有效”。
- 严重混淆真实生产数据与教学设定、伪造来源或隐去安全约束的部分不得获得对应“证据与可复现性”分；是否构成学术诚信问题按学校制度另行处理。

### 7.3 个人贡献区分

个人项目分不是团队分的机械复制。教师以四类证据综合判断：版本记录与贡献日志、个人提交的关键页、随机抽取的模型或来源解释、对反事实追问的回答。若个人无法解释其署名部分，可下调个人答辩与贡献核验分，但不据此连带下调其他成员。

## 8. 仿真与 AI 的课程规则

### 8.1 当前可用范围

当前 V1.0 主要服务第 3—6、11、15 讲：提供确定性集装箱码头情境、角色命令、事件记录、回放和诊断性多维评分。现有能力和限制以[仿真课程路线图](./port-simulation-curriculum-roadmap-v1.md)的“已验证基线”为准。

### 8.2 课堂使用底线

- 运行引擎是业务状态的权威来源，动画只是投影；
- 安全前置条件和合法动作由环境硬约束，不用奖励扣分替代；
- AI 默认只提出可解释建议，由有授权的学生确认；
- 自动执行仅限隔离的实验沙箱，不连接真实港口设备或生产系统；
- 所有比较保留情境版本、策略版本、种子、原始指标和异常记录；
- 每讲必须准备不依赖软件的等价活动，软件故障不能取消学习目标。

### 8.3 未来能力不得提前冒充

参数化情境、服务端确定性复算、扩展货种、成本与排放、Agent Lab、掩码 PPO 等均是计划能力。教师在上线验收前必须明确标注“计划”或使用预生成材料，不能把路线图描述为已经部署的功能。

## 9. 证据治理

课程资料统一标注为“史料、官方资料、教学情境、路线示意、概念模型”之一：

- **史料**：说明历史事件或当时制度，不自动证明今天仍然如此；
- **官方资料**：可证明发布机构在特定日期和口径下公开的事实或立场，不自动证明因果关系；
- **教学情境**：为练习而设的参数、事件和角色，不得称为真实生产记录；
- **路线示意**：帮助理解空间关系，不用于导航、海图或工程测量；
- **概念模型**：用于解释机制和比较方案，不等于生产级数字孪生。

每个现实主张都应能回指[资料与证据台账](./port-management-evidence-ledger-v1.md)的来源编号。课程开始前按台账刷新法规、统计、政策和港方资料；无法复核的材料降级为历史案例或删除相关当前性措辞。

## 10. 实施条件

### 10.1 建议班级组织

- 建议每班 30—50 人，每组 4—5 人；
- 可使用普通多媒体教室；有稳定网络和每组一台电脑时使用在线仿真；
- 第 4、5、6、11、15 讲优先安排可分组讨论和投屏的教室；
- 教师端保留纸面活动包、预生成运行包和离线来源摘要。

### 10.2 教师开课前检查

1. 确认第 1—3 讲课件版本、119 页页序和运行方式未被本设计包改变；
2. 按资料台账复核法规、统计、政策、港方页面和链接状态；
3. 验证仿真版本、情境、固定种子、回放和导出；未通过的能力标为计划；
4. 检查所有教学参数的来源类型，删除任何“实时 AIS”“真实调度数据”等无依据标签；
5. 准备每讲的无软件备用材料；
6. 公布评价量规、贡献日志模板、AI 使用规则和学术诚信要求。

### 10.3 最低可开课条件

即使全部计划软件能力尚未完成，只要具备锁定课件、公开来源包、纸面情境卡、状态—动作记录表、预生成实验结果和项目模板，16 讲仍可完整开设。软件增强的是反馈速度和可复现性，不是课程成立的前提。
