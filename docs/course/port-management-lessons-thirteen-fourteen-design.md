# 第13—14讲：通关与保税业务教学设计

实施日期：2026-10-19。两讲分别32页、40页，各90分钟，均分为两个45分钟教学段。课程既有第1—12讲页码保持稳定；第13讲全局550—581，第14讲582—621。第15—16讲继续保留规划状态。

## 连续故事与知识递进

澄江机电、海岚港和A/B/C货票为独立编写的教学情境。三票有各自的运输、申报和库存身份，不假定同一货票可任意拆分改变状态。

- A急用件：从卸船、相关放行、承运人交付、码头可作业到运输接续，形成到厂时间判断。
- B备货件：以期末全部内销的简化情境比较直接进口与保税安排的资金时间价值和增量成本。
- C分拨件：境内外去向未定，重点核查分拨服务、适用条件和客户需求；不直接套用B货计算。

第11讲的时间端点、瓶颈和反事实比较进入第13讲；第12讲的可信记录、授权和条件进入货物状态判断。第13讲交付“延误诊断及下一步行动”，第14讲交付“物流路径及有条件的经营建议”。不新增独立仿真内核、试验轮次或成绩提交。

## 第13讲的推理链

1. 6时卸船、8时30分海关放行，不足以承诺16时到厂。
2. 从六类主体的责任接口识别应查询的记录。
3. 1,000套与100箱×10套先统一单位；980套的修订资料需要核对实际货物，不能改成一致。
4. 将申报、监管处置与运输作业放入并行泳道。依据2025年277号令与115号公告介绍提前及两步申报，避免只讲早期试点。
5. 海关手续段插入40秒新闻教学节选，观察高新技术货物查验安排的变化与条件；不视为普遍报关教程。
6. 教学四条件全部就绪后另需30分钟出闸；X/Y/Z三组记录比较，解释局部提速为何可能无效。
7. 分阶段发出回执，个人修订初判；用事实、影响、后续核查给生产经理答复。
8. 引出B和C是否需要立即全部进入国内市场。

## 数量关系与评价

四条件准备模型是教学简化：最晚准备时刻加30分钟，不含额外排队和其他窗口。X最早14:30出闸，另加道路运输3小时为17:30到厂；海关提前1小时不改变运输14时准备的限制。

B货给定延期税款100万元、年资金成本8%、一次性增量费用6,000元及每天100元，不反推真实税率，暂不展开抵扣和其他差异。30/60/90天净收益为−2,424.66 / 1,150.68 / 4,726.03元；60天6%为−2,136.99元。盈亏平衡约50.3天依赖固定假设。实际分批内销需使用逐步变化的余额。

评价证据、机制、条件和复核行动；选择直接进口或认为信息不足均可形成有效结论。不要求学生推荐同一区域或追求最大单项收益。
