# 《港口管理概论》资料与证据台账（V1.0）

> 台账基线日期：2026-08-09
> 用途：支持[课程设计](./port-management-course-design-v1.md)、[16 讲教学蓝图](./port-management-lesson-blueprints-v1.md)与[仿真课程路线图](./port-simulation-curriculum-roadmap-v1.md)中的现实主张、课程框架和案例选择。
> 重要边界：本台账是教学取证目录，不是法规汇编、工程数据库、实时港口数据源或系统接入清单。链接可访问不等于内容当前有效；法规、统计、政策和港方状态必须按复核周期重新确认。

## 1. 证据分类

所有进入课程的材料或参数必须标为以下一种：

| 类别 | 定义 | 课堂允许用途 | 禁止用途 |
|---|---|---|---|
| 史料 | 记录特定历史时期事件、制度、航线或观点的材料 | 复原历史问题、比较解释、讨论当时条件 | 直接证明今天仍然如此；省略争议或殖民强制背景 |
| 官方资料 | 政府、国际组织、港口管理机构或企业在特定日期公开的文件／数据 | 证明发布主体在相应口径下公布的事实、规则、目标或立场 | 自动证明独立绩效、因果关系、实施完成度或全行业普遍性 |
| 教学情境 | 为课堂推演构造的船舶、货量、时刻、成本、故障和角色数据 | 练习流程、决策、实验和复盘 | 冒充真实生产记录、实时 AIS、商业报价、事故概率或工程参数 |
| 路线示意 | 对航线、走廊、港序和腹地连接的教学化表达 | 理解空间关系、网络角色和替代路径 | 导航、海图、引航、航道测量或实时路径建议 |
| 概念模型 | 为解释机制而抽象的系统、公式、状态或指标 | 比较方案、检验逻辑、暴露假设 | 冒充生产级数字孪生、工程可研、法律结论或财务承诺 |

来源再按证据角色标记：

- **规范性来源**：法律、规则、标准、官方战略；说明“应当／目标／要求”，不自动说明实际结果；
- **描述性来源**：统计、港方设施页、企业公告；说明“在何时公开了什么”，不自动说明原因；
- **方法性来源**：教材、工具包、研究论文；说明分析框架或特定研究结果，不自动保证适用于所有港口；
- **教学性来源**：任务卡、仿真场景、预生成运行包；只在课程内有效。

## 2. 台账字段与引用规则

每个现实数字或事实至少记录：

| 字段 | 要求 |
|---|---|
| 来源编号 | 使用本台账的稳定 ID；课程文档以方括号回指。 |
| 发布者与标题 | 优先记录原始发布机构、正式标题和直接链接。 |
| 发布／版本日期 | 无法确认时写“页面未标明”，不得猜测。 |
| 访问／复核日期 | 本版统一基线为 2026-08-09；每次复核后更新课程运行副本。 |
| 支持主张 | 只写来源直接支持的最小主张。 |
| 禁止外推 | 明确来源不能证明的结论。 |
| 适用课次 | 方便教师按讲次复核。 |
| 更新周期 | 法规、统计、政策和动态案例优先于教材框架。 |

现实数字的课堂脚注建议格式：

> 指标名称｜数值与单位｜对象／地区｜统计期间｜口径或分母｜来源 ID｜访问日期｜边界说明

若材料只有二手转述，必须继续寻找一手来源；找不到时标“二手待核”，不得成为项目关键结论的唯一证据。

## 8. 项目证据档案最低标准

每组的最终证据档案至少包含：

1. **五条一手来源**：其中至少一条政府／国际组织资料、一条港口管理机构或运营主体资料、一条独立方法或研究资料；
2. **三个口径完整的现实指标**：对象、单位、期间、范围、来源和更新时间齐全；
3. **一条规范性约束**：注明管辖范围、版本和复核日期；
4. **两条竞争性解释**：同一现象至少有两个可能机制；
5. **一条反证**：说明出现什么事实会削弱或推翻当前建议；
6. **参数登记表**：所有仿真／纸面参数标为“官方观测、文献估计、由来源推导、教学设定、未知”之一；
7. **主张映射**：报告中每个关键主张回指来源 ID 或实验运行 ID。

来源数量不是质量替代。多个网页复制同一新闻稿只算一个证据链；检索摘要、搜索结果页和 AI 回答不得作为最终证据。

## 9. 情境参数登记

建议字段如下：

| 字段 | 示例含义 |
|---|---|
| parameterId | 情境内稳定参数名 |
| value / unit | 数值与单位；未知不得用 0 代替 |
| scope / period | 对象、空间范围和时间范围 |
| provenanceType | 官方观测／文献估计／推导／教学设定／未知 |
| sourceId | 现实来源 ID；教学设定可为空但必须写理由 |
| transformation | 汇率、价格基期、换算、抽样或校准步骤 |
| uncertainty | 区间、分布或“未知” |
| allowedUse | 本讲演示／项目比较／仅敏感性分析 |
| prohibitedUse | 生产、导航、工程、法律或实时判断 |
| reviewedAt / reviewer | 复核日期与责任人 |

现实观测与教学设定不得在同一列无标记混合。由现实资料推导的数值必须保存公式和原始值，不能仅保留结果。

## 10. 开课前复核流程

### 10.1 必做顺序

1. 检查法规和规则的现行版本、施行日期、废止／修订状态及正式发布机构；
2. 检查上一年度统计公报、CPPI、UNCTAD 报告及方法口径；
3. 检查港方设施、项目和战略页面的完成状态与目标年份；
4. 检查教材新版、论文正式卷期、勘误和可复现材料；
5. 检查所有链接，保存标题、发布日期、访问日期和必要的合规课堂摘要；
6. 更新逐讲来源包和参数登记；无法复核的内容降级为历史材料或删除当前性措辞。

### 10.2 更新频率

- 法律、行政规则、IMO 决议状态：每学期开课前 30 日内，并在相关课次前再看一次；
- 年度统计、CPPI、UNCTAD 年报：每年新版发布后；
- 港方项目、设施、服务和政策：每学期开课前；
- 排放因子、价格、汇率和技术参数：每次使用前；
- 教材与研究综述：每学年；
- 教学情境与运行包：每次版本发布或规则变更后。

### 10.3 链接失效与冲突

- 链接失效：先从发布机构站内检索标题或文号，不用未经核验的转载替代；
- 数字冲突：先比较单位、期间、范围、修订日期和原始／快报口径；无法调和则并列呈现并标“待核”；
- 港方与独立资料冲突：港方资料用于其设施和立场，独立资料用于外部评估，不能静默选择更有利的一方；
- 法规文本冲突：暂停当前性结论，转交教师按正式法律数据库和主管部门渠道复核；
- 仿真与现实冲突：现实证据决定现实主张；仿真只说明模型内机制和敏感性。

## 11. 课堂与数字人引用边界

- 回答现实数字时，数字人必须能给出来源 ID、期间、单位和边界；否则说“当前知识包不足以确认”。
- 回答法规时，必须说明本台账的复核日期，并建议查看当期正式文本；不得使用“绝对合法／违法”替代专业判断。
- 回答案例因果时，至少区分“公开事实、发布者解释、课程推断”；单一港方页面不能证明投资效果。
- 回答仿真时，明确引擎版本、情境／种子和教学属性；不声称连接实时 AIS、生产 TOS、PCS 或设备。
- 不大段复制受版权保护的教材或论文；课堂使用短引文、图表时遵守许可与署名要求，优先自制结构图并引用来源。
