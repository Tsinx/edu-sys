## 公开采购记录与PCA

Cardoso, M. (2013). *Wholesale customers* [Dataset]. UCI Machine Learning Repository. DOI [10.24432/C5030X](https://doi.org/10.24432/C5030X)，CC BY 4.0。原始文件来自[官方仓库](https://archive.ics.uci.edu/dataset/292/wholesale+customers)，原ZIP与CSV保存在本目录。文件哈希见[provenance-measurement.json](provenance-measurement.json)。本课派生变换、图形与计算不冒称为原作者结论。

440行，无缺失。输入六列为Fresh、Milk、Grocery、Frozen、Detergents_Paper、Delicassen（最后一列保留原文件拼写）。它们是年采购支出的货币单位，仓库未在此给出可自行改写的币种或具体观测年份。W001—W440只是原文件行序标签，不是稳定客户ID。

Channel=1餐饮酒店298行，Channel=2零售142行；Region=1里斯本77行，2波尔图47行，3其他316行。两列类别只辅助着色与分面，不参与PCA拟合。

本课主方案逐列log(1+x)，用全部440行的对数均值中心化、样本SD（n−1）标准化，再对矩阵做SVD。成分系数是单位特征向量，得分是中心化标准化记录乘系数。每一方向最大绝对系数约定为正，符号整体翻转不改变信息。相关载荷另外定义为变量与成分的Pearson相关；在本方案下为w×√λ，不混用共同因子载荷。

| PC2 | 27.1949% | 71.2727% |
| PC3 | 10.6984% | 81.9711% |
| PC4 | 10.1033% | 92.0744% |

六个特征值之和为6。课件用k=2作二维描述，同时披露k=3的增量。PC1强调乳品、杂货与清洁纸品；PC2强调生鲜、冷冻与熟食。它们是本输入尺度上的组合方向，不是客户价值、利润、原因或心理构念。

保留k维的重构为T_k W_kᵀ，全样本平方重构误差/(n−1)等于舍弃特征值之和。71.3%保留方差指标准化对数采购的总体样本变异，不是每位客户均保留同样比例，更不是利润解释率或测试集预测精度。满六维还原误差仅为浮点量级。

敏感性比较固定主方案的对数均值和SD，暂不含五条标准化向量范数最大的记录，再中心化拟合435行。排除行号与全部对照结果在`measurement-data.json.wholesale.sensitivity`披露；440行主数据与主结果仍保留。方向一致度为两个单位PC1向量内积的绝对值。此对照不是自动删极端值的依据。原值中心化、原值标准化、对数后标准化的保留比例对应不同方差对象，不据比例高低评选最佳方案。

当前是全样本描述。如果用于未来预测，预处理与PCA均应只在训练集拟合，随后固定变换到评价集。本讲没有宣称任何样本外预测成绩。

## 九点几何与复算
