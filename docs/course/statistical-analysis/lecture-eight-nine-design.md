# 第8—9讲教学设计

延续第6讲的服务响应、信息透明六道自编题，第8讲48页、第9讲52页，各90分钟。保持1600×1000画布、深墨蓝与暖纸白、原生可编辑统计图表、宋体标题和教师手动翻页。题项回答、相关、模型和解释依次出现，不从载荷表或拟合阈值开始。

## 第8讲：探索性因子分析与量表结构探索

开头重读原题和原始计分方向。先观察六题相关，再追问共同变异与独特变异。沿同一实例解释共同因子模型、适用研究问题、顺序数据和多分相关、KMO与Bartlett的有限用途、MINRES提取、因子数、斜交旋转、模式和结构矩阵、共同度、命名、题项取舍及报告。保留单独的判断页和后页反馈。

主分析仅使用原240份教学模拟的221份六题完整记录，保留S编号，T3反向。完整记录分析是演示中的透明选择，不声称缺失随机，也不把便利样本相关推广为总体结构。Pearson矩阵仅用于直观比较和经典KMO/Bartlett演示；实际提取使用多分相关和MINRES、oblimin。平行分析预先指定199次逐列独立置换，保留各题边际分布，每次重估多分相关，比较SMC替换对角后的特征值与95%参考分位。明确这种共同因子留数程序与第7讲PCA总方差规则不同。

难点各有证据：旋转前后重构相关一致；斜交共同度使用ΛΦΛ′；模式载荷不是简单相关；跨载荷和Heywood另设有公开标签的独立示意，不伪称主数据确有问题。成熟量表适用版本通常先检验已有结构，适配或新内容才有重新探索的理由。删除题项须兼顾内容覆盖，改变结构后的再次分析仍属于探索。

## 第9讲：验证性因子分析与结构方程模型入门

先把第8讲的候选结构写成可被拒绝的限制，再说明独立确认样本。逐步引入矩形、椭圆、残差和路径，解释定标、识别、顺序响应阈值和WLSMV。先检查收敛和参数可接受性，再读标准化载荷、因素相关、隐含相关与残差，最后解读χ²、CFI/TLI、RMSEA区间与SRMR。没有统一阈值“过关即有效”的结论。

确认样本为另一随机流生成的400份完整五级回答，编号C001—C400，六道R/T题的文字及选项保持一致。它不是原240份的切分，也不是实际追访。确认模型在分析前固定交叉载荷和题项残差协方差为零；生成数据有小幅T2跨载荷，以保留局部失配讨论。两因素与单因素报告同一估计方法的描述性拟合，不能直接相减WLSMV校正χ²。修正指数只支持提出修订假设，不能替代内容理由和后续验证。T1/R3与T2/R2都存在较大残差；两个不同参数的MI相同，不能以已知生成设置充当观测资料的唯一解释。

SEM段明确新增三道满意度自编题，不假称原六题包含结果变量。用同一400份九题教学数据演示测量模型与结构路径的区别，以及同一定标下直接项c、间接乘积ab和总项c+ab。区间采用WLSMV参数协方差的delta方法，不声称进行了bootstrap。用反向递归模型得到同一隐含协方差和拟合，说明横截面路径及显著乘积不足以确定因果方向。第10讲由此进入设计和识别。
