## 18｜平行变化假设
全局页564；键 stats-l12-18；讲内 31:03—32:26。

我们称之为跨队列的平行变化假设。它允许两类地区原有教育水平不同，所以不要求两条线从同一个高度开始；它要求的是，在没有相应暴露差异的世界里，高低地区的队列差距保持可比，而不是被另一项只作用于年轻人的因素改变。
