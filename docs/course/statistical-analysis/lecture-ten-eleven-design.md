# 第10—11讲：从可比较对象到店内变化

第10讲48页（451—498），第11讲48页（499—546），各90分钟。沿用16:10、1600×1000、深墨蓝/暖纸白、宋体标题、琥珀与蓝绿。新封面为原生门店图形，正文为可编辑表格、SVG和KaTeX，不把数值或文字烘焙成图片。

## 学习路径

第9讲以横截面路径不确定方向结束；第10讲改用门店培训决策，不把前讲满意度模拟伪装成企业追踪。先看到组间销售差额，再定义处理、反事实和ATT；观察基线差异后讨论条件可交换性、一致性、干扰与重叠，最后才使用匹配与加权。第10讲没有把诊断不理想的结果隐藏：59家培训店仅50家保留，9家未匹配；加权后3项绝对SMD仍大于0.1，不能宣布设计成功。

第11讲直接接住稳定经营能力这一缺口，展开同一批门店的24个月。先区分面板/重复截面、唯一键/缺失、店间/店内变化，再用独立两店三期概念例子逐项去均值，回到主数据的FE与双向FE。最后分开讨论可估计性、严格外生性、差异性时变混杂和门店聚类。RE与Hausman仅解释选择依据，避免“一次检验自动选模型”。政策时间、反事实变化与动态证据留到第12讲，不提前计算DID或事件研究。

## 案例与目标

120家固定门店，每店24个月；59家在第13月启动统一培训，61家未参加。净销售额单位为万元/店/月，不是利润、生产率或量表分数。第10讲每店使用前12月均值、培训前面积和中心区标记作X，后12月均值作Y。第11讲使用同一2880个唯一门店—月份键；G为稳定参加组别，D=G×1(月≥13)为生效状态。没有删行或为结果重新换样本。

第10讲ATT加权以全部59家参加者为目标，但识别与平衡限制必须同时说明；匹配只针对50家保留参加店。第11讲估计共同加性斜率，不无条件声称与前一讲ATT相同。主数据、概念图和风险反例均有公开区分；生成审计的潜在能力和常数作用只供教师核查，不进入助手当前页证据或学生投影。

## 数值程序

- 固定seed 20261017；Python/NumPy/SciPy单线程生成和预计算，课堂不拟合模型。
- logistic仅使用事先规定的培训前销售、面积和中心区，先标准化连续/二元输入以便数值求解；估计概率与未标准化输入模型等价。
- 1∶1最近邻、有放回、logit得分距离，卡钳为全样本logit SD的0.2倍；等距按门店编号。保存全部配对和未匹配对象。点估计不套普通独立t检验或朴素bootstrap区间。
- ATT权重：参加者1，比较者e/(1−e)，分别归一化组均值。SMD分母固定为原两组样本方差均值的平方根，二元变量同样声明该口径；不是临时更换标准化分母。ESS只概括权重集中。
- 加权区间：seed 20261018，499次门店非参数bootstrap，每次重新估计倾向模型；若数值求解失败则报错，不静默丢弃。百分位95%区间；门店独立同分布是演示推断假设，不是现实抽样事实。
- 面板三模型同样本、同结果、同生效状态，无额外控制或权重。门店和双向FE分别组内/双重去均值；简单双重去均值仅对当前完整无权重平衡面板使用。
- CR1协方差乘G/(G−1)×(N−1)/(N−K)，G=120，N=2880；K分别2、121、144（含吸收项）。区间参考t₁₁₉。该显式LSDV有限样本口径与某些软件默认自由度修正可能不同，不能假称完全复刻某软件默认SE。
- 独立核验从CSV重算汇总，以Newton法重估logistic、以完整虚拟变量QR回归和全矩阵聚类sandwich复核变换法；不只读取同一程序的结果互相比较。

生成机制刻意保留选择：参加由含扰动的前期销售、面积、中心区和潜在稳定能力影响。因此不能从生成审计声称三项X足以保证可交换性；选择还可能关联前期误差，静态FE严格外生性也没有被保证。所有表格均作为有条件的估计与诊断演示，不以已知生成常数充当“实证识别真值”。
