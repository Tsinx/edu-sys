# 第12—13讲：真实资料上的连续项目

已建设两讲各48页，第12讲全局547—594，第13讲595—642，均90分钟。延续1600×1000画布、深墨蓝与暖纸白、宋体标题及原生可编辑图表、公式与代码。新增项目模块独立于问卷测量和门店模拟模块。

## 问题、对象与教学衔接

第11讲结尾保留“固定效应之后，未处理变化怎样比较”的问题，明确第12讲换用真实资料；没有把模拟门店改称真实调查。统一项目使用1995 SUPAS公开处理版，研究1970年代INPRES小学建设。

主线：政策扩张 → 不同地区与出生队列的暴露 → 四格教育比较 → 跨队列平行变化与诊断 → 工资可观测者的共同样本 → 教育内生性 → 候选工具 → 第一阶段/简约式/2SLS → 弱识别与AR集合 → 可复现研究备忘录。

同一真实数据可以自然支持DID到IV的联系；不用两套互不相干的数据拼接方法目录。该案例存在后续复核与争议，保留真实弱结果，不把经典研究当作预先保证显著的答案。

真实资料只有1995年的一次结果调查。主要设计是**地区强度×出生队列**的DID，不是个人面板，也不是1974—1995追踪。年龄队列剖面明确标为暴露诊断；没有伪造政策前后日历记录或错位实施日期。日历事件研究与现代多期DID在33—35页解释其变量、基期、比较污染与资料要求，不冒称本项目已经拟合。

四格入门规格使用来源自带recp高低强度，而不是按结果重分组或把低组说成零处理。权重为调查观测权重，人数用实际记录数。地区CR1聚类配t289区间，未声称完整重建复杂抽样设计。

## 数据、计算与诚实边界

固定版本、hash、变量字典、行数与处理规则在学生包的DATA.md及[sources-policy.json](sources-policy.json)。原始文件只读，项目包提供固定下载与校验程序，不再分发许可未明的原始微数据。第一次准备后可断网运行。

教育主样本78470、工资共同样本31061、出生地区290。当前四格权重版教育差分约0.036年且不精确。工资共同样本第一阶段约0.115年，稳健诊断约0.555，工具弱；IV点估计约0.136，但AR的95%集合为全体实数。

这些是本课堂明示规格的实际计算，不是原论文完整复制、也不是对整项政策的精确否定。公开处理版、简化规格、连续强度未使用、原论文与后续复核的差异均明确记录。不能把本模型教育差分说成“每千儿童多一所学校”的剂量效应。

## 跟做与逐字稿

每讲55分钟讲述、25分钟个人操作、10分钟观察判断。6个操作点依次留4、4、3、4、5、5分钟；其他页面观察预算合计10分钟。课前另留环境与数据准备时间，避免安装挤占正式授课。无AI也可执行完整代码；有AI时使用明确的数据、样本与方法约束。

96页逐字稿逐页编写，分别10365与9895汉字。每页3段，含承接、指图/解释顺序与翻页转场，停顿另列。独立Markdown和课堂教师备课区使用同一稿源。稿件不放入学生ZIP、投影、PDF正文或助手提示。按当前页公开证据编译助手上下文，保留后页判断反馈隔离。

字数与页内秒数是备课估计，不冒充真人朗读计时或实际课堂试讲。真实课堂的设备、安装差异、学生基础与跟做速度仍需教师现场试讲评估。
