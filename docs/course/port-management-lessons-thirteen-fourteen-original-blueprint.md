# 第13—14讲原始蓝图归档

2026-10-19按用户选题调整为通关与保税业务。下文是调整前的数字化、绿色主题，不作为现行课件或当前实验能力说明。

## 第 13 讲　自动化为什么不等于智能化？

**驱动问题：** 自动执行、信息互联、状态感知、预测和自主决策分别解决什么问题，为什么不能都叫“智能港口”？

**学习目标：**

- 区分设备自动化、TOS、PCS、海事单一窗口、数字孪生和 AI 决策的对象与边界（CLO5）；
- 从数据语义、时效、质量、互操作和网络风险评价数字系统（CLO6）；
- 设计人工、规则与 AI 策略的公平、可解释、可复现实验（CLO7）。

**概念链：** 传感与执行 → 设备控制 → TOS 作业协同 → PCS 社区协同 → 单一窗口申报 → 状态模型／数字孪生 → 预测与优化 → AI 建议／自动执行 → 人类授权与问责。

**真实案例与来源：** 洋山四期公开的远程岸桥、AGV、轨道吊和 ITOS 说明设备与系统组合 [CASE-YANGSHAN-IV]；新加坡海事数字孪生用于理解实时／历史数据、仿真和“what-if”定位 [CASE-MPA-DT]；IMO 海事单一窗口自 2024-01-01 起成为国际航运申报要求的背景材料 [IMO-MSW-2024]。2026 年 IMO 相关数字化／网络安全措施须区分“已批准”“待通过”“已生效” [IMO-DIGITAL-2026]。

### 90 分钟节奏

| 时间 | 用时 | 教学段落与动作 |
|---|---:|---|
| 0—8 分 | 8 | 将六个系统功能按“自动化／信息化／智能化”分类，并记录争议。 |
| 8—22 分 | 14 | 区分设备控制、TOS、PCS 和海事单一窗口的用户、数据与责任。 |
| 22—36 分 | 14 | 用一条错误数据链分析标识、语义、时效、接口和数据质量。 |
| 36—50 分 | 14 | 比较可视化、仿真、数字孪生与生产控制，明确同步和验证要求。 |
| 50—68 分 | 18 | 设计人工、规则和 AI 三种策略的同情境对照及原始指标。 |
| 68—82 分 | 14 | 讨论建议模式、人工确认、动作掩码、自动执行和问责。 |
| 82—90 分 | 8 | 写出一项适合自动化的任务和一项必须保留人工授权的决定。 |
| **合计** | **90** |  |

**课堂活动与实验：** 各组领取同一状态快照，分别扮演人工调度员、固定规则和“黑箱高分策略”。先比较动作，再要求每种策略提供可审计理由、合法动作证据和失败条件。

**仿真与降级：**

- 当前：V1.0 是确定性教学仿真，支持人工命令和回放；不具备生产 TOS／PCS 接口、实时同步或训练型 Agent Lab。
- 计划：统一 reset—observation—legal actions—step 接口；提供人工、规则和预训练掩码 PPO；全体学生在无代码界面调整目标权重，编码训练为选修。
- 备用：使用同一组状态—合法动作表和三份预生成策略轨迹，手工审计决策。

**项目里程碑：** 提交公平对照实验预注册：情境版本、策略版本、种子集合、允许信息、合法动作、原始指标、停止规则和失败判据必须相同或明确解释。

**课后任务：** 选择 TOS、PCS、单一窗口或数字孪生之一，写“用户—输入—输出—时效—责任—不能做什么”六栏卡。

**常见误区：** 无人化等于智能化；数据更多必然更好；可视化大屏就是数字孪生；AI 分数高即可自动执行；PCS 与 TOS 是同一系统；已批准文件等于已生效法规。

**数字人回答边界（助手知识边界）：** 可解释概念和审计给定策略；不得宣称 V1.0 与真实系统实时相连，不得生成生产系统操作或网络接入方案，不得将研究论文的实验结果说成行业部署事实。

## 第 14 讲　港口如何在效率、能源与城市之间取舍？

**驱动问题：** 岸电、替代燃料、设备更新或流程优化带来的减排，如何与成本、可靠性、劳工和港城影响一起判断？

**学习目标：**

- 建立清晰的排放边界、活动数据、排放因子和基准情境（CLO5、CLO6）；
- 比较岸电、替代燃料、设备电动化、靠泊优化和集疏运改善的适用条件（CLO4、CLO6）；
- 将社区空气质量、土地、交通、就业和公平纳入投资决策（CLO4）。

**概念链：** 活动边界 → 能源使用 → 排放清单 → 船／港／腹地措施 → 生命周期与电力结构 → 成本和可靠性 → 劳工转型 → 港城外部性 → 多准则决策。

**真实案例与来源：** IMO 2023 温室气体战略用于说明港口在岸电、替代燃料基础设施和港口调用优化中的支持作用 [IMO-GHG-2023]；港口排放清单方法参考 IMO 工具包 [IMO-PORT-EMISSIONS]；鹿特丹岸电与洛杉矶／长滩清洁空气行动用于观察具体措施和港城约束 [CASE-ROTTERDAM-SHOREPOWER] [CASE-LALB-CAAP]。项目公告不自动证明全生命周期净减排。

### 90 分钟节奏

| 时间 | 用时 | 教学段落与动作 |
|---|---:|---|
| 0—8 分 | 8 | 在“更快周转／更低能耗／更少社区暴露”三目标中先分配预算权重。 |
| 8—23 分 | 15 | 建立船舶靠港、码头设备、车辆和购入能源的排放边界与口径。 |
| 23—38 分 | 15 | 比较岸电、替代燃料和设备电动化的前置设施及边界条件。 |
| 38—53 分 | 15 | 分析准班、港口调用优化、等待和设备利用对能源的影响。 |
| 53—68 分 | 15 | 加入劳工技能、卡车交通、空气质量、噪声和土地等港城影响。 |
| 68—82 分 | 14 | 多准则决策：在硬约束下比较三个投资组合并做权重敏感性。 |
| 82—90 分 | 8 | 写出建议、受益者、成本承担者和一项需持续监测的副作用。 |
| **合计** | **90** |  |

**课堂活动：** 各组使用同一活动数据，但分别采用港口运营、船公司、城市社区和劳工视角。公布权重后进行一次敏感性分析；安全和法定排放限制不参与权重交换。

**仿真与降级：**

- 当前：V1.0 没有经来源校准的成本、能源或排放模型，不能用资源分推导现实减排。
- 计划：情境工作台增加活动量、能源、排放因子、成本、气象和社区暴露；输出原始指标并记录边界、年份和来源类型。
- 备用：使用活动数据表、排放因子卡、投资组合卡和多准则矩阵完成计算。

**项目里程碑：** 提交安全—绿色—治理综合分析 V0.5：至少一项运营措施、一项能源／环境措施、一项港城或劳工影响，并说明责任主体和监测指标。

**课后任务：** 对一项绿色港口主张完成边界审计：基准是什么、计算到哪里、排除了什么、谁受益、什么证据会推翻结论。

**常见误区：** 电动化自动等于零排放；岸电接入即证明全周期减排；替代燃料天然绿色；效率与减排永远同向；平均排放能代表社区暴露；绿色投资没有分配影响。

**数字人回答边界（助手知识边界）：** 可按给定边界计算情境排放；不得编造排放因子、能源价格或项目减排量，不得把教学计算用于环评、碳核算认证或设备选型。
