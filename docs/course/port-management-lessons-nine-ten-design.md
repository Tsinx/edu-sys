# 港口管理概论 · 第9—10讲建设说明

版本：`release-port-management-governance-market-v14`。第9讲390—437页，第10讲438—485页，各48页、90分钟；两段各45分钟，第24页后课间。前8讲页序和内容保持，第11—16讲仍待建设。

## 设计与学习成果

第9讲“谁拥有港口，谁承担责任？”从虚构起重机故障事件进入，先区分资产、权利和实际行为，再比较服务港、工具港、地主港及私人资产与经营的典型配置。借鹿特丹港务局与新加坡商业运营主体的公开资料练习主体识别，随后阅读虚构特许经营安排，讨论投资、支付、风险、监督、公共责任、调整和移交。

- 知识：治理职能、组织层次与合同构成。
- 分析：区分所有权、运营义务与公共监管，发现接口和责任空档。
- 应用：为给定问题写出主体、动作、证据和前提，不以模式名称替代归责或效率判断。

第10讲“港口怎样竞争、定价并赢得货源？”从降价仍未获得货源的疑问进入，辨认客户和竞争替代，固定同一货物及交付任务，比较全程现金、时间和可靠性。转入收费结构、成本与贡献，再讨论竞争响应、网络联系、合作边界及客户价值主张。结尾衔接第11讲绩效评价。

- 知识：派生需求、竞争层次、收费与成本口径。
- 分析：筛选可行方案，解释全程成本和可靠性，检验时间价值敏感性。
- 应用：形成包含客户、任务、收益机制、证据和复核条件的方案卡。

## 表现与授课方式

保持1600×1000画布，以场景引入、观察、判断、概念和应用形成每段链条。新增职能分层、合同关系、支付分解、全程成本、账单和交付分布6类SVG图解；复用既有教学复原插图，不声称为现场照片。关键数值直接标单位，模型结果不包装成港方统计或企业报价。

内容逐页编写，沿用前6讲的教师主导方式。教师拥有播放、暂停、下一幕、进度、选项与解析权限；动画入页2秒后播放，不自动翻页和揭示答案。学生课堂跟随与自主浏览分开，独立阅读没有教师控制台。教师稿、助手约束和作者字段不进入共享画布。课堂为个人口头或纸面判断，没有新增分组、代码运行、个人经营仿真或成绩提交。
