## 图形与数量口径

- 散货串联能力：输入均为同货种吨/小时，忽略波动和新增缓冲，只求固定串联系统持续能力。
- 冷藏箱：空位与可用插座为同一时点，20只箱每箱需独立插座，其他条件固定满足。
- 规划规模：使用同货种万实体吨/年，需求、有效能力和实际产出分别解释。
- 分期比较：两期各一年；费用为教学资金单位，不贴现，不计收益和运营成本；扩建时间简化在第8讲第40页明确修正。
- 地图：候选区位及旧仓库全部为虚构空间，不按比例，不表达真实地块许可。
- 代际：PEMP整理的研究框架，不作为国家标准、认证或排行。
