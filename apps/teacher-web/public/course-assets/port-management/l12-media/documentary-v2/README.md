180秒，1920×1200，H.264/AAC，30fps。入口 index.html；课堂由 PortElevenOpening 既有控制器承接。

以核验和交接动作进入职业责任，事故段只显示调查档案。现实作业与历史材料通过明确切点和短标识区分，不制造采访、事故同期声或违规人员指认。

实拍来源、许可、使用时间与事实范围在 storyboard.json 和播放器内逐一列明。原素材只存放于 ignored output/port-documentary-recut/sources，不作为公开素材集发布。素材人物不作为历史案件当事人，不合成采访。

编辑流程：scripts/port-documentary-author.mjs → port-eleven-speech.mts --documentary → port-documentary-film.mjs prepare / picture / mux / verify → port-documentary-player.mjs。第12讲额外传 --lesson12。既有 opening.mp4、storyboard.json、animation.js 等V1源文件保留在上级目录，legacy-index.html可对照。
