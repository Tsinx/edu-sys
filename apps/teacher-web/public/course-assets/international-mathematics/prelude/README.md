# ONE MORE

An original kinetic typography prelude for **Higher Mathematics: Calculus for Economics and Business**. A small business decision connects quantities, functions, rates and accumulated totals, then leaves the class with an unanswered question.

**36 seconds · 1920 × 1200 · 16:10 · 30 fps · H.264/AAC · English**

## Watch and use

Open `index.html` or play `one-more.mp4`. The page and editable animation work without an account, API or external fonts. Press Play to enable music. An English transcript, VTT and SRT accompany the film; captions are optional because the main words are already part of the image. The film intentionally uses typography and music without a spoken narrator.

The standalone page restricts scripts, fonts, media and connections to its own origin. All playback assets are bundled. The offline ZIP includes the complete viewer and source, separately from the existing v2 course package.

Use this once as a course opening or when returning to the connection between differentiation and integration. After the final question, invite a quick prediction. The existing sixteen lesson opening films remain available.

## Mathematical boundaries

These are illustrative models, rather than textbook quotations or real business data. Profit is `P(q) = 40q − q²` USD on `0 ≤ q ≤ 40` items. The average rate uses `[P(10+h) − P(10)] / h` for positive `h`; the local rate uses `P′(10) = 20` USD/item. Cash flow is `r(t) = 10 + 2t` USD/hour on `0 ≤ t ≤ 6` hours; its area has units USD. The final question has no answer shown. The course scope remains single-variable calculus; Jacques, ninth edition, Chapters 1, 2, 4 and 6.

## Edit and export

`animation.js` is the editable, explicit-time renderer. `player.js` provides the interactive timeline and local frame encoder. `player.css` contains the two bundled fonts; `storyboard.json` and caption files provide timed text. All preview and export frames use the same renderer; no animation depends on a random clock or uncontrolled CSS transitions.

In the repository, run:

```
node scripts/international-mathematics-prelude.mjs prepare
node scripts/international-mathematics-prelude.mjs serve
```

Open `http://127.0.0.1:5195/?export=1` in a browser supporting WebCodecs. Click **Render 1,080 video frames**. When complete, run `mux`, then `verify`, then `package` instead of `serve`. The exporter binds only to loopback and writes only its own frame and audit files. Node.js and FFmpeg are required to re-export; ordinary viewing needs neither.

For the standalone source package, run `node tools/export.mjs prepare --dir .` and `node tools/export.mjs serve --dir .` from its root. The same `mux`, `verify` and `package` commands work with `--dir .`.

## Design and provenance

The compositions, wording, graphs and deterministic synthesized soundtrack were created for this course. There are no stock clips or borrowed music samples. The style combines kinetic typography, strong geometric composition and restrained continuous transformations. Visual references: the creators’ [continuous transformation brief](https://jasonzhu.ai/en/prompts/claude-opus-5-5/2103273003555402193) and [motion graphics brief](https://jasonzhu.ai/en/prompts/claude-opus-5-5/2103151003272962130); model attribution belongs to those creators.
