# 青栀 · 手绘数字人基底 v1.3

2026-09-08。加入第一版流式 TTS 节奏口型与三场景试听。原创 SVG 漫画角色，经五轮静态修订，现已加入自然眨眼、轻呼吸和稀疏视线变化。角色采用墨青长发、翡翠虹膜、淡彩肤色、象牙白衬衣、植物刺绣披肩和金色宝石配饰。用户认可的静态 SVG 原件保持不变。

## 打开与文件

- `index.html`：直接用浏览器打开即可；SVG、样式、脚本和中文 TTS 测试样本均内嵌，不需要联网或安装依赖。
- `qingzhi.svg`：透明背景、900 × 1100 逻辑画布的原始矢量文件，166 个路径元素、41 个具名图层组，无位图。
- `qingzhi-transparent.png`：900 × 1100 透明 PNG，方便放入其他场景试排。
- `preview.png`：浅草色背景静态预览。
- `motion.js`：独立的 SVG 微动作控制器；连续眼睑形变、呼吸、视线和极轻的发梢跟随。
- `audio-lips.js`：独立 PCM 节奏分析与音频播放控制器。
- `audio-preview.js`：三组试听、模拟分片、抖动与断流检查。
- `audio-fixture.js`：现有中文 TTS 样本的内嵌 PCM；原句自称“澜舟”，并非青栀定稿声线。
- `preview.js`：审核页按钮、逐帧观察、系统偏好和页面生命周期控制。
- `sync-preview.mjs`：修改 SVG 或任一 JS 后运行 `node sync-preview.mjs`，将各源文件与测试音频同步到自包含 HTML。

在已有 teacher-web 开发服务下，地址为 `/avatar/handdrawn/qingzhi-v1/`。也可在本目录运行 `python -m http.server 8766 --bind 127.0.0.1`，访问 `http://127.0.0.1:8766/`。

## 审核页交互

默认自然微动。可切换自然 / 浅笑、半身 / 面部细节、浅草纸 / 深墨青 / 透明网格。

- **暂停微动 / 继续微动**：冻结当前帧，继续时从暂停位置播放。
- **停止回正**：停止所有动作，回到所选神态的静态基准。
- **眨眼一次 / 轻看一眼**：独立检查一个动作；静止状态下执行一次后停止，播放状态下结束后继续自然微动。
- **逐帧观察**：拖动眼睑闭合、呼吸幅度滑块检查静态中间帧。随后继续播放时，会在 0.65 秒内平滑回正再开始自然微动。
- 系统开启“减少动态效果”时默认静止；手动眨眼只显示闭眼静态图，滑块仍可检查姿态。运行时切换系统偏好也会停止动作。
- 页面隐藏时取消动画帧，恢复可见后从原位置继续；用户手动暂停的状态保持暂停。

新增“让声音，带动表情”面板，可直接试听纯 TTS、仅背景噪音、TTS ＋ 背景。“流式与噪声设置”支持分片抖动、650 毫秒断流、背景相对强度和播放音量。原有无声口型与手动滑块仍收纳在“原有口型试验”。播放不会自动开始；切换到后台、停止回正或手动检查口型会取消语音。系统减少动态效果时可以试听音频，但嘴部保持静止。

“保存这一帧 SVG”请求浏览器下载当前姿态的透明静态 SVG，包括眼睑、呼吸和视线位置；不包含背景或持续动画。动态版本是自包含的 `index.html`；`qingzhi.svg` 始终是原始静态母版。

## v1.3 节奏口型与噪声边界

第一版采用 **已知来源的独立 TTS 声道**：`TTS PCM → 能量包络 → SVG 嘴部`，同时 `TTS PCM + 背景 PCM → 扬声器`。背景不会进入口型分析。它不是混合音频的人声识别器，也不做音素、韵母或身份识别。将较响噪声误接到 TTS 输入会误张嘴；测试保留了这一反例，不能把声道隔离的结果宣传为通用降噪能力。

参数与行为：

- 24 kHz、单声道 PCM16 流可直接接入；独立模块还接受 16 / 48 kHz 的 Float32 PCM。
- 跨分片缓存，固定 20 毫秒分析帧。去直流的 RMS 包络，开门 0.004、关门 0.0025；低于关闭阈值连续两帧后关门。对已知 TTS 通道中的轻微底噪起门限作用。
- 开口攻击时间常数 25 毫秒、释放 55 毫秒，20 毫秒帧间插值；幅度限制在 0–80%，平静时还原用户选定的神态。说话时保留浅笑的眉形。
- 首次与断流后累积至少 120 毫秒 PCM，再提前约 35 毫秒排入播放。尾片可提前结束缓冲；网络层本身的生成、传输延迟另计。
- 每帧的口型与对应 AudioBuffer 使用相同起点，以 `getOutputTimestamp()` 推算实际输出进度。不可用时回退到音频时钟减估计输出延迟；这里没有测量扬声器到人耳的物理声画偏差。
- 断流时嘴部归零，补足缓冲后继续。停止会取消音源、分片定时器与口型动画；旧 `turnId` / 重复包忽略，乱序和非法采样明确报错，由上游负责重排或取消。队列限制约 15 秒，需要传输层施加背压。
- 音量只改变输出增益，因此静音观察时仍能看到同样的口型轨迹。手动口型、神态切换与停止回正会取得嘴部控制权。

**测试样本**：复用仓库 `artifacts/avatar/lanzhou/voice/lanzhou-preview.wav` 的实际 8.56 秒音频，两端各加一秒静音。原 WAV 使用流式占位长度，依据实际 PCM 字节修正测试副本，原文件未修改。页面嵌入 10.56 秒 PCM，以 70–160 毫秒分片重放。本轮没有调用在线 TTS 服务，也没有测试实时服务端到端延迟。

**2026-09-08 结果**：20 项音频与播放调度检查、23 项既有微动作检查通过。−18 / 0 / +6 dB 背景条件中，纯 TTS 与混合播放的口型在各播放观察帧的轨迹差均为 0；仅背景条件每组 1090 个播放观察帧均未张嘴。650 毫秒断流记到 1 次饥饿，闭嘴等待后播完。将同一 0 dB 噪声错接 TTS 通道的反例中，100% 分析帧触发了开口，明确显示当前方法的边界。

浏览器实际点击验证了 TTS 开口、仅背景播放至 2.110 秒仍为 0%、断流闭嘴与恢复、停止、试听后手动 100% 口型。桌面与 390 像素窄屏查看控件和图像，未见裁字或横向溢出；浏览器控制台无警告或错误。原始 SVG SHA-256 未变。验证脚本、指标与人工观察记录在 `output/avatar/qingzhi-audio-loop-2026-09-08/`。

## 接入项目中的流式 TTS

`audio-lips.js` 是可复用模块；当前仅在此独立审核页启用，没有替换课堂播放器。现有服务的 `speech.chunk` 已提供 `turnId`、从 0 开始的 `sequence`、`audioBase64` 和 24000 Hz 单声道 PCM16。接入时由该控制器统一承担该路语音播放，避免与原 `enqueueSpeech()` 重复播放同一声音。

```js
// 在用户点击“开始对话”等动作中创建并恢复 AudioContext。
const context = new AudioContext({ sampleRate: 24000 });
await context.resume();
const speech = QingzhiAudioLips.createPlayer({
  audioContext: context,
  onFrame: ({ amount }) => renderMouth(amount), // 宿主自己的 SVG 嘴部更新函数，0–100
});

// 每轮只 begin 一次；之后按序接收 PCM。
speech.begin({ turnId, sampleRate: 24000 });
function onSpeechChunk(event) {
  speech.pushPCM({
    turnId: event.turnId,
    sequence: event.sequence,
    tts: QingzhiAudioLips.decodePCM16(event.audioBase64),
  });
}
// 后台音乐/环境声走另一播放通道；不要把扬声器总混音作为 tts。
// 输入传完时调用 end；动画在最后一片实际播完后才结束。
speech.end(turnId);
// 用户打断时取消上游请求，并停止本轮播放。
speech.stop();
```

音频时间依据见 [MDN getOutputTimestamp](https://developer.mozilla.org/en-US/docs/Web/API/AudioContext/getOutputTimestamp)。

## 微动作参数与接入

参数按 900 × 1100 的 SVG 坐标计算，均为本角色的美术调试值。

| 动作 | 当前设置 |
| --- | --- |
| 眨眼 | 首次 2.8–4.2 秒，其后间隔 8–14 秒；单次 270–320 毫秒，闭合占 30%，完全闭合停留 13%，睁开占 57% |
| 呼吸 | 6.1–7.8 秒一个周期，周期和幅度略有变化；躯干以下边缘为锚点，肩部约上移 1.6 单位，头部最多上移 0.65 单位 |
| 视线 | 首次 10–15 秒，其后间隔 19–31 秒；水平 2.6–3.6 单位、垂直最多 0.8 单位；移动后停留 1.3–2.1 秒，再缓慢回正 |
| 发梢 | 随呼吸阻尼跟随，左右最大约 0.8 / 0.6 单位；y=470 以上根部不做局部形变，填色、轮廓、高光使用相同位移场 |

`motion.js` 暴露 `window.QingzhiMotion.create(svg, options)`，返回 `play()`、`pause()`、`stop()`、`blink()`、`glance()`、`previewBlink(0..1)`、`previewBreath(0..1)`、`suspend(boolean)`、`getState()`、`destroy()`。审核页实例为 `window.qingzhiMotion`。同一 SVG 只创建一个控制器。调用方负责把系统减少动态偏好、页面隐藏事件传给控制器；审核页已完成这些处理。

控制器使用一个基于时间戳的 `requestAnimationFrame` 循环，所有帧从原始路径计算，避免累计变形。`seed` 选项用于复现相同事件序列；`onChange` 用于接收播放、暂停等状态变化。`stop()` 恢复原始属性及路径字符串。此轮不增加侧倾、转头或眉部表情动作。

当前是单视角半身立绘与动作示意。未接入音频、音素对齐或真人动作捕捉；现有图层不等于完整的 Live2D 模型，也未制作侧面、转头或手势。
