# 港口仿真 V1.0：登录后本地单机版

V1.0 的默认交付模式为 `local_solo`。服务器只在页面进入时确认登录身份并读取课堂挑战；仿真时钟、命令校验、状态推进、计分、事件记录和存档均在学生浏览器完成，不建立小组席位、SSE、服务端仿真时钟或实时排行榜。

## 领域研究

港口、港区、码头、泊位、水域、陆域、前陆、腹地及设施对象的统一口径见
[《港口仿真领域框架与对象清单 v0.1》](../../../../../docs/design/port-simulation-domain-framework-v0.1.md)。

## 独立预览

启动 Teacher Web 后访问：

```text
http://127.0.0.1:5173/port-simulation-preview.html
```

独立入口默认展示 V1.0 本地单机运行器，同时保留浏览演示和 V0.05 协同兼容入口用于回归验收。正式入口为登录后的 `/simulations`，课堂 `simulation` Activity 也使用同一本地运行器。

## 组件边界

- `InteractivePortScene.tsx`：通用 SVG 视口、平移缩放、设施选择、分层高亮、键盘操作和演示运动层。
- `port-scene-camera.ts`：无浏览器依赖的相机与路径插值数学。
- `port-scene-types.ts`：场景、分层、实体、几何、详情与运动路径的公开类型。
- `yangshan-container-scene.ts`：港口总体环境与集装箱码头功能结构场景。
- `PortSimulationWorkspace.tsx`：共享态势、岗位命令和复盘信息的通用运行工作区。
- `LocalPortSimulationStage.tsx`：单人四岗位轮换、本地时钟、自动暂停、个人计分、复盘导出和个人历史入口。
- `local-port-simulation.ts`：版本化本地存档、恢复校验、个人历史和工作区投影。
- `StudentLocalPortSimulation.tsx`：登录课堂中的本地运行包装层；不认领小组或岗位席位。
- `ClassroomLocalPortSimulationStage.tsx`：教师发布挑战与说明本地运行边界，不监控学生过程状态。
- `port-simulation-sync.worker.ts`：浏览器内确定性事件回放、时钟推进和状态哈希校验。
- `usePortSimulationTeamSync.ts`：检查点、SSE、缺失事件补取、旧快照兼容与重同步编排。
- `@edu/port-simulation-core`：无 UI、无 I/O、可确定性回放的权威仿真内核。

后两个同步模块仅供 `network_teams_legacy` 历史运行兼容，V1.0 默认入口不加载或调用它们。

场景数据与相机逻辑相互独立。新增港口类型时优先增加新的 `PortSceneDefinition`，不要把设施布局写入相机组件。

## 交互

- 鼠标或单指拖动：平移视口。
- 滚轮或双指：以当前锚点缩放。
- 点击、`Enter` 或空格：选择设施。
- 方向键：平移；`+` / `-`：缩放；`0`：适应全景；`Escape`：清除选择。
- 演示动画在页面不可见、用户暂停或系统启用减少动态效果时停止。
- 纯手动模式中，视图动画不改变业务状态；只有已验证命令和引擎事件能够推进状态。

## V1.0 本地单机边界

- 同一名学生可在港调/VTS、泊位与岸桥、水平运输、堆场与闸口之间随时切换，所有有效命令都归入个人运行事件链。
- 页面载入后不发送心跳、席位续租、业务命令、状态快照或计分数据；网络中断不会停止已经载入的运行。
- 运行状态每次改变后写入浏览器 `localStorage`；关闭或重新打开页面时，正在运行的时钟会安全恢复为暂停，不按离线墙钟跳时。
- 页面切到后台时自动推进到当前时刻并暂停，避免浏览器节流期间错过管理决策。
- 最近30轮个人结果保存在当前浏览器；界面展示最近5轮和同案例历史最佳。
- 复盘 JSON 不包含姓名、登录标识或外部学号。V1.0 不自动上传成绩，浏览器本地成绩不能作为服务器认证成绩。
- 教师只发布挑战案例，不能远程暂停、接管或查看学生本地过程。旧多人模式代码保留，但新课堂发布 `deliveryMode: local_solo` 且服务端不创建队伍。

V1.0 设计见 [《港口仿真 V1.0 登录后本地单机运行说明》](../../../../../docs/design/port-simulation-local-solo-v1.0.md)。

## 历史兼容：V0.03 运行边界

- 4–72 名学生自动拆成 4–6 人小组；7 人明确采用“6 人运行组 + 1 名课堂观察员”。
- 四个唯一业务主操分别控制港调/VTS、泊位与岸桥、水平运输、堆场与闸口。
- 5 人组增加计划协调员，6 人组再增加安全与复盘员；协作席不能直接改变权威业务状态。
- 协作项使用独立 `collaborationRevision`，方案与提醒不会造成业务命令的无意义版本冲突。
- 岸桥拥有 `0–700` 标准化轨道位置、15 单位最小间距、移动时间、顺序约束和标准/大伸距匹配。
- 地图主选、计划选择、关联对象和风险提醒分别使用青绿、琥珀、青蓝虚线和珊瑚色描边，不覆盖设备状态色。
- 系统执行航行、装卸、运输、故障恢复等物理推进，但不代替学生分配资源。
- 不安全命令被拒绝并给出原因；低效但安全的决策会执行并形成等待、拥堵或延误。
- 学生命令使用岗位凭证、幂等请求 ID 和预期版本；教师接管会写入事件日志。
- V0.03 复盘基线只展示等待、忙闲、阻塞、响应和事件恢复；V0.05 在其上增加可解释总分与团队榜单。

V0.02 基线见 [《港口仿真 V0.02 纯手动协同运行说明》](../../../../../docs/design/port-simulation-manual-mode-v0.02.md)，V0.03 增量见 [《港口仿真 V0.03 弹性协作与岸桥轨位调度说明》](../../../../../docs/design/port-simulation-flex-collaboration-v0.03.md)。

## 历史兼容：V0.04 可靠运行边界

- 新运行采用服务端权威事件、SQLite WAL 检查点和浏览器 Worker 确定性回放；旧运行保持快照兼容。
- 每组拥有独立 `sequence`，命令确认前不会乐观改变正式界面；哈希或序号异常会禁用命令并重同步。
- 允许最多 15 个小组；教师端显示已确认序号、同步状态、延迟、重连次数和单组强制重同步。
- 身份由同源 HttpOnly 会话解析，客户端不再提交身份 ID；开发身份生产禁用，教学信息系统只预留适配接口。
- 岗位续租仅更新临时在线状态，不推进业务或协作版本，也不广播完整快照。

V0.04 增量见 [《港口仿真 V0.04 课堂可靠运行与边缘协同说明》](../../../../../docs/design/port-simulation-edge-sync-v0.04.md)。

## 历史兼容：V0.05 情境挑战与排行榜

- 内置“第一次联合值班”“稀缺岸桥的选择”“故障与高峰叠加”三个递进案例；案例版本与业务场景版本分离。
- 权威状态通过共享核心计算 1000 分可解释成绩，包含安全、任务、周转、资源、恢复和协作六个维度。
- 教师端提供课堂总榜、按 4/5/6 人编制分别排序的同编制榜，以及第二轮起生效的进步榜。
- 教师接管局保留完整复盘和练习成绩，但不进入正式排名；网络重连、事件补齐和幂等重复请求不扣分。
- 计分项保留权威事件证据 ID；学生可以点击计分维度查看支持该结果的事件，而不是只看到不可解释总分。
- 单机预览可以切换三个挑战案例，验证不同事件压力和任务简报，不写入课堂榜单。

V0.05 增量见 [《港口仿真 V0.05 情境挑战与可解释排行榜说明》](../../../../../docs/design/port-simulation-challenge-leaderboard-v0.05.md)。

## 公开边界

场景功能结构参考上港集团公开的洋山四期资料。公开资料中的7个集装箱泊位、2350米岸线，以及岸桥、AGV、自动化轨道吊生产工艺用于建立教学结构；图形、船名、任务、时刻、设备数量和位置均为原创或虚构教学示意，不是工程图、导航图或实时生产数据。
