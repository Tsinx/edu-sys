# Visual and technical references

The original illustrations were generated with the built-in imagegen tool. The 36 original prompts, PNG hashes and actual page/film references are supplied separately. Mathematical curves, formulas and measurements are generated from code; decorative objects in scene art are not data charts.

Visual references: [continuous transformations](https://jasonzhu.ai/en/prompts/claude-opus-5-5/2103273003555402193) and [bold motion graphics](https://jasonzhu.ai/en/prompts/claude-opus-5-5/2103151003272962130). Model attribution follows the creators' descriptions. These references informed motion and typography; the delivered illustrations, teaching scenes and animation code are original to this course.

Video encoding follows the explicit-frame-time workflow described in [Chrome WebCodecs guidance](https://developer.chrome.com/docs/web-platform/best-practices/webcodecs): canvas frames have fixed timestamps, encoder queues are drained, and all 2700 frames are validated. FFmpeg produces the H.264/AAC deliverables. Frame caches include source/scene/image fingerprints.

English narration uses explicit language and voice configuration following [Qwen TTS realtime client events](https://www.alibabacloud.com/help/en/model-studio/qwen-tts-realtime-client-events). The provider is recorded in the narration receipts. No provider credentials are included in the package.
