# Australian pilot reproduction

The original workbook is deliberately not committed. Obtain the official register through its visible download interface and comply with its terms; do not substitute an unauthenticated/hidden endpoint. This run used the unchanged30October2026workbook,25,754,571bytes,SHA256`d11687c4423ad0469159a6c386073fcfd104166af6948501bea15d96f94f9441`. Retain it at`../data/au-payment-times-register-2026-10-30.xlsx`.

The extraction uses standard-library OpenXML streaming; it does not need Excel, calculate formulas, or save the original. The modelling uses pandas/numpy/scipy. The optional public-policy downloader also uses PyMuPDF. No browser automation, credentials, network or live website state is used by the statistical scripts. CPU thread environment variables are set to1inside the numerical scripts; execution is serial, including LPs and bootstrap draws.

Observed statistical environment: Python3.13, pandas3.0.3, numpy2.4.6, scipy1.18.0, PyMuPDF1.27.2. Initial workbook inspection/extraction also ran in the provided bundled Python runtime. No packages were installed by this AU analysis.

The extraction scripts take their source path and expected hash from`records/au-register-download-receipt.json`; the commands above use that frozen receipt. A new snapshot should be stored and audited separately. Source IDs/rows and raw versions must remain available when reviewing changed estimates.

`records/au-segment-pilot-plan.json`predates the first persistence model. The follow-up plan explicitly postdates the42-group result; its stronger benchmarks, larger adjacent-match sample and extra outcomes are exploratory. The original plan is not rewritten to incorporate successful post-hoc checks. The joint bootstrap in`verify_au_information_pilot.py`refits both training models after resampling entire ABN histories.

The official recognition checks in`records/au-fast-payer-ui-checks.json`are two manually observed UI records, not generated by the model. Computed eligibility remains separate. The data do not supply payment counts by segment, verified public-release timestamps for each historic revision, or evidence of an actual supplier response. The estimands are group-equal information-content comparisons at the published segment level.

All results are based on Commonwealth of Australia data. Original data, derived CSVs, privately read journal PDFs and browser screenshots stay local under scoped ignore rules. The human-readable source/method/contribution assessment is`../records/round-6-au-register-and-information-pilot.md`.
