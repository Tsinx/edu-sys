UK source attribution: Contains public sector information licensed under the Open Government Licence v3.0. The OCP files are compiled representations of official FTS data, with documented source-quality issues. Compilation/file year is not an award date.

HHS exports came from the original public government portal through its visible CSV controls. Preserve both source lists. Its export contains opaque Java component headers in columns1and8: column1's company-name meaning was verified against the visible table; column8 remains unverified. HHS submission dates must not be relabeled as discovery dates. Public organization-level breach counts are used; no victim-level records were collected.

Other source access outcomes: SEC's official current ticker-to-CIK file and HCSG submission index were obtained under `../records/`. California's CSV URL and Washington'sSocrata dataset were located but **not downloaded**: this computer's direct/browser access failed. Maine's official current page says its public-facing database is offline; a cached detail result does not establish a complete current dataset. These are not counted as obtained datasets.

Round3 subsequently obtained an independent openly licensed copy of event records and directly accessible WA-hosted notice PDFs. This does not change the failed official Socrata/CA CSV access status. Derived dates retain original-source and audience distinctions; VCDB incident dates, registry dates and consumer mailing dates are not interchangeable. Raw files stay local; no student package was created.
