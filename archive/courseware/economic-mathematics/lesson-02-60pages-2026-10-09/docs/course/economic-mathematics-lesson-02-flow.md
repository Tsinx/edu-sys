# 第二讲叙事重构：从定价疑问到经营决策

保留两个45分钟课时，五次独立练习共20分钟。解除50页上限后，按连续讲稿安排60页；分步公开仍是当前页的状态。第一课时1-30页，第二课时31-60页。

贯穿问题：一个商家准备调整售价，怎样得到一份有依据的定价建议？案例为单日、自拟教学情境，固定其他需求条件，按实际履约数量发生成本。需求关系不得由两条截断销量记录直接推断。

| 页码 | 问题进展 | 内容与时间预算 |
| --- | --- | --- |
| 1-10 | 两个价格同销量，究竟相同的是哪一个量？确定的对应有什么要求？ | 从容量记录到需求/销量两种对应，再抽象映射、一元实函数、定义域/陪域/值域；12分钟 |
| 11-20 | 公式能算的价格都能用于建议吗？承诺改变会怎样？ | 非负性、资料范围、明确增加模型假设、平台报价集合、履约约束、空集及解除冲突；14分钟，含4分钟练习 |
| 21-30 | 允许部分需求不能成交时，收入与成本应使用哪个数量？ | 分段销量、值域、按实际履约计费、具体复合链、一般复合定义、定义域及错误反馈；19分钟，含5分钟练习 |
| 31-39 | 希望每天售出300件或400件，该怎样报价？ | 目标驱动逆向判断、单射与反函数、定义域交换、双侧验证、限制原函数；12分钟，含3分钟练习 |
| 40-48 | 开场两种方案怎样比较？怎样排除所有其他价格？ | 收入、平台佣金、单位贡献、完整分段利润、三点与全域证明、顶点适用区间及网格核验；15分钟，含4分钟练习 |
| 49-55 | 最佳售价已定，扩容还能多赚多少？扩容是否值得？ | 容量400变500、边界80变70、同一顶点现在合法、相邻报价比较、项目成本与统一实验；8分钟 |
| 56-60 | 这套论证能否迁移到新商品，并形成有限度的建议？ | 新情境作答、集合和逆向反馈、利润与范围、回到经营建议；10分钟，含4分钟练习 |

每一页有独立编写的口播与教师承接说明。题设保留在计算页，抽象定义先有具体对应，关键结果有条件和核对。成本仅在成本链出现时引入，佣金仅在利润问题出现时引入。参数变化必须说明继承条件与改变条件。

扩容是核心条件变化：基准二次式的顶点640/9不在需求约束分支；容量500时分界变70，该顶点进入适用分支。连续最优约71.11元；网格最优71元，利润19511元，比基准增加711元。新增固定成本1000元后利润18511元，低于基准18800元。固定成本平移的数学意义在此随项目比较提出。

抽成20%、60%压力情境及停业可避免成本比较留在课后与备课拓展，课堂实验允许教师按时间选用，不挤占完整扩容论证。全课程其他讲次保持原内容。逐页时间是试讲预算；现场讨论可能需要调整，不能把页数和本地检查当作课堂节奏证明。
